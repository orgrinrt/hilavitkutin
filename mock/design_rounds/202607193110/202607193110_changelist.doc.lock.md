## CHANGE: `hilavitkutin/DESIGN.md.tmpl` gains the swap requirement

The accumulator-region paragraph gained a shared-derivation invariant last round. The resource
section gains the corresponding statement for `Replaceable` swaps, quoting the requirement rather
than paraphrasing it:

a swap is a member-by-member copy of each leaf into its column slot, the same path as the initial
drain, **not** an in-place blob write of the whole value. Scalars are a write per leaf; `Seq` and
`Map` write their elements consecutively.

This is stated in the design because the code cannot currently express it, and because a reader who
finds `replace_value` marking dirty and writing nothing should find the reason next to it rather
than having to reconstruct why the obvious one-line install is wrong.

The statement also records what an implementer needs: the decomposition comes from
`<T as Decompose>::Leaves`, and per-leaf column slots are what #654 is building.

## Why this lands even though the code is being reverted to a stub

An unimplemented function whose design is written down is a gap. An unimplemented function whose
design is not written down is an invitation to implement it the obvious wrong way, which is what
happened. The design text is the thing that stops the next attempt repeating this one.

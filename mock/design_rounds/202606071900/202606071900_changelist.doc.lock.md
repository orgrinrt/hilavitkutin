# Doc changelist: GATE-2 R4c round A, frame wake-word protocol

**Date:** 2026-06-07
**Phase:** DOC
**Scope:** no `*.md.tmpl` edits

## Rationale

The three new `PoolFrame` fields (`seq`, `done`, `exited`) and the `thread/frame.rs`
helpers are internal runtime-orchestration mechanism, not part of the documented
public design surface. `PoolFrame` is described in the api `DESIGN.md.tmpl` as the
runtime data-plane carrier; adding per-frame sync words to it is an additive
internal detail, and the `frame_*` helpers are engine-internal (siblings of the
existing `phase_barrier_*` helpers, which are likewise not enumerated in the doc
surface). No documented contract changes.

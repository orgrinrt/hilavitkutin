`pub trait WitnessIndex { const INDEX: USize; }`, impl for `Here` (ZERO) and `There<I>` (`I::INDEX + 1`). Gives each peano witness its runtime store-bit index (the existing `Selector`/`Project` never needed a numeric index).

## CHANGE: NEW trait `Locate` ADD
File: `mock/crates/hilavitkutin/src/plan/project.rs`
`pub trait Locate<Target, Index> {}`; head impl `Locate<Target, Here> for Cons<Target, Tail>`, tail impl `Locate<Target, There<I>> for Cons<Head, Tail> where Tail: Locate<Target, I>`. Pure type-level index witness over the api `AccessSet` cons-list.
Verification: `grep "trait Locate" mock/crates/hilavitkutin/src/plan/project.rs`.

## CHANGE: NEW trait `MaskProject` ADD
File: `mock/crates/hilavitkutin/src/plan/project.rs`
`pub trait MaskProject<Stores, Indices, const MAX_STORES: Cap>`; folds an access set into an `AccessMask<MAX_STORES>` by setting each member's located bit. `Indices` is the parallel witness list (inferred at the call site).
Verification: `grep "trait MaskProject" mock/crates/hilavitkutin/src/plan/project.rs`.

## CHANGE: NEW trait `BundleProject` ADD
File: `mock/crates/hilavitkutin/src/plan/project.rs`
`pub trait BundleProject<Stores, Witnesses, const MAX_UNITS: Cap, const MAX_STORES: Cap>`; walks a `WorkUnitBundle` cons-list, per WU projecting `Read`/`Write` into `PlanInputs.{reads,writes,access}[i]`, copying `COMMUTATIVE` into `commutative[i]`, tracking `unit_count`. `Witnesses` is the parallel per-WU `(ReadIdx, WriteIdx)` witness list, inferred.
Verification: `grep "trait BundleProject" mock/crates/hilavitkutin/src/plan/project.rs`.

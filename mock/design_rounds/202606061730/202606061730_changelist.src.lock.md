# Src changelist: build-time topological-registration gate

## Summary

Add the build-time precondition that rejects an acyclic-but-anti-topological
WorkUnit registration, ahead of the D1e dispatch-walk rewrite that will rely on
the carrier order being topological. The plan layer stays order-independent; the
scheduler enforces the provisional constraint. New `BuildError` variant, a
canonical back-edge detector reusing `build_dag`, the check wired into
`compute_plan`, plus test coverage (new rejection test, rehab of the
anti-topologically-registered `phase_sequential_dispatch` test).

## CHANGE: enum `BuildError` GAINS variant `NonTopologicalRegistration { producer: USize, consumer: USize }`
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs` (enum at line 84)
Detail: a struct variant naming the offending carrier slots: `producer` writes a
store that `consumer` reads, while `producer` is registered after `consumer`
(carrier slot index of producer >= consumer). Distinct from `PlanFailed` (a
dependency cycle). Doc comment states the provisional framing and that the
variant relaxes when RCM auto-ordering lands.
Verification: `grep "NonTopologicalRegistration" mock/crates/hilavitkutin/src/scheduler/mod.rs` returns the variant declaration plus its construction site.

## CHANGE: fn `first_back_edge` ADDED to `plan::steps`
File: `mock/crates/hilavitkutin/src/plan/steps.rs`
Detail: `pub fn first_back_edge<D: PlanDims>(inputs: &PlanInputs<D::Units, D::Stores>) -> Maybe<(USize, USize)>`. Builds the canonical dag via `build_dag` and walks its
edges; returns `Maybe::Is((from_idx, to_idx))` for the first edge whose source
slot index is not strictly less than its destination slot index (a back-edge in
carrier space), else `Maybe::Isnt`. Reuses `build_dag` so "what is a dependency
edge" has one definition. WAW edges are appended only for `s < t`, so they never
back-edge; only RAW edges (reader registered before writer) can.
Verification: `grep "pub fn first_back_edge" mock/crates/hilavitkutin/src/plan/steps.rs` returns one match.

## CHANGE: fn `compute_plan` GAINS the registration-topological precondition
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs` (fn at line 221)
Detail: before `compute_execution_plan`, call `steps::first_back_edge::<DefaultPlanDims>(&inputs)`; on `Maybe::Is((producer, consumer))` return
`Outcome::Err(BuildError::NonTopologicalRegistration { producer, consumer })`. The
check runs before any allocation, so a rejected registration allocates nothing,
consistent with the existing `PlanFailed` path. `compute_execution_plan` is
unchanged: the plan layer stays order-independent.
Verification: `grep -n "first_back_edge\|NonTopologicalRegistration" mock/crates/hilavitkutin/src/scheduler/mod.rs` shows the call and the error construction in `compute_plan`.

## CHANGE: test `build_rejects_anti_topological_registration` ADDED
File: `mock/crates/hilavitkutin/tests/scheduler_run_walk.rs`
Detail: registers a producer/consumer chain with the consumer registered before
the producer (anti-topological under append), asserts `build` returns
`Outcome::Err(BuildError::NonTopologicalRegistration { .. })` with the producer

lands (build currently succeeds via the runtime-reorder path), green after.
Verification: `cargo test -p hilavitkutin --test scheduler_run_walk build_rejects_anti_topological_registration` passes after the precondition lands.

## CHANGE: test `phase_sequential_dispatch_runs_the_chain_in_order` REHABBED to topological registration

  D1e deletes it; this round only adds the precondition the deletion relies on.

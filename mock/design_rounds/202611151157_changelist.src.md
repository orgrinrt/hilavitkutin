## mock/crates/hilavitkutin-build/src/prototype.rs (new)

- `Prototype`, an enum of the scripts the crate offers: `Default` and `Deterministic`.
- `Prototype::tune`, a `const fn` over `PragmaSet`: `Default` returns the set as it is, `Deterministic` returns it without `FastMath`.
- `Prototype::configure`, which resolves the build through the script's `Env` closure, writes the directives, and hands the resolved `BuildConfig` back in a notko `Outcome`. It writes no warning.

## mock/crates/hilavitkutin-build/src/wiring.rs (new)

- `WRAPPER_NAME`, the wrapper's file name, which `bootstrap.rs` reads.
- `Tree`, whose the workspace root is: `Own`, `Fetched` for a root under `CARGO_HOME` or one that holds `Cargo.toml.orig`, and `Foreign` for a root other than the one the wrapper cargo names sits in.
- `WrapperFile` (`Current`, `Stale`, `Missing`) and `ConfigFile` (`Named`, `Unnamed`, `Missing`). `ConfigFile::read` decides `Named` or `Unnamed` from the file's text: a `rustc-workspace-wrapper` key whose value ends with `WRAPPER_NAME`, read under the `[build]` table, as the dotted `build.rustc-workspace-wrapper` at the top of the file, or inside an inline `build = { .. }` table, and nowhere else.
- `Plan`, what the script does next: whether it writes the wrapper, whether it writes the config file, and which `Notice` it prints. `Notice` is `Silent`, `Wired`, `AddLine` or `Dropped`.
- `plan`, a `const fn` from the value of `RUSTC_WORKSPACE_WRAPPER`, the `Tree`, the `WrapperFile`, the `ConfigFile` and whether the prototype writes flags, to a `Plan`. A `Fetched` or `Foreign` tree writes nothing and says nothing.
- `write_cargo_config`, the text of the `config.toml` written where there is none.
- `write_notice`, the `cargo::warning` line of a `Notice`. The `Wired` line says a build of that workspace takes the flags from the next one on.
- `write_watch`, the two `cargo::rerun-if-changed` lines that name the wrapper and the config file.

## mock/crates/hilavitkutin-build/src/script.rs (new)

- `script!`, exported with `#[macro_export]`, taking a `Prototype` variant by name. Its expansion writes the prototype's directives to standard output, asks `cargo locate-project --workspace` from `CARGO_MANIFEST_DIR`, decides the `Tree`, reads the two files, calls `plan`, writes what the plan names (the wrapper with mode 0755 on unix), prints the notice, and in an `Own` tree prints what `write_watch` writes. Where cargo gives no root it prints one warning and writes nothing. Where `CARGO_HOME` is not set it takes `.cargo` under the home directory.
- The tree is `Foreign` where `RUSTC_WORKSPACE_WRAPPER` names a file called `WRAPPER_NAME` that is not this root's own wrapper file, both paths made canonical where they can be.
- The expansion keeps no text in memory: a sink over `std::io::Write` takes the crate's texts to standard output or the file, and a sink that compares holds the wrapper on disk to `write_wrapper`.
- The lint `forbidden-imports` reads the macro's body as this crate's own imports, so its two `use` lines of std carry a `lint:allow` naming the ticket `forbidden_imports_reads_the_body_of_an_exported_macro_as_the`.

## mock/crates/hilavitkutin-build/src/bootstrap.rs

- `write_directives` writes `cargo::rerun-if-env-changed=RUSTC_WORKSPACE_WRAPPER` in place of `cargo::rerun-if-changed=build.rs`.
- `configure_with` keeps its warning for a script that calls it directly, and shares the resolving half with `Prototype::configure`.
- The module doc shows the one-line script.

## mock/crates/hilavitkutin-build/src/lib.rs

- `prototype`, `wiring` and `script` are declared, and `Prototype`, `Tree`, `WrapperFile`, `ConfigFile`, `Plan`, `Notice`, `plan`, `write_cargo_config`, `write_notice`, `write_watch` and `WRAPPER_NAME` are exported.

## mock/crates/hilavitkutin-build/tests/wiring.rs (new)

- `plan` over the whole product of its inputs. What is said comes from a table of thirty rows written out by hand, and what is written from two more, one row for each `WrapperFile` and each `ConfigFile`, every expected value a literal.
- A `Fetched` and a `Foreign` tree plan no write and no notice over the same product.
- `ConfigFile::read` over texts that name the wrapper in each of the three forms, and over texts that name another wrapper, name none, carry the key in a comment, or carry it under another table.
- `write_cargo_config`, each `write_notice` and `write_watch` as literal text, and a refusing writer is reported by all three.

## mock/crates/hilavitkutin-build/tests/prototype.rs (new)

- Over both profile names cargo passes and an unknown one: `Default` writes what `configure` writes less the warning, `Deterministic` writes what `configure_with` without `FastMath` writes, and neither writes a `cargo::warning`.
- `Prototype::tune` over the default set of every `Profile`.

## mock/crates/hilavitkutin-build/tests/script.rs (new)

- A scratch workspace built by the pinned cargo offline, with a rustc that writes its arguments down. The first build writes both files, the wrapper with its executable bit, and prints the `Wired` notice once, and the crate's rustc has no flag of ours. The second build prints no notice, and the crate's rustc takes the flags.
- A wrapper overwritten with another text in the wired workspace is written again by the next build.
- A `config.toml` without the line is byte-identical after the build and the notice names the line.
- A workspace holding `Cargo.toml.orig` is written nothing.
- A workspace whose `.cargo` cannot be made says the wiring could not be written, and the build passes.
- A path dependency that is a member of a second workspace: built from a wired workspace, the second workspace is written nothing.
- Not held by a test: the `CARGO_HOME` branch, since a build under another cargo home has no dependency sources offline (the sketch's git dependency shows it), and the branch where cargo gives no root.

## mock/crates/hilavitkutin-build/tests/bootstrap.rs

- `the_committed_wrapper_is_the_written_one` is deleted.
- `the_wrapper_appends_the_variable_and_nothing_else` runs the text of `write_wrapper` from the test's temporary directory.
- The literal directives in three tests take the new rerun line.

## What a consumer sees

`script!` and `Prototype` are added, and the first line `write_directives` writes changes. `configure`, `configure_with`, `write_wrapper` and the rest keep their signatures.

## Comparison to deprecated changelist

### mock/crates/hilavitkutin-build/src/prototype.rs (new)

Unchanged in source. `Prototype`, `Default`, `Deterministic`, `Prototype::tune` over `PragmaSet` without `FastMath`, and `Prototype::configure` through `Env` handing back the `BuildConfig` in an `Outcome` are as the deprecated text has them.

### mock/crates/hilavitkutin-build/src/wiring.rs (new)

`Tree` gains `Foreign` beside `Own` and `Fetched`, where the deprecated text had a root under `CARGO_HOME` or holding `Cargo.toml.orig` as the only ones left alone. `ConfigFile::read` reads the key under `[build]` alone, where the deprecated text took it under any table and missed the inline form; `ConfigFile` keeps `Named`, `Unnamed` and `Missing`, and `WrapperFile` keeps `Current`, `Stale` and `Missing`. `write_watch` is new. The `Wired` text of `Notice` no longer says the next build takes the flags without saying whose; `Silent`, `AddLine` and `Dropped` are unchanged, and so are `Plan`, `plan` and `WRAPPER_NAME`.

### mock/crates/hilavitkutin-build/src/script.rs (new)

`script!` decides the `Foreign` tree from `RUSTC_WORKSPACE_WRAPPER` and prints the watch lines. The question to cargo from `CARGO_MANIFEST_DIR` is unchanged.

### mock/crates/hilavitkutin-build/src/bootstrap.rs

Unchanged.

### mock/crates/hilavitkutin-build/src/lib.rs

`write_watch` joins the exports.

### the thirteen build scripts

Unchanged.

### mock/crates/hilavitkutin-build/tests/wiring.rs (new)

The expected writes are literal rows, where the deprecated text's test computed them with the implementation's own expressions. The `Foreign` tree, the table forms of the config file and `write_watch` are added.

### mock/crates/hilavitkutin-build/tests/prototype.rs (new)

Every profile, where the deprecated text's test sampled the release profile alone.

### mock/crates/hilavitkutin-build/tests/script.rs (new)

The second build is held to its rustc taking the flags, which the deprecated text's test did not look at. A stale wrapper, a `.cargo` that cannot be made and a path dependency in a second workspace are added. The two branches no test holds are named.

### mock/crates/hilavitkutin-build/tests/bootstrap.rs

Unchanged.

### what a consumer sees

Unchanged, and `write_watch` is one more export.

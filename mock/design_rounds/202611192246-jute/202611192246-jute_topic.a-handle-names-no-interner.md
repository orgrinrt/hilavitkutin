# Topic: a string handle names no interner, so resolve guards only the live count

**Date:** 2026-11-19
**Phase:** TOPIC
**Scope:** `hilavitkutin-str` (`ArenaInterner` contract), `hilavitkutin-providers` (`MemoryArena`, its tests)
**Source topics:** the pr-reviewer-senior pass over `work/hila-consumer-surface` at `110ecccc`, blocker 1 and findings 3 and 4; round `202611192051-ers6`, closed, whose decision this corrects

## What the record says

Round `202611192051-ers6` wrote into the `ArenaInterner` contract and the `MemoryArena` design that resolving an id the arena did not issue returns the empty string, and named a handle from another interner as one such id. A `Str` carries a kind bit and a 28-bit index and nothing naming the interner that issued it, which the expert seat had already recorded (`mock/research/202611191955_consumer-surface-seat/NOTES.md`, "a `Str` from another interner instance is indistinguishable by bits"). `arena_resolve` refuses only an index at or past the live entry count. The canon says a string handle is specific to its session (`tenet::an_interned_string_handle_is_session_specific_so_it_is_stored_on_disk_as_its_content_hash`), so a handle carried to another interner was never one the design had to answer for.

## Where the record is wrong

A foreign handle whose index is below the arena's count resolves to that arena's string at the index: intern one string in each of two arenas and the first arena's handle resolves to the second arena's string in the second. The test `a_handle_from_a_larger_arena_resolves_empty_in_a_smaller_one` interned five strings so its probe sat past the count, the one input where the claim holds. The law's two overflow violations, left by the closed round as known, are asserted nowhere as red: two different strings that both overflow get one handle, and an overflow handle resolves to the empty string rather than to its value (`mock/crates/hilavitkutin-sym/DESIGN.md.tmpl`, the interning law).

## Decision for this round

Derived, not asked. The contract states what holds: an id at or past the arena's live count, the masked overflow sentinel among them, reads nothing outside the arena and resolves to the empty string. It states what does not: a handle is meaningful only to the interner that issued it, and one carried to another interner resolves to whatever that interner holds at its index. The foreign-handle test is replaced by one asserting exactly that. The two overflow violations become tests of the law that fail, ignored under the ticket that tracks them. The shapes the seat listed and the suite never asked are added: `intern_static` through the default interner, an arena with no bytes, and overflow by running out of entry slots rather than bytes.

What this round leaves: an unresolvable runtime handle still reads as the empty string, so `evict_str` stores the hash of `""` where the persistence canon says `Missing`; that wants `arena_resolve` to say it holds nothing, a signature change, and goes with the visible refusal loru asked for in `e08a7317ab9e`. Both are tickets.

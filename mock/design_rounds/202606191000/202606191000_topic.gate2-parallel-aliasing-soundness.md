# Topic: GATE-2 parallel aliasing-model soundness

**Date:** 2026-06-19
**Crate:** hilavitkutin (engine, scheduler/mod.rs)
**Tracked:** GATE-2 (#662) close, capstone-review finding 1

## Problem

In `run_parallel`, each worker binds `let s = unsafe { &*sched }` once, above its
frame loop, and holds that shared reference across every park
(`frame_await`). Between frames the main thread mutates three plain
(non-interior-mutable) scheduler fields through `*mut Self`:
`virtual_epoch` (USize), `first_frame` (Bool), `store_dirty`
(AccessMask). The workers then read `first_frame` and `virtual_epoch`
through the live `&*sched`.

The frame publish/await Release/Acquire pair makes the values race-free and
correct (workers read after Acquire, main writes before Release, never
concurrent). That is the value axis, and it holds. The borrow axis does not:
under Stacked/Tree Borrows, writing to an allocation through a raw/`&mut`
pointer while a derived shared reference to it is live in another thread is
undefined behaviour regardless of timing. The bindings and `meta_block`
mutations are already sound because they go through interior-mutable cells
(`Cell` / accumulator `UnsafeCell`); only the three plain scalar/mask fields
are exposed.

## Decision

Give the three between-frame-mutated, worker-visible fields interior
mutability so every write goes through a shared reference, matching the
engine's existing `plan_dirty: [AtomicBool; 256]` and
`gate2_accum_live: [AtomicUsize; ..]` precedent (Relaxed atomics ordered by
the frame barriers):

- `first_frame: Bool` becomes `AtomicBool`.
- `virtual_epoch: USize` becomes `AtomicUsize`.
- `store_dirty: AccessMask<D::Stores>` becomes `Cell<AccessMask<D::Stores>>`
  (worker-invisible, main-only access; `Cell` matches the `meta_block`
  interior-mutability precedent and the single-core `&mut self` paths use
  `get`/`set` uniformly).

All atomic accesses use `Ordering::Relaxed`: the per-frame publish/await
Release/Acquire already establishes the happens-before that orders these
fields across the park, exactly as it does for `plan_dirty` and
`gate2_accum_live`. The parallel-path writes change from
`(*me).field = v` to `(*me).field.store(v, Relaxed)` / `.set(v)`, which
create a shared reference to the atomic/cell and write through it, the sound
interior-mutability path. Worker reads change from `s.field.0` to
`s.field.load(Relaxed)`.

## Scope note

This fixes the exercised between-frame writes inside `run_parallel`. The
broader latent concern (any `&mut self` method, e.g. `mark_dirty`, called
after workers spawn aliases the parked workers' `&*sched`) is not exercised
by the current parallel tests and is recorded for a follow-up; the
three-field conversion removes the path the capstone review flagged.

# Src changelist: fiber-structured morsel-outer dispatch

**Date:** 2026-06-05
**Phase:** SRC
**Round:** 202606051500 (fiber-structured-morsel-outer-dispatch, branch `feat/hilavitkutin-fiber-structured-dispatch`)

Restructure `Scheduler::run` from the whole-plan `accum_free` morsel-outer guard to a per-fiber walk over `phases -> trunks -> fibers`, dispatching each fiber morsel-outer when it is morsel-local (writes no accumulator) and unit-outer otherwise. Correct for every plan via the unit-outer fallback; morsel-outer where provable.

## Deviation from the locked doc CL (recorded per cl-claim-sketch-discipline / arvo-bridge-home-rule precedent)

The locked doc CL (and the architect read it captured) place the accumulator-store-set production at the store DRAIN, as a `Mask` over `D::Stores`. SRC inspection of `plan/project.rs` shows that is the wrong store-index space: the plan's access masks (`PlanInputs.reads/writes/access`) index stores by POSITION IN THE GLOBAL `Stores` AccessSet cons-list (`WitnessIndex` / `Locate` / `MaskProject`), whereas the drain's `StoreId` advances "once per non-zero-sized resource and once per column" (`bindings.rs:269`), skipping ZST resources, a different space. A fiber's morsel-local test is "does any unit in the fiber write an accumulator," and the per-unit write masks (`PlanInputs.writes`) live in the Stores-list-position space. So the accumulator mask must live in that same space.

Corrected production site: a type-level fold over the global `Stores` AccessSet, built by the same `MaskProject` machinery, setting the bit at each `Accum<T>` member's position. The intersection `writes[u] & accum_mask` is then self-consistent in one space, independent of the drain's `StoreId` space. The locked doc CL stays as audit trail; this src CL is the corrected execution.

## CHANGE: add type-level accumulator-store mask fold over the global `Stores` list
File: `mock/crates/hilavitkutin/src/plan/project.rs`
A sealed per-marker classification (`Accum<T>` accumulator, `Column`/`Resource`/`Virtual` not) read by a positional fold producing an `AccessMask<CS>` with bits set at accumulator positions, mirroring `MaskProject` / `WitnessIndex` to dodge the marker-trait coherence wall the module already documents.
Verification: a unit test instantiates the fold over a `Stores` list with an `Accum` member and asserts the mask bit at its position is set and non-accumulator positions are clear.

## CHANGE: struct `Fiber<D>` ADD field `morsel_local: Bool`
File: `mock/crates/hilavitkutin/src/plan/fiber.rs`
Default `Bool::TRUE` in `new()` (an empty fiber writes no accumulator). Copy/Clone unaffected (`Bool: Copy`).
Verification: `grep "pub morsel_local: Bool" mock/crates/hilavitkutin/src/plan/fiber.rs` returns one match.

## CHANGE: compute per-fiber `morsel_local` at fiber formation
File: `mock/crates/hilavitkutin/src/plan/steps.rs`
For each formed fiber, `morsel_local = (for every unit u in the fiber, writes[u] & accum_mask == empty)`, using `PlanInputs.writes` and the accumulator mask. Thread the accumulator mask through the plan-build entry.
Verification: a 2-fiber plan (one accumulator-writing unit, one accumulator-free) yields `morsel_local == FALSE` on the accumulator fiber and `TRUE` on the other.

## CHANGE: `Scheduler::run` walk `phases -> trunks -> fibers`, gate morsel-outer per fiber
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs`
Replace the whole-plan `accum_free` branch with a per-fiber walk (a compact per-fiber dispatch descriptor derived at build time alongside `topo_order`: each fiber's slice start into the order, unit count, and `morsel_local`). Per fiber: morsel-outer when `morsel_local`, unit-outer otherwise; `record_count == 0` keeps the one-empty-morsel-per-unit pass. Retire the whole-plan `accum_free` field and its `AccumFreeBindings` use once per-fiber lands; keep the existing accumulator-pipeline test green via the per-fiber path.
Verification: the existing whole-plan accum-free and accumulator-pipeline dispatch tests stay green; a new mixed 2-fiber test asserts per-fiber morsel-outer vs unit-outer dispatch and correct results.

## CHANGE: add `Scheduler::select_adapt_config` + `BALANCE_FACTOR`
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs`
Verification: `grep -n "fn select_adapt_config" mock/crates/hilavitkutin/src/scheduler/mod.rs` returns one match.

Scans `phase_ema`, treats nonzero slots as active phases, sets `adapt_reconfigure`
iff >= 2 active phases and `max_active > BALANCE_FACTOR * min_active`. Pure
`&self`, no clock, no dispatch tap. `BALANCE_FACTOR` is a tunable module const
default.

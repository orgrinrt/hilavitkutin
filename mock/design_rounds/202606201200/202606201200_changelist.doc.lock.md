## File: `mock/crates/hilavitkutin/DESIGN.md.tmpl`

After the per-phase EMA paragraph, add a short note on the adapt trigger:

- `select_adapt_config` reads the engine-internal EMAs (`phase_ema`, `idle_ns`)
  once per frame and sets a reconfigure trigger when it detects phase imbalance
  (one active phase's EMA dominates the least active phase's by more than a
  tunable balance factor). It is the keystone the adapt-performance contracts
  pin: an adaptive run improves / never degrades only if this decision fires
  correctly.
- The first trigger is `adapt_reconfigure` (phase imbalance). The actuation that
  acts on it (re-selecting per-phase configs, re-chunking morsels) is the
  follow-up; this is the decision half.

No new public backticked type (`select_adapt_config` / `adapt_reconfigure` are
private engine surface), so the design-doc-source-mismatch lint is unaffected.

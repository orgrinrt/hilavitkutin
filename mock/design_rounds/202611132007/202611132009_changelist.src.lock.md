# src changelist

Round topic `202611132004_topic.leaf-crates-green.md`, doc changelist `202611132007_changelist.doc.lock.md`. The two other flat topics, `202607200100_topic.b1-cap-lifting-completion.md` and `202607281547_topic.adopt-the-shared-hlist.md`, name `hilavitkutin` and `hilavitkutin-api` only, which this round does not touch, so they need nothing from it.

## mock/crates/hilavitkutin-str/src/entry.rs

- `StaticStrEntry::new(value)` is a `const fn` that builds an entry from a string literal, with `hash` the 28-bit const handle of its FNV-1a hash. It is the one place an entry's hash is derived.

## mock/crates/hilavitkutin-str/src/macros.rs

- `str_const!` builds its entry with `StaticStrEntry::new` and returns that entry's `hash`, instead of spelling the hash out twice.

## mock/crates/hilavitkutin-str/src/section.rs

- Each platform's `imp` places one anchor entry, the empty string, in the strings section with `#[used]`. The walker returns the empty slice unless the anchor lies inside the section bounds, so a link that holds no `str_const!` still defines the section's start and stop symbols and still links.

## mock/crates/hilavitkutin-str/tests

- A test that `static_entries()` holds the empty-string anchor and that `intern("")` resolves to a const handle and back.

## mock/crates/hilavitkutin-linking/src/backend/unix.rs

- `RTLD_LOCAL` is 4 on macOS, iOS, tvOS and watchOS and 0 on every other unix target.

## mock/crates/hilavitkutin-linking/tests

- A test that loads a library the process has not mapped and gets a non-null handle (gnu Linux), and a negative control that `dlopen` with the value 4 returns null for the same library.

## mock/crates/hilavitkutin-sym/src/generator.rs

- `Generator::single` and the `Default` impl are bounded on `D::Shape: SymShape<Origin = OneOrigin>` instead of `Shape = Standard`. The bound on `single` sits on the function, since an inherent impl cannot carry a `[const]` bound, and the function asserts that origin index 0 is in range for the shape: a build error where `single` sits in a constant, a panic at the first call elsewhere. A `const` block and an associated constant both fail to see the `[const]` bound, so the check cannot be made at instantiation alone. The type doc states the shape's counter width, not 28 bits.

## mock/crates/hilavitkutin-sym/tests/generator.rs

- A `WideKind` domain test for `single`, and a `compile_fail` doctest that `single` does not exist on a `SixteenMinters` domain.

## mock/crates/hilavitkutin-persistence/src/archive_str.rs, string_table.rs, manifest.rs

- `evict_str` returns the 64-bit `ContentHash` of the string's bytes, or `PersistenceError::Missing` for a handle the interner cannot resolve. `inject_str` accepts a const candidate only if its string hashes back to the whole key. The 28-bit wording in the field and doc comments is replaced.

## mock/crates/hilavitkutin-persistence/tests/archive_str.rs

- The helper no longer masks the hash to 28 bits, the identity test is reworked to the new evict contract, and a ten-thousand-string test counts collisions at 64 bits and again at a narrow width as its control.

## mock/crates/hilavitkutin-extensions-macros/Cargo.toml

- `object` 0.37 joins the dev-dependencies, with the elf, macho and pe readers only, for the smoke test below. It is Apache-2.0 or MIT, which `deny.toml` allows, and pulls in `memchr`, already in the lockfile.

## mock/crates/hilavitkutin-extensions-macros/tests/lto_smoke.rs

- The `nm` command and the non-unix ignored stub are replaced by a reader of object files over the `object` crate, running on every host, with the three conditions from the design. A unit test on a symbol list without the shutdown trampoline shows the check reports it missing.

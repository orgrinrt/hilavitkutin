## What this round is

The triage found that dev does not link two test binaries (`hilavitkutin-providers` `smoke` and `hilavitkutin-persistence` `archive_str`), that the unix loader passes a flag value that means something else on linux, that one sym constructor is offered on one shape where the property it needs belongs to several, and that persistence keys strings by a width its own source says collides. Each is small and sits in a crate nobody overhauls. They are one round because they share the leaf crates and a gate, and because a ticket per crate would have been four rounds of the same size.

## The jobs, and what each decides

The strings section. On linux the linker defines `__start_hilavitkutin_strings` and `__stop_hilavitkutin_strings` only when at least one input places something in the section, so a binary that links `hilavitkutin-str` and never calls `str_const!` does not link. The section's owner is `hilavitkutin-str`, so the crate places one entry itself, an anchor the walker reads from, and the walker refuses a section that does not contain the anchor. The anchor is the empty string, registered through the same constructor `str_const!` uses, so the derivation of an entry from a string has one definition. Whether strings should be collected through linker sections at all is op's question `hilavitkutin_str_collects_strings_through_linker_sections`, and this round does not decide it.

The loader flag. `RTLD_LOCAL` is 4 on macOS and the other Apple targets and 0 on the others, where 4 is `RTLD_NOLOAD` and makes `dlopen` return null for any library not already resident. The ten loader tests all load libc, which is always resident, so none could see it.

The generator. `Generator::single` is offered on `Standard` alone, where the property it needs is one origin. `WideKind` has one origin and is refused. The constructor is bound on the property, and its totality is checked per shape at compile time instead of assumed.

Persistence. The content key of a string on disk is the full 64-bit hash the substrate type already has, where evict and inject mask it to 28 bits, which collides at about 17 percent over ten thousand strings. The design text for it still says 28.

The LTO smoke. The unix test reads the symbol table through `nm`, and the other hosts have an ignored stub. One reader of object files for every host replaces both.

The trybuild fixtures. The ticket measured the extensions-macros fail fixtures compiling at `81c5c58`. At `271909e` all four fail to compile under `cargo test` and under `cargo mock test`, so this part of the ticket does not reproduce, and the round records that instead of changing the fixtures.

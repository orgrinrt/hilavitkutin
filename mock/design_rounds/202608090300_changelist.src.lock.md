# Source changelist: the kind width, and widths that mean something

**Phase:** IMPL
**Doc changelist:** `202608090300_changelist.doc.lock.md`
**Scope:** `mock/crates/hilavitkutin-sym/src/**`, `tests/**`.

Every verification below is run **after** the commit hook's autofix, against
`git show HEAD`, because the previous round's changelist named a command that its
own commit's rustfmt pass falsified.

## CHANGE: new `WideKind` shape with its own bitfield

File: `src/shape.rs`, `src/handle.rs`

A second `bitfield!` declaring five bits of kind, one flag, twenty-six of id.
`WideKind` implements `SymShape` over it. This is what makes the kind width
variable rather than nominal: until a shape's tag is a different width, every
implementation shares one layout and the trait is a parameter over one value.

Verification: a domain declared on `WideKind` mints a handle whose tag is
`0b10000`, a value no three-bit tag can hold, and that handle round-trips.

## CHANGE: remove the widths nothing consumes

File: `src/shape.rs`

`ORIGINS` is read by no code and constrained by no check, so a shape could
declare any number and compile. It goes. What survives is what the mechanism
consumes or what a law constrains.

Verification: `grep -rc 'ORIGINS' src/` returns 0.

## CHANGE: assert the width laws for every shape, not for `Standard`

File: `src/shape.rs`

The two laws (the widths account for all 32 bits; the id is origin plus counter)
were asserted for `Standard` alone while three shapes ship. Choosing which
instantiations to check is choosing what not to find out. Both laws now run over
every shape.

Verification: each law's test names all three shapes.

## CHANGE: delete the two restatements

Files: `src/shape.rs`, `tests/origins.rs`

`assert_eq!(Standard::ORIGINS.0, 1)` restates the literal defining it and cannot
fail. Both occurrences are deleted rather than repaired, which is what the rule
says to do with a test that is structurally incapable of failing.

Verification: no assertion in the crate compares a shape constant to the literal
its own impl declares.

## CHANGE: correct `mint`'s rustdoc and drop the dead items

File: `src/generator.rs`

The doc says exhaustion happens at the 28-bit id space; it happens at the
origin's ceiling, which is the mechanism the previous round built. The unused
`Identity` import and the now test-only `MAX_ID` go.

Verification: `cargo build -p hilavitkutin-sym` emits no warning from this crate.

# src changelist

Round `202611200518-zrf9`, against `202611200518-zrf9_changelist.doc.lock.md`.

## Changes proposed

### 1. The engine's os tier is the `os` feature, off by default

`mock/crates/hilavitkutin/Cargo.toml`: `default = []`; `platform-os` is renamed `os = ["dep:libc"]`; `platform-no-os` is removed. The dev-dependencies gain `hilavitkutin = { path = ".", features = ["os"] }`, so the engine's own tests and fixtures build with the os tier as they did under the old default, and `hilavitkutin-providers` with `features = ["static", "portable"]`.

`mock/crates/hilavitkutin/src/lib.rs`: the two `compile_error!` checks that demanded one platform feature go, with their comment. `#[cfg(feature = "platform-os")]` becomes `#[cfg(feature = "os")]` here and in `src/platform/mod.rs`, `src/scheduler/null_providers.rs`, `src/thread/class.rs` and `src/thread/parking.rs`. Doc comments naming `platform-os` or `platform-no-os` name `os` and its absence: `platform/mod.rs` says a build without `os` has no backend, and `DefaultClock` says it is `OsClock` under `os` and `NullClock` otherwise.

`mock/crates/hilavitkutin/tests/platform_os.rs`: unchanged in what it asserts; it builds through the self dev-dependency.

### 2. Every providers implementation behind `static` or `portable`

`mock/crates/hilavitkutin-providers/Cargo.toml`: `[features]` with `default = []`, `static = []`, `portable = []`. The dev-dependencies gain `hilavitkutin-providers = { path = ".", features = ["static", "portable"] }` for the crate's own tests and examples.

`mock/crates/hilavitkutin-providers/src/lib.rs`: `memory` and its re-exports under `#[cfg(feature = "static")]`; `storage`, `adapt_ema`, `adapt_kits`, `adapt_wu` and `metrics` and their re-exports under `#[cfg(feature = "portable")]`. The crate doc says what each feature carries and that a build on default features carries only `InternerApi` and `HasInterner`.

`mock/crates/hilavitkutin-providers/src/interner.rs` becomes `src/interner/mod.rs`, holding the two contracts `InternerApi` and `HasInterner`, and `src/interner/arena.rs` under `#[cfg(feature = "portable")]`, holding `MemoryArena` and its impls, `default_interner`, `InternerKit` and the impl of `InternerApi` for `StringInterner`. Nothing in them changes but where they sit.

### 3. Each dependent names the features it uses

`mock/crates/hilavitkutin-persistence/Cargo.toml` and `mock/crates/hilavitkutin-frozen-authors/Cargo.toml`: their dev-dependency on `hilavitkutin-providers` names `features = ["static", "portable"]` where its tests use those items, and frozen-authors' dev-dependency on the engine names `os` where its tests use `OsClock` or `OsMemoryProvider`.

The bench crates `mock/benches/asm_gate_fixtures`, `mock/benches/resource_storage/axis_ce` and the support crates `evs-support`, `grid_common`, `rcm_common`, `fiber_common`, `swap_common`, `frame-wide-support`: each path dependency on `hilavitkutin-providers` names `features = ["static", "portable"]`, or `["portable"]` where no `Static*` provider is named; each path dependency on the engine names `os` where it reaches `OsClock` or `OsMemoryProvider`.

## Not changed

`intrinsics-std` and `mutant-truncating-append`. `hilavitkutin-linking`. No item changes its shape: the round moves items behind features and renames one feature.

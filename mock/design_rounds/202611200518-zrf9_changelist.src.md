# src changelist

Round `202611200518-zrf9`, against `202611200518-zrf9_changelist.doc.lock.md`. It replaces `202611200518-zrf9_changelist.src.deprecated.md`.

## Changes proposed

### 1. The engine's os tier is the `os` feature, off by default

`mock/crates/hilavitkutin/Cargo.toml`: `default = []`; `platform-os` is renamed `os = ["dep:libc"]`; `platform-no-os` is removed. The dev-dependencies gain `hilavitkutin = { workspace = true, features = ["os"] }`, so the engine's own tests and fixtures build with the os tier as they did under the old default, and `hilavitkutin-providers` names `features = ["static", "portable"]`.

`mock/crates/hilavitkutin/src/lib.rs`: the two `compile_error!` checks that demanded one platform feature go, with their comment. `#[cfg(feature = "platform-os")]` becomes `#[cfg(feature = "os")]` here and in `src/platform/mod.rs`, `src/scheduler/null_providers.rs`, `src/thread/class.rs`, `src/thread/parking.rs`, `tests/gate2_adapt_ema.rs` and `tests/platform_os.rs`. Doc comments naming `platform-os` or `platform-no-os` name `os` and its absence: `platform/mod.rs` says a build without `os` has no backend, `DefaultClock` says it is `OsClock` under `os` and `NullClock` otherwise, and `NullClock` and `SchedulerBuilder::clock` say the same.

### 2. Every providers implementation behind `static` or `portable`

`mock/crates/hilavitkutin-providers/Cargo.toml`: `[features]` with `default = []`, `static = []`, `portable = []`. The dev-dependencies gain `hilavitkutin-providers = { workspace = true, features = ["static", "portable"] }` for the crate's own tests and examples, and the dev-dependency on the engine names `os`, as its old default had it.

`mock/crates/hilavitkutin-providers/src/lib.rs`: `memory` and its re-exports under `#[cfg(feature = "static")]`; `storage`, `adapt_ema`, `adapt_kits`, `adapt_wu` and `metrics` and their re-exports under `#[cfg(feature = "portable")]`. The crate doc says what each feature carries and that a build on default features carries only `InternerApi` and `HasInterner`.

`mock/crates/hilavitkutin-providers/src/interner.rs` becomes `src/interner/mod.rs`, holding the two contracts `InternerApi` and `HasInterner`, and `src/interner/arena.rs` under `#[cfg(feature = "portable")]`, holding `MemoryArena` and its impls, `default_interner`, `InternerKit` and the impl of `InternerApi` for `StringInterner`. Nothing in them changes but where they sit.

### 3. Every dependent names the features it builds with

Each dependency on the engine inside the workspace names `os`, so it builds with the parking and clock it had under the old default: the dev-dependency of `hilavitkutin-conformance`, and the path dependencies of the bench crates `asm_gate_fixtures`, `frame_wide`, and the support crates `evs-support`, `grid_common`, `rcm_common`, `stc-support`, `wake_common`, `fiber_common`, `swap_common` and `frame-wide-support`. A bench that measured the engine before measures the same engine after.

Each dependency on `hilavitkutin-providers` names `features = ["static", "portable"]`, or `["portable"]` where no `Static*` provider is named: the dev-dependency of `hilavitkutin-persistence`, and the path dependencies of `asm_gate_fixtures`, `resource_storage/axis_ce` and the support crates `evs-support`, `grid_common`, `rcm_common`, `fiber_common`, `swap_common` and `frame-wide-support`.

`mock/crates/hilavitkutin-frozen-authors/Cargo.toml` is a frozen file. Its dependency on the engine names `os` and its dev-dependency on `hilavitkutin-providers` names `portable`, and the change takes a line in `BREAKS.toml` with the file's new hash in `LEDGER.toml`: the engine and the providers now carry their implementations behind features by op's ruling, and a consumer names the ones it builds with.

## Not changed

`intrinsics-std` and `mutant-truncating-append`. `hilavitkutin-linking`. No item changes its shape: the round moves items behind features and renames one feature.

## Comparison to deprecated changelist

### changes proposed

Sections 1 and 2 are the deprecated changelist's, with `OsClock`, `OsMemoryProvider`, `DefaultClock`, `NullClock`, the `compile_error!` checks, `InternerApi`, `HasInterner`, `MemoryArena`, `InternerKit` and the impl for `StringInterner` handled as it had them. The self dev-dependency is written `workspace = true`, as sibling dependencies are, where the deprecated one wrote `path = "."`, and the providers' dev-dependency on the engine names `os`.

Section 3 is where they differ. The deprecated changelist gave `os` only to a dependent that names `OsClock` or `OsMemoryProvider`, and there is none outside the engine. Every crate that builds the engine would then have lost the futex parking and the real clock it had under the old default, and a bench would have measured spin parking under the same name. This one gives `os` to every engine dependency in the workspace. It also names the frozen `hilavitkutin-frozen-authors/Cargo.toml` and the break it takes, which the deprecated changelist left out.

### not changed

The features, their names and what each carries, as the locked doc changelist has them.

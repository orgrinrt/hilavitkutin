## CHANGE: `RunCfg` gains `WAKE_SPIN_BUDGET`

File: `mock/crates/hilavitkutin-api/src/run_cfg.rs`
`const WAKE_SPIN_BUDGET: USize = USize(128);` on `RunCfg`: the bounded
middle-tier spin budget the frame waits run before parking (canonical
Topic 6 axis K P-core default). Zero restores park-immediately exactly.
Consumer-tunable per `arvo-toolbox-not-policer`; the telemetry-driven
`pick_tier` selection remains the D-phase follow-up.
Verification: `grep -c "WAKE_SPIN_BUDGET" mock/crates/hilavitkutin-api/src/run_cfg.rs` returns at least 1.

## CHANGE: `frame_await` / `frame_await_done` FROM park-immediately TO spin-then-park

File: `mock/crates/hilavitkutin/src/thread/frame.rs`
Both waits gain a `spin_budget: USize` parameter and spin up to the
budget re-loading the word (`core::hint::spin_loop` per iteration)
before falling into the unchanged load-check-`atomic_wait` pattern, so
the lost-wakeup discipline is untouched (the spin tier only delays the
first park; the park itself still only sleeps on the observed value).
`await_exit` stays park-only (shutdown latency is irrelevant) with the
reason stated.
Verification: `grep -c "spin_budget" mock/crates/hilavitkutin/src/thread/frame.rs` returns at least 4.

## CHANGE: the two wait call sites pass the Cfg budget

File: `mock/crates/hilavitkutin/src/scheduler/mod.rs`
The worker phase-loop's `frame_await` and `run_parallel`'s
`frame_await_done` pass `Cfg::WAKE_SPIN_BUDGET`.
Verification: `grep -c "WAKE_SPIN_BUDGET" mock/crates/hilavitkutin/src/scheduler/mod.rs` returns 2.

## CHANGE: budget equivalence sweep in the frame-protocol test

File: `mock/crates/hilavitkutin/tests/frame_protocol.rs`
`RunCfg` is sealed, so a test cannot supply a custom impl overriding
the const; the equivalent coverage sweeps the budget at the wait
parameter itself. The protocol test runs its full worker/frame cycle
under budgets 0 (park-immediately baseline) and 128 (the canonical
middle tier), asserting identical frame results: zero IS
park-immediately, and the spin tier never changes what a wait returns.
The default-budget engine path is exercised by every `run_parallel`
test through `Cfg::WAKE_SPIN_BUDGET`.
Verification: `cargo test -p hilavitkutin` green; `grep -c "USize(128)" mock/crates/hilavitkutin/tests/frame_protocol.rs` returns at least 1.

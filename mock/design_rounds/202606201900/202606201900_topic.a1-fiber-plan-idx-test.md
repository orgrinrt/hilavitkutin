## Current state

A1's test uses a single-fiber carrier, where the dispatch-order index `fd` and
the plan CSR index `f` collapse to 0, so `fiber_plan_idx` (which exists precisely
because the two index spaces differ for multi-trunk plans) ships unasserted.

## Change proposed

Add a catalogued `#[ignore]` test asserting `fiber_plan_idx` records the CSR
index when dispatch order reorders fibers (`fd != f`). Left red/ignored because
the mapping is not consumed until slice A2 (loop inversion) and a multi-trunk
fixture that forces `fd != f` is cleanest to build alongside A2's machinery. The
ignored test with the real assertion preserves the case per the
edge-cases-as-tests discipline.

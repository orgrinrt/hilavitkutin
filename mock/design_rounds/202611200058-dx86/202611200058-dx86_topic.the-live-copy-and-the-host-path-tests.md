# The live copy of a host import, and the host path's tests

**Date:** 2026-11-20
**Phase:** topic
**Scope:** `hilavitkutin`, the `Host import and dump` section of its design and the tests under it
**Source topics:** `202611192343-hx2c`, `202611200033-ut6z`

Round ut6z said the live copy of a buffered import has no reader, on the premise that every pass writing a buffered store writes each of its records. That premise is false. A unit's `execute` runs once per window and may call `map` in some windows and not in others, and the engine's own boundary documents the records no unit wrote in a pass (`src/resource/bindings/column.rs:428-430`). The pass 2 reviewer of the branch built such a unit over four windows: with the live copy taken away, the record in an unwritten window loses the import under both `Snapshot` and `Exchange`, and every committed test still passed. So the live copy is what keeps an import across a pass that writes part of the store, and a test has to say so in both modes.

The same premise sits in the buffered boundary paragraph of the design, which says the value function is applied at every record of the unit's range. Under `Exchange` a pass that skips a window then publishes values of two passes before. That is a defect of the boundary rather than of the host path, and it goes to ticket `a_pass_that_skips_map_in_a_window_publishes_stale_records` instead of this round.

The rest are smaller. The `Written` fixture is not refused by `Kept` alone, since `import` also fails to locate the wrapper; `dump` locates it, so a `Written` dump is the one case that pins `Kept` by itself. A buffered store is tested under `run` only. The ticket for the coarse mark cites a question row that asks who says a store changed, not at what grain; the grain is the ratified `change_detection_is_per_morsel_and_skips_what_is_unchanged`, and the coarse bit stands under the stamped `the_per_morsel_generation_counters_are_not_built_and_the_engine_has_a_coarse_per_store_dirty_only`. The design calls evict and inject ticketed when no ticket existed; `the_zero_copy_half_of_the_host_path_evict_and_inject_is_not` is that ticket now. One sentence denies a method that `import` is, and the parallel test's `SAFETY` comment asserts soundness across the aliasing hole.

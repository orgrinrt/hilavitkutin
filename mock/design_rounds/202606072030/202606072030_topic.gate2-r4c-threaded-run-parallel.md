## Current state

`Scheduler::run_parallel` is the R4b single-threaded sweep: it computes the const
grouping and walks `run_core_phase` phase-outer / core-inner on the calling
thread. All the threading primitives now exist: `OsThreadPool::spawn<F>` (real,
slice 1), the frame wake-word protocol `thread::frame_*` (round A), the
per-(core,phase) dispatch primitive `run_core_phase` (B1), and the proven Pin
inline-PoolFrame composition (sketch 202606071930). The executor itself is not
yet threaded.

## What changes

Replace `run_parallel` with the real persistent-pool threaded executor, the
proven Pin shape:

- Inline Scheduler fields: `pool: PoolFrame<'static, 1, 1>` (the C/P-sized adapt
  arrays are unused pre-adapt; the sync words seq/done/exited/shutdown are
  scalars), `worker_ctxs: [WorkerCtx; MAX_CORES]` (`WorkerCtx { sched: *const (),
  core_id: usize }`), `spawned: Bool`, and the grouping result
  (`gate2_phase`/`gate2_trunk` arrays, `gate2_n`, `gate2_nphases`,
  `gate2_ncores`), zero-init at both `build` construction sites. The Scheduler is
  `!Unpin` via a `PhantomPinned` marker.
- `run_parallel<Witnesses, GW, P: ThreadPoolApi>(self: Pin<&mut Self>, pool: &P)`:
  take `let me: *mut Self = self.get_unchecked_mut()`; on first call compute the
  const grouping into the `gate2_*` fields and spawn `pool.worker_count()` workers
  (each closure captures one Send-wrapped `*const WorkerCtx`, the slice-1 smuggle),
  set `spawned`; then drive phases main-orchestrated: `for p in 0..nphases {
  frame_publish(&me.pool); frame_await_done(&me.pool, ncores) }`. The main thread
  IS the inter-phase waist barrier (no worker-side sense-reversing barrier).
- Free fn `worker_main<...6 generics + Witnesses>(ctx: *const WorkerCtx)`: cast
  `ctx.sched` to `*const Scheduler<...>`, then `loop { last = frame_await(pool,
  last); if shutdown { frame_exit_arrive; return }; let p = (last-1) % nphases;
  run_core_phase(core, p, ...); frame_done_arrive }`. Phase derived from the seq
  value (no `current_phase` field).
- `Scheduler::Drop`: if `spawned`, `request_shutdown` + `await_exit` so workers
  leave before the inline fields tear down.

Single-core (`worker_count() == 1`) is the degenerate: one worker owns every
trunk per phase. The R4b inline sweep is replaced (no-legacy-shims).

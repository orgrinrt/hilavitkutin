## CHANGE: add inline pool/worker fields to `Scheduler`
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs`
Detail: `pool: PoolFrame<'static, 1, 1>`, `worker_ctxs: [WorkerCtx; MAX_CORES]`,
`spawned: Bool`, `gate2_phase`/`gate2_trunk: [USize; GATE2_MAX_UNITS]`,

## CHANGE: add `WorkerCtx` + `worker_main` free fn
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs`
Detail: `struct WorkerCtx { sched: *const (), core_id: usize }` (Send-wrapped at
spawn); `fn worker_main<Cfg, WuVals, Vals, CS, D, Stores, Witnesses>(ctx: *const
WorkerCtx)` casts `sched` to `*const Scheduler<...>` and runs the park / phase /
done / exit loop, deriving phase from the seq value.
Verification: `grep "fn worker_main" mock/crates/hilavitkutin/src/scheduler/mod.rs`.

## CHANGE: `run_parallel` FROM single-threaded sweep TO threaded persistent pool
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs`
Detail: signature `run_parallel<Witnesses, GW, P: ThreadPoolApi>(self: Pin<&mut
Self>, pool: &P) -> Cfg::Out`; spawn-once on first call via `pool.spawn`, then
main-orchestrated phases `for p { frame_publish; frame_await_done }`. Replaces the
R4b inline sweep (no-legacy-shims).
Verification: `grep "self: Pin<&mut Self>" mock/crates/hilavitkutin/src/scheduler/mod.rs`.

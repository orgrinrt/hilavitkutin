**Date:** 2026-06-20

**Source topics:** A3 re-chart `202606210000`, sketch `202606210100`, A3-redo-1 (PR #163), op decision "build the Seq/Map write-resource capability now"

## Current state

A3-redo-1 shipped `CollectionBytes` + `ResourceFootprint` traits in `hilavitkutin-api`
(`src/footprint.rs`). To re-bound `StoreElemBytes for Resource<T>` on `ResourceFootprint`
(A3-redo-3), every resource value type must implement `ResourceFootprint`. No
no-specialization blanket default exists, so a derive is mandatory.

The cargo rule (`cargo.md`) states `hilavitkutin-extensions-macros` is the sole
proc-macro crate and a second requires a design round. The `ResourceFootprint`
derive emits `::hilavitkutin_api::footprint::*` paths, which `hilavitkutin-extensions-macros`
is forbidden from referencing. So the derive needs a NEW proc-macro crate. This is
that design round.

## Changes proposed

1. New crate `hilavitkutin-api-macros` (`mock/crates/hilavitkutin-api-macros`): `[lib]
   proc-macro = true`, deps proc-macro2 + syn + quote. Ships `#[derive(ResourceFootprint)]`.
2. The derive: syntactic field-walk over the struct's fields. For each field whose
   type path's last segment is `Field`/`Seq`/`Map`, emit `<ty as
   ::hilavitkutin_api::footprint::CollectionBytes>::BYTES.0`; sum into
   `impl ResourceFootprint for T { const L1_BYTES = USize(Σ) }`. Plain fields
   contribute 0 (skipped). Carries the struct's generics. So existing plain-field
   resources derive to 0 without field-type migration; Seq/Map-bearing resources
   get the real footprint.
3. Workspace registration: `mock/Cargo.toml` members + `[workspace.dependencies]`.
4. `mock/mockspace.toml`: add `hilavitkutin-api-macros` to `proc_macro_crates`; add a
   forbidden-imports scope (error level, same as the existing macro crate's) allowing
   only `::hilavitkutin_api::*` emission paths, forbidding the other hilavitkutin
   crates. ADDITIVE gate coverage for the new crate, NOT a severity change.
5. Doc-claim updates (crate count 9 -> 10, proc-macro count 1 -> 2, "sole proc-macro"
   -> "two proc-macro crates"): `mock/DESIGN.md.tmpl` crate table, `mock/agent/MAIN.md.tmpl`,
   `mock/agent/rules/cargo.md.tmpl` (count + crate list + dependency direction + the
   "exactly one proc-macro crate" forbidden-crate-types bullet).
6. A test: a fixture resource with Field/Seq/Map fields + `#[derive(ResourceFootprint)]`,
   asserting `L1_BYTES == N_seq*elem + N_map*(k+v)` (Field 0).

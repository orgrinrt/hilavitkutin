# Source changelist — resource arena (B2a)

Round: 202605290018. Phase: IMPL. Routes store values onto a `Stores`-aligned `StoreValues` list under the single `.with` verb (validated mechanism, sketch `202605290002_builder-kind-dispatch.md`), builds a `ResourceArena` from registered `Resource<T>` values via a `build(memory_provider)`-supplied `MemoryProvider`, and reshapes `Scheduler` to own the arena and deallocate on `Drop`. Resources only; column buffers are B2b.

## CHANGE: `RouterKind` trait + `StoreKind`/`UnitKind`/`PlatformKind` tags ADDED; impl for each router
File: `mock/crates/hilavitkutin-api/src/builder_input.rs`
`pub trait RouterKind { type Kind; }` with disjoint unit tags. `impl RouterKind for StoreDispatch<S> { type Kind = StoreKind; }`, `UnitDispatch<W> -> UnitKind`, `PlatformDispatch<P> -> PlatformKind`, `RunCfgDispatch<C> -> UnitKind` (run-cfg value dropped at B2a; it is read via the type-level accumulator, not the value list). `KitDispatch` (in `hilavitkutin-kit`) gets `RouterKind` with `UnitKind` there if needed for `.with(kit)` to compile; Kit-owned store values come from `HasTrivialCtor`, not a carrier.
Verification: `grep -q "trait RouterKind" mock/crates/hilavitkutin-api/src/builder_input.rs`.

## CHANGE: `StoreValues` cons-list (`SvEmpty`, `Sv<H, T>`) + `Place<P>` view ADDED
File: `mock/crates/hilavitkutin-api/src/builder_input.rs` (or a new `store_values.rs` in api)
Sealed `pub trait StoreValues`; `pub struct SvEmpty`; `pub struct Sv<H, T: StoreValues> { head: H, tail: T }`. `pub trait Place<P> { type Next<L: StoreValues>: StoreValues; fn place<L: StoreValues>(provider: P, sv: L) -> Self::Next<L>; }`. Non-overlapping impls keyed on the tag-as-`Self`: `StoreKind` prepends (`Next<L> = Sv<P, L>`), `UnitKind` and `PlatformKind` are identity and drop `provider`. Mechanism per the validated sketch.
Verification: `grep -q "trait Place" mock/crates/hilavitkutin-api/src/builder_input.rs` and the sketch shape compiles.

## CHANGE: engine `scheduler::stage` module REMOVED; `SchedulerBuilder` FROM `<Wus, Stores, Platform, Staged: StageList>` TO `<Wus, Stores, Platform, StoreValues>`
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs` and `mock/crates/hilavitkutin/src/scheduler/stage.rs` (removed)
B1's all-values `Staged`/`StageList` is replaced by the api `StoreValues` list. `builder()` returns `SchedulerBuilder<Empty, Empty, Empty, SvEmpty>`. `.with<P>(self, provider: P)` routes via `<<P::Dispatch as RouterKind>::Kind as Place<P>>::place(provider, self.store_values)`, advancing the typestate as before; return type encodes the next `StoreValues`. Delete `stage.rs` and its module declaration. Update the `builder_retains_registered_value` test to read off `StoreValues` (the staged resource value is reachable on the store-value list).
Verification: `! test -e mock/crates/hilavitkutin/src/scheduler/stage.rs` and `grep -q "SchedulerBuilder<Empty, Empty, Empty, SvEmpty>" mock/crates/hilavitkutin/src/scheduler/mod.rs`.

## CHANGE: `resource/arena.rs` ADDED (`ArenaFor`, arena nodes, `DrainStores`, `DropArena`)
File: `mock/crates/hilavitkutin/src/resource/arena.rs` (new) + `mock/crates/hilavitkutin/src/resource/mod.rs` (expose)
Sealed `ArenaFor<S: AccessSet> { type Arena; }`: `Empty -> ArenaTail`; `Cons<Resource<T>, R> -> ArenaResourceNode<T, <R as ArenaFor>::Arena>` (holds `ResourcePtr<T>`); `Cons<Column<T>, R> -> ArenaColumnNode<T, ...>` (placeholder, no allocation in B2a); `Cons<Virtual<T>, R> -> ArenaVirtualNode<T, ...>`. Sealed `DrainStores` walks `Stores` + `StoreValues` in lockstep: per `Resource<T>`, `mp.allocate(size_of, align_of)`, null-check (on null, drop the prefix already built and return `Err(BuildError::AllocationFailed)`), `core::ptr::write` the carrier's `into_inner()` value, record `ResourcePtr::new_unchecked`. Sealed `DropArena` walks the arena: `core::ptr::drop_in_place` each resource value then `mp.deallocate`. `lint:allow(no-bare-numeric)` at the `size_of`/`align_of` `usize` roots with `reason: core::mem size/align return usize by contract; tracked: #345`.
Verification: `grep -q "trait ArenaFor" mock/crates/hilavitkutin/src/resource/arena.rs` and `cargo check -p hilavitkutin` green.

## CHANGE: `Scheduler` FROM `<Cfg>` TO `<Cfg, Stores, M: MemoryProviderApi>`; `build` FROM `(self) -> Scheduler` TO `<M>(self, memory_provider: M) -> Outcome<Scheduler<DefaultRunCfg, Stores, M>, BuildError>`; add `Drop`
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs`
`Scheduler<Cfg, Stores, M>` gains `arena: <Stores as ArenaFor>::Arena` + `memory_provider: M` fields (struct bound `Stores: AccessSet + ArenaFor`). `build`/`build_with` take `memory_provider: M`, call `DrainStores`, return `Outcome`. `pub enum BuildError { AllocationFailed }`. `impl Drop for Scheduler<Cfg, Stores, M>` calls the `DropArena` walk. `type BuiltScheduler<Stores, M> = Scheduler<DefaultRunCfg, Stores, M>`. Existing inference-built tests update to `let s = builder.build(provider).unwrap_or(...)` shape.
Verification: `grep -q "memory_provider: M" mock/crates/hilavitkutin/src/scheduler/mod.rs` and `cargo test -p hilavitkutin -p hilavitkutin-api` green.

## CHANGE: arena tests ADDED (engine) with a stack-backed counting test `MemoryProvider`
File: `mock/crates/hilavitkutin/tests/resource_arena.rs` (new) or unit tests in `scheduler`/`resource`
`resource_arena_round_trip` (register `Resource::new(99u32)`, build, deref the `ResourcePtr<u32>` = 99); `resource_arena_drop_deallocates` (counting provider, every allocate paired with a deallocate on drop); `resource_arena_multiple_resources` (three distinct-type resources reachable); `resource_arena_drop_runs_destructor` (a `DropCounter` resource increments a shared atomic on drop). Test provider is a fixed `[MaybeUninit<u8>; N]` bump allocator with allocate/deallocate counters, defined in the test module (no `std::alloc`).
Verification: `cargo test -p hilavitkutin resource_arena` passes (all four).

## Note: GCE walls resolved (carrier position as Peano witness + fixed grouping cap)

Two generic-const-expr walls surfaced when the const-gated walk was monomorphised, both rooted in a `cap_size(CU::CAP)` array-length bound re-proven through the walk's type-level recursion: (1) `const POS: usize` recursion threads `{POS + 1}`, which the trait solver overflows normalising; (2) the `[(); cap_size(CU::CAP)]` well-formedness bound, re-proven per recursion level, overflows. Resolved: (1) the carrier position is a type-level Peano witness `Pos` (`Here` / `There<Pos>`, `Pos::INDEX`), so the recursion threads a type with no const arithmetic; (2) the grouping arrays size by a fixed `GATE2_MAX_UNITS` const (the loops bound by the actual unit count, so the cap costs only scratch). `plan::grouping` keeps `CU` as an (unused) fn parameter for API continuity.

## What this round does

Re-point `Scheduler::run` through const-gated per-trunk dispatch: a flat walk over the `WuVals` carrier where each position is gated by `const { phase_of(POS) == PHASE && trunk_of(POS) == TRUNK }`, member positions delegating to the shipped `RunFiber` per-unit projection, so dead-code elimination collapses the walk into one member-only program per `(phase, trunk)`. Single-core, output-equivalent to the current flat `RunFiber::run` walk, `#664` no-regress. This establishes the per-trunk dispatch structure (op's correction: trunks established before parallelism); G2-N core-pins one trunk per core onto the shipped pool in a following round.

## Grounding (truth-of-impl, read this firing)

- `Scheduler<Cfg, WuVals, Vals, CS, D, Stores>` (scheduler/mod.rs:553). The dispatch carrier is the field `wu_values: WuVals`, a `WuCons<W, Tail>` / `WuNil` list of work-unit VALUES. `D: PlanDims` gives `CU = D::Units`, `CS = D::Stores`; `Stores` is the global store `AccessSet`.
- The `Cons`-shaped `Wus` bundle (what round 1's `BundleMasks` folds) is NOT a Scheduler field. It lived on `SchedulerBuilder<Wus, Stores, ...>` and was consumed at `build()` via `compute_plan<Wus, Stores, BWit>`. So at `run()` time the only unit-bundle type in scope is `WuVals` (the value carrier).
- `Scheduler::run<Witnesses>` (scheduler/mod.rs:860) walks `self.wu_values` via the shipped `RunFiber::run` (accumulator/record-less path: unit-outer, one full-range walk) or `RunFiber::run_gated` (morsel-outer path: per-frame incremental dirty skip). `Witnesses` is the per-unit PROJECTION-index list (the quad `(RIdx, RCIdx, WCIdx, WAIdx)` per unit), inferred at the `scheduler.run()` call site.
- `RunFiber::run_gated` (dispatch/fiber_run.rs:104) ALREADY gates per carrier position: `if dirty.bit(pos).0 { project + invoke }`, threading a runtime `pos`. The const-gated trunk walk is the same shape with a CONST gate and `POS` as a const generic (so the gate const-evaluates and DCE fires), proven in isolation by sketch 071230.

## Design

1. **Fold the value carrier.** `impl BundleMasks for WuCons<W, Tail>` (and `WuNil`) mirroring the round-1 `Cons<Un, T>` impl, so `phase_of` / `trunk_of` over `(WuVals, Stores, GWitnesses, CU, CS)` fold the carrier's own type. `W` satisfies `UnitAccess` via the `WorkUnit` blanket. (`GWitnesses` = the per-unit `(RI, WI)` MaskProject witness list, distinct from `RunFiber`'s projection `Witnesses`.)

2. **Const-gated walk.** A walk over `WuCons` threading `const POS`, gating each cell by `const { phase_of::<WuVals, Stores, GWitnesses, CU, CS>(USize(POS)).0 == PHASE && trunk_of::<..>(USize(POS)).0 == TRUNK }`; a member position runs the SAME per-unit `EngineCtx` projection + `invoke_wu_in_fiber` as `RunFiber`, a non-member position folds away. Open question (sketch gate): whether the const gate composes around `RunFiber`'s real per-unit body (heavy `Project` / `ColProject` / `AccumProject` / Ctx-GAT bounds) and still devirtualises, vs the sketches' toy `UnitRun` body. Likely either (a) a new `RunFiber` method `run_trunk<const PHASE, const TRUNK, const POS>` mirroring `run_gated`, or (b) a sibling trait delegating each member to a single-unit `RunFiber` step.

3. **Phase/trunk dispatcher.** `phase_count` const fn (max phase + 1). A const-generic recursive dispatcher runs all `(phase, trunk)` programs in phase order: for each phase `P` in `0..nphases`, run trunks (recursive over `const TRUNK` in `0..N`, since trunk ids are component-mins `< N`; empty trunks are no-op monos DCE'd away), with the degenerate `waist_barrier` between phases. Single-core: sequential. **Compile-cost note:** `N` phases x `N` candidate trunks = up to `N^2` monos, most empty (DCE removes them). Acceptable for the mechanism round; if compile time bites at large `N`, narrow the dispatcher to only-occupied trunks later (a perf/bench follow-up, not correctness).

4. **Re-point `run`.** Thread `GWitnesses` as a second inferred generic on `run` (precedent: `compute_plan` threads `BWit`, `run` already threads `Witnesses`). Drive the dispatcher instead of the single flat `RunFiber::run`. Keep the accumulator-bearing unit-outer path correct (an accumulator resets + re-appends each frame; the dispatch order must still run every unit once). Gate: output bit-identical to the pre-change flat walk + `#664` no-regress + objdump each `(phase, trunk)` mono zero blr.

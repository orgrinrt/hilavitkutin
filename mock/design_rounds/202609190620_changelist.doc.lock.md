## Why

PR #8 drops the workspace's last `mockspace` Cargo dependency, and no crate in
this repository has carried a `build.rs` calling into mockspace since
`202607311110_topic.launcher-migration.md` tore the bootstrap model down.
These three crates' design docs were the one place the old claim survived
that teardown, since the migration explicitly scoped itself away from crate
source and design docs. No sibling crate's DESIGN.md.tmpl makes an
equivalent claim, so the fix is deletion, not a rewrite to a different claim.

`docs/LINKING.md`, `docs/EXTENSIONS.md`, `docs/EXTENSIONS_MACROS.md`
regenerate from these sources via `cargo mock` once this changelist locks.

## Refactor: hilavitkutin-str

### CHANGE: struct `Str` FROM `Str(StrLayout)` TO `Str(Sym)`
File: `mock/crates/hilavitkutin-str/src/handle.rs`
`Str` becomes `#[repr(transparent)] Str(Sym)`. Delete the local `StrLayout` bitfield. Add `pub const STR_DOMAIN: SymKind` (`0b000`). `__make(id)` builds `Sym::new(STR_DOMAIN, id)` (flag 0); `__runtime(id)` sets flag 1. `is_const` becomes `kind == STR_DOMAIN && flag == 0`. `id()`, `to_bits()`, `RUNTIME_MASK`, `ID_MASK` forward to the `Sym`.
Verification: `grep -q 'pub struct Str(Sym)' mock/crates/hilavitkutin-str/src/handle.rs && ! grep -q 'struct StrLayout' mock/crates/hilavitkutin-str/src/handle.rs`.

### CHANGE: marker `StrDomain` + `impl Interner<StrDomain> for StringInterner` CREATE
File: `mock/crates/hilavitkutin-str/src/interner.rs`
`pub struct StrDomain;` with `impl Domain for StrDomain { const KIND = Str::STR_DOMAIN; }` and `impl InterningDomain for StrDomain { type Value = str; }`. `impl<A: ArenaInterner> Interner<StrDomain> for StringInterner<A>`: `intern(&str) -> Sym` (delegates to the string `intern`, returns the `Sym`), `resolve(Sym) -> Maybe<&str>` (delegates to the string `resolve`). The bespoke string-typed `intern`/`intern_static`/`resolve` methods stay.
Verification: `grep -q 'impl.*Interner<StrDomain>' mock/crates/hilavitkutin-str/src/interner.rs`.

## Tests (fail-first, strict)

### CHANGE: `mock/crates/hilavitkutin-sym/tests/` CREATE
- `sym mints only its kind`: `Generator<TestDomain>::mint` yields handles with `kind() == TestDomain::KIND`.
- `mints are distinct`: two mints yield unequal `Sym`.
- `exhaustion`: a generator seeded near the 28-bit ceiling returns `Maybe::Isnt` rather than wrapping.
- `disjointness`: a `Sym` of one kind never equals a `Sym` of another kind, regardless of id/flag.
- compile-fail (trybuild or doc): `Generator` cannot be built for an `InterningDomain`; `Interner` cannot be implemented for a `GenerativeDomain`'s producer path.
Verification: `cargo test -p hilavitkutin-sym` compiles and the intended assertions run.

- A `str_const!` handle's `to_bits()` equals the pre-refactor value for the same literal (const nibble `0b0000`); a `__runtime` handle is nibble `0b1000`.
- A minted non-string `Sym` passed to string `resolve` returns `Maybe::Isnt`.
Verification: `cargo test -p hilavitkutin-str`.

## The shape

`ArenaColumnStorage<M: MemoryProviderApi, D: Capacity = Dim<256>>`. A fixed slot table `D::Array<Maybe<ColumnSlot>>` indexed by `StoreId`. `reserve<T>` allocates `count * size_of::<T>()` bytes 64-byte aligned through the bound `MemoryProvider` (a resizing re-reserve frees the prior block first), records the slot. `column_ptr` / `column_ptr_mut` cast the recorded base. `count` reads the slot. `release` is a no-op (reader-count reclamation is a columnar-engine concern). `Drop` deallocates every live slot. `D` caps the distinct-column count, defaulting to `Dim<256>` to match the engine's `Mask256` store ceiling.

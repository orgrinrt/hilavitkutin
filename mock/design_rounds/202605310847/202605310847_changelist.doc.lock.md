# Doc changelist: order-independent RAW + cycle rejection in the plan stage

The plan-stage prose in the engine DESIGN describes step 1 as "Build DAG
from AccessMask overlap" without naming the edge direction, and step 2
as topological sort without naming the cycle outcome. The source change
this round makes RAW hazard detection order-independent (the writer
sorts before the reader regardless of registration order) and makes the
cycle path reachable from real registrations. The doc gains two
sentences so the contract a reader infers from the prose matches the
source.

registered first. WAW conflicts serialise deterministically by input

A catalogued behavioural-contract suite for the adapt subsystem (the make-or-
break properties). Each contract is one `#[ignore = "catalogue: ...; tracked
#341"]` test whose name + doc state the intended comparison; the body documents
the contract and `unimplemented!`s with the contract text, so the test fails on
run (red) until the machinery (adapt on/off toggle + `select_adapt_config` +
actuation) lands, at which point the body is filled with the real comparative
measurement and the `#[ignore]` removed. Catalogued, never lost, never softened.

The seven contracts:

- `ema_adaptation_never_degrades_balanced_workload`: adapted <= baseline * (1+eps).
- `ema_adaptation_improves_imbalanced_workload`: adapted steady-state < baseline.
- `select_adapt_config_reduces_bottleneck_phase_ema`: the bottleneck phase's EMA
  drops after re-selection.
- `morsel_rechunk_reduces_idle_ns`: tier-1 re-chunk lowers worst-core idle without
  raising total time.
- `strategy_reselect_never_regresses_throughput`: throughput non-decreasing after
  a between-frame strategy switch.
- `predictive_parking_reduces_idle_without_added_latency`: wait-tier selection cuts
  spin/park waste without raising frame latency.
- `pe_core_routing_improves_throughput_on_hot_work`: P-core routing beats uniform
  routing on a P/E machine (guarded off on uniform-core hosts).

No production source change; this round only adds the catalogued test file (and
the DESIGN note from the doc CL).

## Intent

Fix the `ArenaColumnStorage::reserve` byte-length overflow (PR #112 review finding 1): replace the unchecked `*count * size_of::<T>()` multiply with `checked_mul`, returning a new `StorageError::LengthOverflow` before any allocation. A test drives it test-first: a reserve whose byte product overflows `usize` returns the overflow error rather than allocating an undersized block.

## CHANGE: add `StorageError::LengthOverflow` and guard `reserve` with `checked_mul`
File: `mock/crates/hilavitkutin-providers/src/storage.rs`
Add a `LengthOverflow` variant to `StorageError`. In `reserve`, compute the byte length with `(*count).checked_mul(size_of::<T>())`; on `None`, return `Outcome::Err(StorageError::LengthOverflow)` before calling `allocate`. This honours the `ColumnStorage` trait rustdoc, which already names "length overflow" as a failure `Error` covers.
Verification: `grep "LengthOverflow" mock/crates/hilavitkutin-providers/src/storage.rs` returns the variant and the guard; `grep "checked_mul" mock/crates/hilavitkutin-providers/src/storage.rs` returns one match.

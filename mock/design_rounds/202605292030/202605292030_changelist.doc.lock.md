# Design changelist

Source-only round; no `*.md.tmpl` template changes. The design rationale lives in
the topic. This changelist records the intended source change so the src
changelist can claim it.

## Change

Remove `#![feature(adt_const_params)]` from the six integration test crates
(`tests/{core_assignment,plan_inputs,plan_runner,plan_types,synthesise_core_programs,dispatch_types}.rs`),
keeping `#![feature(generic_const_exprs)]` and `#![allow(incomplete_features)]`.
Correct the accompanying comment to state that the consuming crate needs only
`generic_const_exprs` to normalise the `[(); cap_size(N)]:` bounds, and that
`adt_const_params` is needed only where a `Cap` const-generic parameter is
DECLARED (the engine crate root), not where a lifted type is merely named.

`src/lib.rs` keeps both gates: the engine declares the `Cap` const params and
genuinely needs `adt_const_params`.

# Src changelist: D1d-a builder appends the WorkUnit carrier

Round `202606061446`. Scope of THIS changelist is **D1d-a only**: flip the WorkUnit accumulators from prepend to append, in lockstep, so registration order equals the carrier TYPE order. D1d-b (build-time topological-registration validation, which needs the `DependencyGraph` threaded out of `compute_execution_plan`) and D1d-c (recommended order in the `BuildError`) are the next round on this branch. The locked doc CL describes the full D1d design (append + validates); source reaches the append flip this round and the validation next, consistent with the docs-as-design model (no backticked type name is introduced that this round fails to ship).

## Why this is self-contained and behaviour-preserving

`CollectFiber::collect` (fiber_codegen.rs) writes one dispatch slot per unit at its cons-list position, and the run walk indexes those slots by `topo_order[k].0` (a `unit_meta` id). The id space equals the cons-list position because the builder grows the unit bundle and the value carrier **in lockstep** (fiber_codegen.rs:92-99). The whole dispatch path is internally consistent in cons-position space, not registration space. Flipping both accumulators from prepend to append in lockstep keeps that internal consistency: cons-position now equals registration order instead of its reverse, `topo_order` remaps as before, dispatch stays topologically correct, observable output is unchanged. The `column_dispatch` test (which registers producer-before-consumer and relied on `topo_order` to undo the prepend reversal) now sees an already-ordered carrier and stays green. No run-path or `topo_order` change is in scope here.

## CHANGE: add trait `WuAppend<P>` for the WorkUnit value carrier
File: `mock/crates/hilavitkutin-api/src/work_unit_values.rs`
New trait `WuAppend<P> { type Out; fn append(self, p: P) -> Self::Out; }` with two impls: `WuNil` appends to `WuCons<P, WuNil>`; `WuCons<H, T>` where `T: WuAppend<P>` appends to `WuCons<H, <T as WuAppend<P>>::Out>` (recurse on the tail, keep the head). Type and value in lockstep; recursive, O(N) per registration.
Verification: `grep "trait WuAppend" mock/crates/hilavitkutin-api/src/work_unit_values.rs` returns one match; `cargo test -p hilavitkutin-api` green.

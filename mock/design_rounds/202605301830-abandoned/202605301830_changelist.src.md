# Src changelist: plan-derived topological dispatch

**Round:** 202605301830
**Phase:** IMPL
**Scope:** Make `Scheduler::run` dispatch the retained WorkUnit instances in the execution plan's topological order. New `dispatch::fiber_codegen` module (the type-erased slot array + collector), two new `Scheduler` fields, a new `BuildError` variant, build-time plan computation, and the run-walk rework. Resource-only this slice. One new integration test.
**Source topic:** 202605301830_topic.c2-topo-dispatch.md (#647)
**Doc CL:** 202605301830_changelist.doc.lock.md
**Sketches:** mock/research/sketches/202605301032_topo-erased-shim-array (WORKS, the erasure mechanism), mock/research/sketches/202605301058_topo-from-generic-build (the pre-#652 GCE wall this resolves)

Slice 2 made `run()` walk the retained units in registration-list order via the slice-1 `RunFiber` recursion. This slice makes `run()` dispatch in the plan's topological order. A heterogeneous typed unit list cannot be indexed by a runtime position, so the walk goes through type erasure: the typed `WuCons` list collects once into a uniform `(erased instance pointer, monomorphised shim)` slot array, then the array is walked in the topological permutation the plan computes at `build()`. The permutation is stored on the scheduler; the slot array is rebuilt inside each `run()` from the retained units (a stored instance pointer would be self-referential). Post-#652, `compute_execution_plan<D: PlanDims>` takes a TYPE parameter and the `Scheduler` already carries `D: PlanDims = DefaultPlanDims`, so the generic `build()` computes the plan with no named-`Cap`-const argument and no `generic_const_exprs` overflow (the wall the parked round 202605301058 hit).

## CHANGE: NEW type `FiberSlot` + fns `fiber_shim` / `noop_fiber_shim` ADD
File: `mock/crates/hilavitkutin/src/dispatch/fiber_codegen.rs`
`pub type FiberSlot<A> = (*const (), fn(*const (), &A, MorselRange));` is the erased dispatch slot, pairing an erased WorkUnit-instance pointer with a monomorphised shim. `fiber_shim::<A, W, RIdx>(erased, arena, morsel)` casts `erased` back to `&W`, projects that unit's `EngineCtx` via `EngineCtx::project::<A, ColPtrNil, RIdx, Empty, Empty>(arena, &ColPtrNil, morsel)`, and runs `invoke_wu_in_fiber`; its where-clause is the slice-1 `RunFiber` per-unit bound exactly (the `for<'f>` `Ctx` GAT equality plus the two `ColPtrNil` column-projection bounds encoding the resource-only boundary). `noop_fiber_shim::<A>` is the placeholder shim filling the unused tail of the slot array (never dispatched: `run` walks only the live prefix). The single back-cast in `fiber_shim` carries a `// SAFETY:` note.
Verification: `grep "pub type FiberSlot" mock/crates/hilavitkutin/src/dispatch/fiber_codegen.rs`; `grep "fn fiber_shim" mock/crates/hilavitkutin/src/dispatch/fiber_codegen.rs`.

## CHANGE: NEW trait `CollectFiber` ADD
File: `mock/crates/hilavitkutin/src/dispatch/fiber_codegen.rs`
`pub trait CollectFiber<A, Witnesses> { fn collect(&self, out: &mut [FiberSlot<A>]); }`. Base impl `CollectFiber<A, Empty> for WuNil` is a no-op. Recursive impl `CollectFiber<A, Cons<RIdx, WTail>> for WuCons<W, Tail>` writes `out[0] = (&self.head as *const W as *const (), fiber_shim::<A, W, RIdx>)` then recurses `self.tail.collect(&mut out[1..])`. The per-unit bound mirrors the slice-1 `RunFiber` impl (`W: WorkUnit`; `A: Project<W::Read, RIdx>`; the two `ColPtrNil: ColProject<...>` resource-only bounds; the `for<'f>` `Ctx` GAT equality; `Tail: CollectFiber<A, WTail>`). One slot per unit, in list position, so the list index equals the `UnitId` index the plan assigns (the builder prepends `Wus` and the value list in lockstep).
Verification: `grep "pub trait CollectFiber" mock/crates/hilavitkutin/src/dispatch/fiber_codegen.rs`.

## CHANGE: method `Scheduler::run` FROM list-order `RunFiber` walk TO topo-order `CollectFiber` walk
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs`
`run<Witnesses>` rebuilds a `<D::Units as Capacity>::Array<FiberSlot<Arena>>` from `&self.wu_values` via `CollectFiber` (filled with `noop_fiber_shim` placeholders, then the live prefix collected), then walks `topo_order[0 .. topo_count]`, dispatching `slots[topo_order[step]]` at each step. The `WuVals: RunFiber<Arena, Witnesses>` bound becomes `WuVals: CollectFiber<Arena, Witnesses>` plus `<D::Units as Capacity>::Array<FiberSlot<Arena>>: Copy` (for the `filled` placeholder array). Resource-only carries forward; the single `(ZERO, ZERO)` morsel is unchanged. Each erased-pointer back-cast happens inside `fiber_shim` under its `// SAFETY:` note; the pointers are valid for the `&mut self` borrow because `wu_values` is not mutated during the walk.
Verification: `grep "CollectFiber" mock/crates/hilavitkutin/src/scheduler/mod.rs` returns a match in `run`'s bound; `! grep "run_fiber_walk" mock/crates/hilavitkutin/src/scheduler/mod.rs`.

## Tests

New integration test `crates/hilavitkutin/tests/scheduler_topo_dispatch.rs`: a resource-writer unit (`type Write = Cons<Resource<R>, Empty>`, `type Read = Empty`) and a resource-reader unit (`type Read = Cons<Resource<R>, Empty>`, `type Write = Empty`) registered so registration-list order disagrees with topological order. The writer is registered first and the reader second, so the builder's prepend puts the reader at list position 0 and the writer at position 1; registration-list order would dispatch reader-then-writer. The write-before-read dependency forces the plan to order writer-then-reader. The test asserts the dispatch order (observed via a `thread_local` recorder, as in `tests/scheduler_run_walk.rs`) is writer-then-reader, which fails under the slice-2 list-order walk and passes only under topological dispatch. A second case asserts a single unit dispatches once. The existing `tests/scheduler_run_walk.rs` two units have no inter-dependency, so their list and topo orders coincide and that test is unaffected.
Verification: `test -f mock/crates/hilavitkutin/tests/scheduler_topo_dispatch.rs`; `cargo test -p hilavitkutin --test scheduler_topo_dispatch`.

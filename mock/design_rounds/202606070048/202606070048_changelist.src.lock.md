## CHANGE: add `RunTrunk<A, WL>` walk
File: `mock/crates/hilavitkutin/src/dispatch/trunk_run.rs` (new)
A `pub trait RunTrunk<A, WL> { fn run(&self, bindings: &A, morsel: MorselRange); }`. Base impl `RunTrunk<A, Empty> for FiberNil` is a no-op. Recursive impl `RunTrunk<A, Cons<FW, RestWL>> for FiberCons<F, Rest>` where `F: RunFiber<A, FW>`, `Rest: RunTrunk<A, RestWL>`: runs `self.fiber.run(bindings, morsel)` then `self.rest.run(bindings, morsel)`. `#[inline]` on both `run` bodies so the delegation folds under fat LTO (no indirect call, the GATE-1 devirt discipline at the trunk level).
Verification: `grep -n 'pub trait RunTrunk' mock/crates/hilavitkutin/src/dispatch/trunk_run.rs` returns one match; `grep -c 'impl.*RunTrunk' mock/crates/hilavitkutin/src/dispatch/trunk_run.rs` returns 2.

## CHANGE: add output-equivalence integration test
File: `mock/crates/hilavitkutin/tests/trunk_run_dispatch.rs` (new)
Two schedulers over identical units (`SX`: `InX -> AX`; `SZ`: `AX -> CZ`, a RAW edge so `SZ` follows `SX`). Scheduler 1 runs the shipped flat walk via `scheduler.run()`. Scheduler 2 drives `RunTrunk` over a hand-built two-fiber trunk `FiberCons{ WuCons{SX}, FiberCons{ WuCons{SZ}, FiberNil } }` through an `#[inline(never)]` `trunk_dispatch<A, T, WL>(bindings, trunk, morsel)` harness (the sketch-A shape at trunk level), inferring the 2-deep witness cons-list with no turbofish. Both host-populate `InX[i]=i` via `__bindings()`. Assert `AX` and `CZ` columns bit-identical between the two paths and equal to the closed form (`fx`, `fz`). Fail-first: `RunTrunk` / `FiberCons` do not exist, so the file does not compile until the two changes above land.
Verification: `cargo test -p hilavitkutin --test trunk_run_dispatch` passes after the carrier + walk land; fails to compile before.

# Memory the consumer takes back, a zeroed block, and the interner's refusal

**Date:** 2026-11-20
**Phase:** topic
**Scope:** `hilavitkutin-api` memory provider and column storage contracts, `hilavitkutin-providers` column storage and memory providers, `hilavitkutin-sym` and `hilavitkutin-str` interning, the engine's os provider

loru keeps its schedulers and its store between rebuilds and reserves its record sets again on every cycle, and the stack does not let it. `ArenaColumnStorage::release` does nothing, and the one memory provider the stack ships for a consumer with no operating system, `StaticBumpMemory`, frees nothing either, so a store under it runs its buffer out on the second cycle (ticket `arenacolumnstorage_release_is_a_no_op_so_a_store_under_a_bum`). loru's WOFF2 port holds its arena 96 percent over its live peak for the same reason. The round gives the placeholder store a release that gives the block back, and adds a provider over a consumer's buffer that takes blocks back and hands them out again. Whether a record set reserved again for more keeps its records is runtime growth, which the canon rejects at present; it is asked of the maintainer in `when_a_column_s_capacity_is_reserved_and_whether_a_live_coun` and this round does not take it.

brotli wants its cells default valued, and a provider whose fresh blocks are already zero, as an anonymous mapping is, could hand them over without a write. `MemoryProviderApi` has no way to say so, so every caller writes every byte. The round adds a zeroed allocation to the contract with a default that writes the zeros, which the os provider replaces with its mapping.

`MemoryArena::arena_intern` answers a full arena with its sentinel id, as the canon has it, and `StringInterner::intern` masks that id into a handle that looks issued. Resolving it no longer reads out of bounds, but the caller never learns its string was not interned (ticket `stringinterner_masks_the_arena_s_overflow_sentinel_into_a_ha`). The round makes the refusal a value the caller sees, from the generic `Interner` trait down to the string interner and its ergonomic conversion. Whether an interner may take its capacity at run time is asked of the maintainer in `whether_an_interner_s_capacity_may_be_set_when_it_is_built_a`.

The stack has no lock primitive, and a provider that takes blocks back keeps a list several threads change. The new provider keeps a one-flag spin lock of its own, written down as a gap with a ticket, since allocation happens at build and between frames and never in the morsel loop.

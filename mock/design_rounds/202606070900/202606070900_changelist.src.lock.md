# Src changelist: GATE-2 const grouping

**Round:** 202606070900 (topic: gate2-const-grouping)
**Phase:** IMPL
**Scope:** `mock/crates/hilavitkutin/src/plan/` (new `grouping.rs` + `mod.rs` re-export) and a unit test.

Computes the GATE-2 grouping (per-unit phase + within-phase trunk) at compile time from the registered work-unit bundle, as a const-evaluable structure the later const-gated dispatch walk indexes. Proven end to end: const-trait fold + const-fn grouping (sketch `202606070800`), real `MaskProject` fold with threaded witness list (sketch `202606070950` = gap a closed), canonical phase + within-phase-component const fns (sketch `202606071330`).

The grouping is keyed by the bundle types `(Wus, Stores, Witnesses)`. `Witnesses` is the per-unit projection-index list threaded from `build()` / `run()` exactly as `compute_plan` threads `BWit` and `run` threads `Witnesses` (so the grouping is a concrete const at the dispatch gate). This round computes the grouping only; re-pointing `Scheduler::run` through the const-gated walk is the next round.

## CHANGE: add module `plan::grouping`
File: `mock/crates/hilavitkutin/src/plan/grouping.rs` (new)
Verification: `test -f mock/crates/hilavitkutin/src/plan/grouping.rs && grep -q "pub trait Grouped" mock/crates/hilavitkutin/src/plan/grouping.rs`

Contents:
- `const trait BundleMasks<Stores, Witnesses, CS: Capacity>` with `fn fill(reads, writes, idx) -> USize`, folding a `WorkUnitBundle` (`Cons<W, T>` / `Empty`) into two fixed-capacity unit-indexed mask arrays via the existing const `MaskProject` (`plan::project`). The `Cons<W, T>` impl bounds `W: WorkUnit`, `W::Read: [const] MaskProject<Stores, RI, CS>`, `W::Write: [const] MaskProject<Stores, WI, CS>`, `T: [const] BundleMasks<Stores, WT, CS>`, threading `Witnesses = Cons<(RI, WI), WT>`. Each unit writes `reads[idx] = project_mask(empty).raw()`, `writes[idx] = ...`, recursing `idx + 1`. This is the const analog of the existing runtime `BundleProject`.
- `const fn compute_phase(reads, writes, n) -> ...` and `const fn compute_trunks(reads, writes, phase, n) -> ...` over the mask arrays: phase = longest read-after-write dependency depth (edge `i -> j` when `reads[j] & writes[i] != 0`); trunk = within-phase column-disjoint component (two same-phase units sharing any accessed column are one trunk), canonicalised to a component id. Ported from the proven sketch `202606071330` const fns.
- `pub trait Grouped<Stores, Witnesses, CS: Capacity>` with associated consts `const N: USize`, `const PHASE: <unit-capacity array of phase ids>`, `const TRUNK: <unit-capacity array of trunk ids>`, blanket-impl for any `Wus: [const] BundleMasks<...>`, the associated consts computed by running the fold then the two const fns. Mask/array storage uses the unit capacity (`Capacity::Array` or a fixed-cap array sized by the plan unit cap), filling the first `N` slots, mirroring `PlanInputs`.
- `pub const fn phase_of` / `pub const fn trunk_of` keyed by `(Wus, Stores, Witnesses, CU, CS)` indexing the associated consts (indexing in a const fn, not a `const {}` block).

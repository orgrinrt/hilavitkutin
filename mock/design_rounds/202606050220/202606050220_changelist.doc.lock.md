# Doc changelist: morsel-outer dispatch when accumulator-free

**Date:** 2026-06-05
**Phase:** DOC
**Round:** 202606050220 (single-core-dispatch-completion, branch `feat/hilavitkutin-single-core-dispatch`)

One prose edit in the engine design doc so the `Scheduler::run` description matches the windowing nesting the src changelist lands. The doc currently states dispatch is unit-outer (a unit completes its record range before the next unit runs) with the per-fiber morsel loop named as a later arc. The src changelist makes the nesting morsel-outer (one morsel runs the whole unit sequence before the next morsel) when the pipeline writes no accumulator, the case in which every cross-unit dependency is morsel-local by construction so morsel-outer is sound; it stays unit-outer when the pipeline writes accumulators (a cross-record surface), which is the safe form there.

## `mock/crates/hilavitkutin/DESIGN.md.tmpl`

The `Scheduler::run` overview paragraph (the one describing the topological-order windowed dispatch) states the nesting is unit-outer unconditionally and that "the per-fiber, phase-sequential morsel loop is a later arc." Update it to state that the nesting is chosen by whether the pipeline writes any accumulator: accumulator-free pipelines (every cross-unit dependency morsel-local, since the per-record `read`/`write` accessors are morsel-relative and the only cross-record surface is the accumulator append path) dispatch morsel-outer, one morsel running the whole unit sequence before the next so intermediate columns stay cache-resident; pipelines that write accumulators stay unit-outer, the cross-record-safe form. Note that the accumulator-free decision is whole-pipeline this round (derived from the bundle's `AccumWrite` projection) and that per-fiber accumulator-granular windowing, where an accumulator-bearing pipeline still dispatches its accumulator-free fibers morsel-outer, remains the later arc. Name `RunCfg::MORSEL_SIZE` so the design-doc-source-mismatch lint ties it to the existing const; do not introduce backticked names that have no source counterpart this round.

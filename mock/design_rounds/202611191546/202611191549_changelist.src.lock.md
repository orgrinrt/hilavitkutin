# src changelist

Round topic `202611191546_topic.api-placement-second-review-fixes.md`; the doc changelist is `202611191546_changelist.doc.lock.md`. The flat topic `202611191521_topic.b1-cap-lifting-completion.md` changes no source here.

## Current state

`Executor` takes the engine's seal `EngineOnly`, `HybridExecutor` implements the seal, and `tests/ui/executor_outside_the_engine_fail.rs` pins that a consumer's executor is refused. No fixture names the seal's module, so making it public would leave every seal fixture's stderr unchanged. `FiberId` and `UnitId` carry no `ADDRESSABLE`, and `tests/engine_id_index.rs` walks them by hand-written widths. `CeilingDiv`'s rustdoc gives `(N + D - 1) / D`, and a zero divisor is untested.

## Changes proposed

### 1. The executor is open

`thread/hybrid.rs`: `Executor` has no supertrait, `HybridExecutor` no seal impl, and the trait's rustdoc states what an executor holds: Release on the phase-arrival and progress counters it publishes, Acquire where it reads them, the shutdown flag observed between morsels. The seal's rustdoc in `lib.rs` says it closes the codegen traits only. `tests/ui/executor_outside_the_engine_fail.rs` becomes `executor_outside_the_engine_pass.rs`, a consumer's `StealingExecutor` that builds and is passed where an `Executor` is taken, and its stderr goes.

### 2. The seal's module is tested

`tests/ui/engine_seal_is_private_fail.rs` names `hilavitkutin::sealed::EngineOnly` and is refused with E0603, module `sealed` is private; it would build if the module were made public, which the two codegen fixtures cannot tell.

### 3. Every id has its bound

`dispatch/codegen.rs`: `FiberId::ADDRESSABLE` (2^7) and `UnitId::ADDRESSABLE` (2^16), each in a block of its own as `PhaseId`'s and `TrunkId`'s are. `tests/engine_id_index.rs` walks all four ids up to their own `ADDRESSABLE`.

### 4. `CeilingDiv` as computed

`plan/ceiling_div.rs` documents the result as `N.div_ceil(D)` and says a zero `D` fails the build where the constant is read; `tests/ui/ceiling_div_by_zero_fail.rs` reads `<Ceil<8, 0> as CeilingDiv<8, 0>>::RESULT` and is refused with E0080, divide by zero.

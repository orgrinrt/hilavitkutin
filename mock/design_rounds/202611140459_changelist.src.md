# src changelist

Round topic `202611140457_topic.suite-as-an-instrument.md`, under the doc changelist `202611140459_changelist.doc.lock.md`. The flat `202607200100_topic.b1-cap-lifting-completion.md` stays flat: nothing here touches the scheduler's scratch arrays.

## Current state

On `f0304be0` the engine, api and providers print 24 warnings under `cargo check --all-targets`, and the api carries eight local seal modules, each with a `private_bounds` allow, beside the one `sealed` module at `hilavitkutin-api/src/lib.rs`. `src/resource/bindings/mod.rs` is over 500 lines. `tests/gate2_run_parallel.rs` is 881 lines over four fixtures. The unregistered-store pass twins discard the build, the six store-only smokes in `tests/scheduler_builder.rs` cannot fail, and `tests/loom_atomics.rs` never compiles.

## Changes

1. `hilavitkutin-api`: `accum_overflow`, `adapt`, `builder`, `dispatch_codegen`, `hint`, `meta`, `run_cfg` and `store_values` take `crate::sealed` in place of their local seals, and every `private_bounds` allow goes, `platform.rs`'s too. `store_values.rs` loses the `dead_code` allow on `Sv`, `lib.rs` its `incomplete_features` allow, and the tests `column_value.rs` and `engine_id_index.rs` the `adt_const_params` and `generic_const_exprs` gates they do not use.
2. `hilavitkutin/src/adapt/arena.rs` is removed with its `pub mod`, as the doc changelist says.
3. `hilavitkutin/src/resource/bindings/mod.rs` keeps the traits and the empty-list impls, and the resource, accumulator and virtual bindings move to `resource.rs`, `accum.rs` and `virt.rs` beside `column.rs`. No signature changes.
4. `tests/gate2_run_parallel.rs` splits into itself (the fan-in), `gate2_run_parallel_three_trunks.rs`, `gate2_run_parallel_two_waists.rs` and `gate2_run_parallel_participation.rs`, sharing `tests/run_parallel/{arena,producers,producer_c}.rs`. The spawn-once test asserts both frames' outcomes.
5. `tests/ui`: the unregistered-store pass twins build, run a frame and assert its outcome, with the run witnesses inferred, and their headers describe the pass side. `assert_out_names_no_refusal_pass.rs` drops the `AccumRefused` it does not use. The fail `.stderr` files move only in context.
6. `tests/scheduler_builder.rs`: the six store-only smokes read back a resource value, a column's records, or the position a kit's stores push a column to; `kit_declarative_shape_typechecks` is removed.
7. The engine tests read back what their units write instead of carrying never-read fields; `FixedWorkers` moves from `tests/common` to `tests/fixed_workers` for the six tests that use it; unused imports and `r3c`'s unused `CAP` go. `tests/loom_atomics.rs` is removed: it asserted nothing, and the backlog keeps loom stress testing.
8. `tests/r6_morsel_window_formula.rs`: the ignored `non_aligned_min_morsel_keeps_the_floor` gets a body and stays ignored on its catalogue ticket. It is red as catalogued (a floor of 66 yields a window of 64); the fix is in `plan/`.
9. `hilavitkutin-api-macros/tests/derive_resource_footprint.rs` and `hilavitkutin-extensions/tests/descriptor_validation.rs` lose their `dead_code` allows: the first reads its fixtures' fields, the second drops a witness function and the imports only it named.

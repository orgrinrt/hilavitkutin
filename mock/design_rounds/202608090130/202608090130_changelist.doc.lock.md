# Doc changelist: the origin mechanism

**Phase:** DOC
**Topic:** `202608090130_topic.the-origin-mechanism-round-one-only-named.md`
**Scope:** `mock/crates/hilavitkutin-sym/DESIGN.md.tmpl`.

The previous round's design document already specifies the origin mechanism. It
was correct as design and wrong only in that no code answered it. So this
changelist does not rewrite that specification; it sharpens it to what the
implementation actually provides and removes the one paragraph that described a
workaround now deleted.

## CHANGE: the `SymShape` section

State that a shape supplies more than widths: the origin type, where a minter's
counter starts and stops, and how a counter projects into the id field. Say that
the projection lives with the shape because the shape decides how wide the field
is.

State that `SymShape` is a const trait, so a handle builds in a const context
under any shape, and that a domain declares which shape it belongs to. Remove
nothing about the widths; this is an addition.

## CHANGE: the shape list

`Standard` keeps its description unchanged. Add `SixteenMinters` beside it, and
say plainly that it exists so the trait has a real second implementation.

## CHANGE: the origins section

Sharpen "origins partition the counter space" into what the code does: each
origin starts at its own base and stops at its own ceiling, so two minters cannot
collide however far either counts, and a minter that exhausts its range refuses
rather than walking into its neighbour's.

Name the two constructors. `Generator::single` for a one-origin shape, taking no
argument because there is nothing to choose. `Generator::at` for every other,
and under a multi-origin shape it is the only way in.

## CHANGE: remove the const-shim paragraph

The previous round documented `*_const` methods on the default shape as the
route to const construction, on the reading that a generic const path was
unavailable. That reading was wrong: making `SymShape` a const trait gives the
generic path, and the shim is deleted. The paragraph goes with it.

## Lock criteria

- The design document describes the mechanism that exists, with no sentence
  specifying behaviour the source does not have.
- Every backticked name in it exists in source, checked by grep rather than by
  reading.
- Nothing in it references the deleted `*_const` surface.

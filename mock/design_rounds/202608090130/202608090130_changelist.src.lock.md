# Source changelist: the origin mechanism

**Phase:** IMPL
**Doc changelist:** `202608090130_changelist.doc.lock.md`
**Scope:** `mock/crates/hilavitkutin-sym/src/**`, `tests/**`,
`mock/crates/hilavitkutin-str/src/**`.

Every verification below is run before this changelist locks, and its output
recorded. The previous round's changelist stated verifications and never ran
them, which is how three of its claims were false at lock.

## CHANGE: `SymShape` FROM a plain trait TO a const trait carrying the id space

File: `src/shape.rs`

Gains `type Origin`, `origin_base`, `origin_ceiling` and `id_from_counter`. The
counter-to-id projection moves here from the generator, because a shape decides
how wide its id field is.

`pub const trait SymShape` with `type Layout: [const] SymLayoutOps`, which is
what makes construction const under every shape.

Verification: `grep -c 'pub const trait SymShape' src/shape.rs` returns 1.

## CHANGE: new `SixteenMinters` and `MinterId`, a second real shape

File: `src/shape.rs`

Four bits naming which of sixteen minters produced a handle, twenty-four
counting within it. Exists so the trait has an implementation other than the
default, and so disjointness is testable rather than asserted.

Verification: `grep -c 'impl const SymShape for SixteenMinters' src/shape.rs`
returns 1.

## CHANGE: `Domain` gains `type Shape`

File: `src/domain.rs`

Declared, not defaulted: `associated_type_defaults` is forbidden and the
compiler refused it when reached for. `const KIND` becomes
`SymKind<Self::Shape>`, so a domain of one shape cannot hand its tag to a
producer of another.

Verification: `grep -c 'type Shape' src/domain.rs` returns 1.

## CHANGE: `Generator` FROM a zero-seeded counter TO an origin-bounded one

File: `src/generator.rs`

Gains a `ceiling` field. `Generator::at(origin)` is the general constructor,
seeding from the shape's base and stopping at the shape's ceiling.
`Generator::single` exists only for a one-origin shape and takes no argument.
`mint` returns `Sym<D::Shape>` and exhausts at the origin's ceiling rather than
the whole id space.

Verification: `grep -c 'pub fn at(origin' src/generator.rs` returns 1, and
`grep -c 'ceiling' src/generator.rs` is nonzero.

## CHANGE: the `*_const` shim is deleted

Files: `src/handle.rs`, `hilavitkutin-str/src/handle.rs`

The previous round added `new_const`, `to_bits_const`, `with_flag_const`,
`id_const`, `kind_const` and `flag_const` on the default shape, on the reading
that a generic const path was unavailable. Making `SymShape` const gives the
generic path, so the shim goes and `hilavitkutin-str` returns to the plain
names.

Verification: `grep -cE 'new_const|to_bits_const|with_flag_const|id_const|kind_const|flag_const'` returns 0 in both files. Named precisely, because a loose `_const` pattern also matches the string domain's own `str_const!` and `is_const`, which are unrelated and stay.

## CHANGE: `tests/origins.rs` replaced

File: `tests/origins.rs`

The two tests that could not fail are **deleted, not repaired**: one asserted a
constant against the literal defining it, and the other asserted that two
generators still collide, so fixing the defect would have broken it.

What replaces them: two origins never collide over sixty-four mints each; all
sixteen origins are pairwise disjoint; a minter exhausts at its own ceiling
rather than walking into the next range, verified by walking the full span.

Verification: collapse `origin_base` to a constant zero, rerun, and the two
disjointness tests must fail. Restore, rerun, and all must pass.

- `cargo test` green across the workspace.

# Doc changelist: per-fiber morsel windows on the parallel dispatch path

**Date:** 2026-07-19
**Phase:** DOC
**Topic:** `202607190910_topic.a4-parallel-per-fiber-windows.md`

## Scope

One file. The parallel-dispatch paragraph in the engine crate's design doc describes
the core-aware trunk walk but says nothing about how the record range is windowed, which
was accurate while the parallel path used a single scalar window and stops being accurate
once each fiber walks its own. The single-core statements at `:265-275` and `:1144-1145`
already describe per-fiber windowing and are correctly scoped to `run`; they need no
change.

## File: `mock/crates/hilavitkutin/DESIGN.md.tmpl`

**CHANGE: the parallel-dispatch paragraph (`:283-294`) gains the windowing shape.**

Current text describes the core-aware walk (rank modulo core count, non-owned trunk
bodies dead-code-eliminated) and then jumps to the head+tail branch. It states the
ownership rule without stating what range each dispatch covers.

Add, after the ownership sentence and before the head+tail sentence: the worker's
per-phase walk is fiber-outer, matching `run`. For each fiber descriptor in plan order,
the worker restricts the walk to that fiber's members and windows `[0, record_count)` by
that fiber's plan-baked `FiberDispatch.morsel_size`, so a fiber's units run over one
morsel before the next and its co-located columns stay L1-hot for the window run, on
every core rather than only on the single-core path. `RunCfg::MORSEL_SIZE` remains the
fallback for a degenerate zero window. Trunk-rank ownership is unchanged by this: the
rank advance is independent of the member restriction, so each core owns the same trunks
in every per-fiber walk.

Amend the head+tail sentence to say that branch keeps the scalar window, because it
dispatches over a whole-phase mask rather than one fiber, so a per-fiber window does not
apply to it.

Verification: `grep -c "fiber-outer" mock/crates/hilavitkutin/DESIGN.md.tmpl` increases,
and the parallel paragraph names both `FiberDispatch.morsel_size` and the head+tail
scalar exception.

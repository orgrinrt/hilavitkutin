# every-swap-fixture-field-is-read

**Date:** 2026-11-13
**Phase:** TOPIC
**Scope:** the seven `#[allow(dead_code)]` attributes that `work/recover-landing-swap` adds over `dev`, in one bench variant crate and two engine tests.
**Source:** the landing tool's refusal of the branch at `f668003`, relayed by the coordinator.

The landing refuses a branch that adds a suppression, and the swap branch adds seven. Round `202611131325` took the same class out of the part of the recovery that is on `dev` now, five attributes in four files. The swap slice was cut before that round and carries its own fixtures, so the same thing is still here in the files only this branch has.

The reasoning of that round holds unchanged. A record type whose one field is written and never read gets the attribute because the compiler says so, and what the attribute hides is that the test never looks at the column its unit fills. In a library crate with public types it hides nothing, since the compiler does not report a public field.

So none of the seven stays. Where a column is filled and never looked at, the test poisons it, runs the frame and holds every record to what the unit wrote. That is a check each test lacked: all three rest on a unit having been dispatched over the records, and none of them showed it. Where the attribute does nothing, it goes.

The class is every `allow` or `expect` attribute the branch adds over `dev`. A search of the branch's diff against `dev` for added lines carrying one finds these seven and no other.

## The seven

- `mock/benches/variants/swap_common/src/lib.rs`, `C1`, `C2`, `C3` and `Cp`: each a `pub struct` with a `pub` field in a library crate. The attribute is removed and the crate must build without a warning.
- `mock/crates/hilavitkutin/tests/replace_swap.rs`, `Out`: `FillWu` writes the record index into its column and nothing looks. The band test poisons the column before the cold frame and afterwards holds every record to its index, so the carrier the band decisions are read on is shown to have dispatched.
- `mock/crates/hilavitkutin/tests/replace_swap.rs`, `ZOut`: the unit reading the zero-sized resource writes the record index into its column, and the test counts its executions only. The test poisons the column before the swap and holds every record to its index after the frame that follows, so the swap is shown to make the reader cover its records again and not only be entered.
- `mock/crates/hilavitkutin/tests/replace_swap_plan_band.rs`, `Av`: `ConsumerWu` writes 7 to every record so that the carrier is record-bearing, and nothing looks. Each arm poisons the column before its cold frame and holds every record to 7 after it, on `run` and on `run_parallel`.

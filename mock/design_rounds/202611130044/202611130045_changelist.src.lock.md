## CHANGE: the run_fused append hole is a committed test
Files: `mock/crates/hilavitkutin/tests/fused_append.rs`, `mock/catalogue.md`.
The ignore is the ledger form the `catalogue-ignore` lint reads, `catalogue: <the gap>; tracked #<id>`, and `mock/catalogue.md` gains the row for the ticket (`run_fused_does_not_refuse_a_recordop_unit_that_writes_an_acc`, short id `0fb716c5a463`).
One unit implements `RecordOp` and also appends one `Log` value per record. `run_appends_one_value_per_record_each_frame` runs two frames through `run` and asserts the live length and the appended values. `run_fused_appends_one_value_per_record_each_frame` asserts the same live length through `run_fused`; it fails today (`left: USize(0)`, `right: USize(2)` at frame 0) because the fused unit runs only the map, and is ignored with ticket `0fb716c5a463`. H25 is reported ticketed, not closed.
Verification: `cargo test -p hilavitkutin --test fused_append -- --include-ignored` shows the first test passing and the second failing with the numbers above; without `--include-ignored` the second is reported ignored.

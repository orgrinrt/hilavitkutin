# notko-by-https

**Date:** 2026-11-13
**Phase:** TOPIC
**Scope:** how the workspace manifest spells the notko git source. A manifest spelling, not a design change.
**Origin:** the roadmap step HV0 for building kaski's engine on the stack's contracts.

## Why the spelling matters

Cargo keys a git source by its URL as written. kaski names notko by `https` and this workspace names it by `ssh`. The day kaski depends on a hilavitkutin crate, one dependency graph would hold two notko packages, and a type from one is not a type from the other. That matters most for the list types in `notko-hlist`, where a list built with one notko is not the list the other expects. Every repository involved is public, so `https` does not hang the way it does for a private one.

## What the lock says today

`mock/Cargo.lock` holds exactly one `notko` package, with the source `git+ssh://git@github.com/orgrinrt/notko.git?branch=dev#1a978e5c2db6c8f68bf94a6fcae266394f172b17`. It holds no `notko-hlist` package. The ten arvo entries are pinned at `1b2796e92ad2b8176c2177d72a9cffa161b7b92e` and stay on the `ssh` spelling in this round.

At that arvo rev, the workspace manifest of arvo declares `notko = { git = "ssh://git@github.com/orgrinrt/notko.git", branch = "dev", ... }`, and nine arvo crates take it with `notko.workspace = true`. None of them names `notko-hlist`. So moving only this workspace's line to `https` would leave the old arvo crates on the `ssh` source and the lock with two notko packages.

## The proposed manifest change

The `notko` line in `[workspace.dependencies]` takes the `https` spelling, with the same branch, version and features. A `[patch."ssh://git@github.com/orgrinrt/notko.git"]` section points `notko` at the same `https` source, so the old arvo crates resolve to the one package. Only `notko` is patched, since nothing at the pinned arvo rev names `notko-hlist`.

Whether a patch unifies two spellings of one repository is untested here. If cargo refuses, its words are recorded in this file and the lock is left as it was.

## What stays

The arvo entries keep their `rev` and their `ssh` spelling, since another job moves arvo's own manifests. Sketches under `mock/research/sketches/` with a manifest of their own are left alone.

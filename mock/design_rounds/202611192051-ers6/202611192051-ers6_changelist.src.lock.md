# src changelist

Round topic `202611192051-ers6_topic.interner-deduplicates.md`; the doc changelist is `202611192051-ers6_changelist.doc.lock.md`. It replaces `202611192051-ers6_changelist.src.deprecated.md`.

## Current state

`MemoryArena::arena_intern` (`hilavitkutin-providers/src/interner.rs`) deduplicates by a length-then-bytes scan, `arena_resolve` reads only ids below the live count, and `MemoryArena::new` reads `ENTRIES_FIT_THE_ID`, which asserts `ENTRIES <= 1 << 28`. At `ENTRIES = 1 << 28` the last slot's id is `0x0FFF_FFFF`, the value the `u32::MAX` sentinel takes once `StringInterner` masks it to 28 bits, so an overflow handle would resolve to that slot's string. `tests/ui/memory_arena_entries_past_the_id_width_fail.rs` asks only `(1 << 28) + 1`.

## Changes proposed

### 1. The arena contract states the law

`hilavitkutin-str/src/interner.rs`: the rustdoc of `ArenaInterner`, `arena_intern` and `arena_resolve` states the law as the doc changelist puts it, and `StringInterner::intern`'s says a runtime string is deduplicated by the arena. No signature changes.

### 2. `MemoryArena` deduplicates and checks the id

`hilavitkutin-providers/src/interner.rs`: `arena_intern` scans entries `0..count` for one whose `len` equals the string's and whose bytes equal it, reading each by pointer as the rest of the arena does, and returns that index; otherwise it appends as before. `arena_resolve` returns `""` for any id at or past `count`, the sentinel included, before it reads the table. `MemoryArena::ENTRIES_FIT_THE_ID` asserts `ENTRIES < 1 << 28`, so every issued id stays below the masked sentinel, and its message, the rustdoc of the type and of `new` say so.

### 3. Tests

The deduplication test in `hilavitkutin-str/tests/interner.rs` is deleted: it proves its fixture. `hilavitkutin-providers/tests/interner_law.rs` asks the shipped arena: one string interned twice gives one id at the arena and one handle through `InternerApi::intern` and `Interner::<StrDomain>::intern`, and distinct strings stay distinct, with the empty string and a const string among them; an `ENTRIES = 1` arena deduplicates a repeat without overflowing; the overflow handle through the default interner resolves to `Maybe::Is("")` and every handle issued before it still resolves to its string; a handle issued by a larger arena resolves to `""` in a smaller one. `hilavitkutin-providers/tests/ui.rs` with `tests/ui/memory_arena_entries_past_the_id_width_fail.rs`: an arena of exactly `1 << 28` entries, the first size whose last id is the masked sentinel, is refused at build. `hilavitkutin-providers/Cargo.toml` gains two dev-dependencies: `trybuild = "1"`, the version the api crate takes, and `hilavitkutin-sym` from the workspace, for the `Interner` trait the law is asked through. Each new test is shown failing against the arena as it was before the change.

## Comparison to deprecated changelist

The deprecated changelist bounded `ENTRIES <= 1 << 28` and had the compile-fail fixture ask `(1 << 28) + 1`. This one bounds `ENTRIES < 1 << 28`, because at `1 << 28` the last id equals the masked sentinel and an overflow handle would alias a held string, and the fixture asks `1 << 28`, the boundary itself. Sections 1 and 3 are otherwise unchanged, and the deduplication and resolve checks of section 2 stand as written there and committed in d96a2192.

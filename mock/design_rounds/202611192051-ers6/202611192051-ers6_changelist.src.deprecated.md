# src changelist

Round topic `202611192051-ers6_topic.interner-deduplicates.md`; the doc changelist is `202611192051-ers6_changelist.doc.lock.md`.

## Current state

`MemoryArena::arena_intern` (`hilavitkutin-providers/src/interner.rs`) appends every string it is given, so equal strings get distinct ids. `arena_resolve` compares the id against `u32::MAX` and otherwise reads the entry at that index with no bound check; the sentinel reaches it masked to `0x0FFF_FFFF`, so it reads past the table. Nothing bounds `ENTRIES`. `hilavitkutin-str/tests/interner.rs` `runtime_intern_dedups` asserts deduplication over its own `VecInterner`, which does it; no test asks a shipped type.

## Changes proposed

### 1. The arena contract states the law

`hilavitkutin-str/src/interner.rs`: the rustdoc of `ArenaInterner`, `arena_intern` and `arena_resolve` states the law as the doc changelist puts it, and `StringInterner::intern`'s says a runtime string is deduplicated by the arena. No signature changes.

### 2. `MemoryArena` deduplicates and checks the id

`hilavitkutin-providers/src/interner.rs`: `arena_intern` scans entries `0..count` for one whose `len` equals the string's and whose bytes equal it, reading each by pointer as the rest of the arena does, and returns that index; otherwise it appends as before. `arena_resolve` returns `""` for any id at or past `count`, the sentinel included, before it reads the table. `MemoryArena::new` reads an associated const that asserts `ENTRIES <= 1 << 28`, so a larger arena fails the build. The type's rustdoc says what it now holds.

### 3. Tests

The deduplication test in `hilavitkutin-str/tests/interner.rs` is deleted: it proves its fixture. `hilavitkutin-providers/tests/interner_law.rs` asks the shipped arena: one string interned twice gives one id at the arena and one handle through `InternerApi::intern` and `Interner::<StrDomain>::intern`, and distinct strings stay distinct, with the empty string and a const string among them; an `ENTRIES = 1` arena deduplicates a repeat without overflowing; the overflow handle through the default interner resolves to `Maybe::Is("")` and every handle issued before it still resolves to its string; a handle issued by a larger arena resolves to `""` in a smaller one. `hilavitkutin-providers/tests/ui.rs` with `tests/ui/memory_arena_entries_past_the_id_width_fail.rs`: an arena of `(1 << 28) + 1` entries is refused at build. `hilavitkutin-providers/Cargo.toml` gains two dev-dependencies: `trybuild = "1"`, the version the api crate takes, and `hilavitkutin-sym` from the workspace, for the `Interner` trait the law is asked through. Each new test is shown failing against the arena as it was before the change.

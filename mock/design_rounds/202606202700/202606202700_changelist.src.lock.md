## CHANGE: `compute_plan` applies the per-fiber L1 morsel-window formula
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs`
Verification: `grep "l1_usable\|store_sizes::<Stores" mock/crates/hilavitkutin/src/scheduler/mod.rs` finds the params + the size-array call.

Adds 3 `USize` params + a `Stores: StoreSizes<..Stores>` bound; after the plan
returns Ok, overwrites `plan.morsel_windows` per fiber via the write-mask union
(`inputs.writes[fib.units[k].index().0]`) + `store_sizes` sum + the clamp/round
formula. Two callers pass `<DefaultRunCfg as RunCfg>::L1_USABLE` etc.

## CHANGE: flip `tests/r6_morsel_window_formula.rs` from catalogue-red to live
File: `mock/crates/hilavitkutin/tests/r6_morsel_window_formula.rs`
Verification: `cargo test -p hilavitkutin --test r6_morsel_window_formula` passes (no longer `#[ignore]`).

A carrier with `record_count > MAX_MORSEL` and a known write footprint asserts the

## CHANGE: refine `StoreElemBytes` to per-record columns only
File: `mock/crates/hilavitkutin/src/plan/project.rs`
Verification: `grep "impl<T> StoreElemBytes for Resource" mock/crates/hilavitkutin/src/plan/project.rs` (no ColumnValue bound).

Only `Column<T: ColumnValue>` contributes its element bytes to the per-record
morsel working set. `Resource`/`StagedResource` are singletons, `Accum` fibers
dispatch unit-outer (no morsel window), `Virtual` is fired: all four contribute
`USize::ZERO` with NO `ColumnValue` bound, so a `Resource<T>` over a
non-ColumnValue provider/interner still satisfies `StoreSizes`. (A3a had bounded
all four on ColumnValue, which broke real carriers; A3b corrects it.)

## CHANGE: update a1 + a3a test values for the real window
Files: `mock/crates/hilavitkutin/tests/a1_fiber_morsel_size.rs`, `tests/a3a_store_sizes.rs`

a1: `morsel_size` for a single 4-byte-column fiber is now the L1 window 6144 (was
the placeholder partition 4). a3a: a `Resource` store contributes 0 per-record

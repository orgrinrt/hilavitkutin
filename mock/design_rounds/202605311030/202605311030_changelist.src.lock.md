# Source changelist

Wire the plan's topological permutation into `Scheduler::run`. A new
type-erased slot walk (`CollectFiber`) records one dispatch slot per retained
unit; `build` computes the plan and stores the permutation; `run` walks it.
`RunFiber` / `run_fiber_walk` stay (slice-1 primitive plus its test). TDD: the
reorder test is written and confirmed red against the current registration
walk before the dispatch wiring lands.

## CHANGE: new module `dispatch/fiber_codegen.rs` with trait `CollectFiber` and type `FiberSlot`
File: `mock/crates/hilavitkutin/src/dispatch/fiber_codegen.rs`
- `pub type FiberSlot<A> = (*const (), fn(*const (), &A, MorselRange))`: an
  erased instance pointer plus a per-unit shim. `Copy`.
- `pub fn noop_fiber_shim<A>(_: *const (), _: &A, _: MorselRange)`: placeholder
  for unused tail slots, never dispatched.
- `pub trait CollectFiber<A, Witnesses> { fn collect(&self, slots: &mut [FiberSlot<A>]); }`
  with a `WuNil` base impl and a `WuCons<W, Tail>` recursive impl whose bounds
  mirror `RunFiber` (resource-only: `A: Project<W::Read, RIdx>`,
  `ColPtrNil: ColProject<W::Read/W::Write, Empty, Out = ColPtrNil>`, the
  `for<'f> W: WorkUnit<Ctx<'f> = EngineCtx<...>>` tie). The recursive impl
  writes the head's `(erased ptr, fiber_shim::<W, A, RIdx>)` into the first
  slot and recurses on the tail.
- private `fiber_shim::<W, A, RIdx>`: casts the erased ptr back to `&W`,
  projects the unit's `EngineCtx` (body identical to `RunFiber::run`), runs
  `invoke_wu_in_fiber`. Carries the `// SAFETY:` note for the back-cast.
Verification: `grep "pub trait CollectFiber" src/dispatch/fiber_codegen.rs`
and `grep "pub type FiberSlot" src/dispatch/fiber_codegen.rs` each return one
match; `cargo test -p hilavitkutin` builds.

## CHANGE: add `RunPhase`, `RunPipeline`, and the degenerate waist barrier
File: `mock/crates/hilavitkutin/src/dispatch/phase_run.rs` (new)
`pub trait RunPhase<A, WL> { fn run(&self, bindings: &A, morsel: MorselRange); }` with a no-op `RunPhase<A, Empty> for TrunkNil` and a recursive `RunPhase<A, Cons<TW, RestWL>> for TrunkCons<T, Rest>` where `T: RunTrunk<A, TW>`, `Rest: RunPhase<A, RestWL>`, delegating each trunk to `RunTrunk::run` then recursing. `pub trait RunPipeline<A, WL> { fn run(&self, bindings: &A, morsel: MorselRange, barrier: &AtomicUsize, expected: USize); }` with a no-op `RunPipeline<A, Empty> for PhaseNil` and a recursive `RunPipeline<A, Cons<PW, RestWL>> for PhaseCons<P, Rest>` where `P: RunPhase<A, PW>`, `Rest: RunPipeline<A, RestWL>`, running the phase, calling `waist_barrier(barrier, expected)`, then recursing. A `fn waist_barrier(counter: &AtomicUsize, expected: USize)` degenerate one-arriver (release `fetch_add`, spin only when `arrived < expected`), the same atomic-op `lint:allow(no-bare-numeric)` pattern `thread::barrier.rs` uses (tracked #121); never spins at `expected == 1`. All `run` bodies `#[inline]`.
Verification: `grep -cE 'pub trait (RunPhase|RunPipeline)' mock/crates/hilavitkutin/src/dispatch/phase_run.rs` returns 2; `grep -c 'fn waist_barrier' mock/crates/hilavitkutin/src/dispatch/phase_run.rs` returns 1.

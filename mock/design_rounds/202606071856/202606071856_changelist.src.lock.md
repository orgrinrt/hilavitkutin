# Source changelist: gate2 head+tail convergence

**Round:** 202606071834 (gate2-head-tail-convergence)
**Phase:** SRC

Single-trunk waist-bounded phases currently run on one core while the rest idle.
Split the single trunk's record range across all cores (head+tail convergence,
spec `:770`). Safe without a commutativity check: `run_parallel` dispatches only
the morsel-local pure-RAW path today (accumulators are the unbuilt §9 threaded
path), and morsel-local work is record-independent. Composes with §4: every
core still hits `waist_barrier(ncores)` at the phase end.

## CHANGE: fn `phase_trunk_count` ADD
File: `mock/crates/hilavitkutin/src/dispatch/core_mask.rs`
Verification: `grep "pub fn phase_trunk_count" mock/crates/hilavitkutin/src/dispatch/core_mask.rs` returns one match. Counts trunk roots in a phase: units `u` with `phase[u]==p && trunk[u]==u`.

## CHANGE: fn `phase_mask` ADD
File: `mock/crates/hilavitkutin/src/dispatch/core_mask.rs`
Verification: `grep "pub fn phase_mask" mock/crates/hilavitkutin/src/dispatch/core_mask.rs` returns one match. Returns the mask of ALL units in a phase (bit `u` iff `phase[u]==p`), the shared mask every convergence core walks for a single-trunk phase.

## CHANGE: fn `run_core_phase` ADD head+tail convergence branch
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs`
Verification: `grep "phase_trunk_count" mock/crates/hilavitkutin/src/scheduler/mod.rs` returns one match. When the phase has exactly one trunk and `ncores > 1`, every core uses the full `phase_mask` and walks a record sub-range `[lo, hi)` with `per = ceil(total / ncores)`, `lo = min(core*per, total)`, `hi = min(lo+per, total)` (ceil so the union covers `[0,total)` with no gap; surplus cores get `lo==hi` and do nothing). Otherwise unchanged: `core_phase_mask` by trunk rank, full range. The morsel loop walks `[lo,hi)` instead of `[0,total)`.

## CHANGE: `tests/gate2_convergence.rs` ADD single-trunk-phase convergence test
File: `mock/crates/hilavitkutin/tests/gate2_convergence.rs`
Verification: a single producer writing N (>= 64) records in its only phase, dispatched via `run_parallel` on the os pool (multi-core), asserts every record written exactly once with the correct value (column poisoned first, so an unwritten record from a range gap or a double-write from overlap fails). Proves all cores converged on the one trunk over disjoint record slices covering the whole range.

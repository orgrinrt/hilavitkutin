## CHANGE: fn `OsThreadPool::spawn` FROM no-op skeleton TO real pthread impl
File: `mock/crates/hilavitkutin/src/platform/os.rs`
Detail: replace the `let _ = _f;` body with a no-alloc generic-closure spawn:
`const { assert!(size_of::<F>() <= size_of::<*mut c_void>() && align fits) }`,
copy `F` (held in `ManuallyDrop`) into a `*mut c_void` via `transmute_copy`,
`pthread_create` a DETACHED thread (attr `PTHREAD_CREATE_DETACHED`) with a
monomorphic `tramp::<F>` that reconstructs and calls `F`. Mechanism proven by
sketch `202606071700_gate2-threadpoolapi-contract`.
Verification: `grep "transmute_copy" mock/crates/hilavitkutin/src/platform/os.rs`
returns a match in `spawn`; the new test passes.

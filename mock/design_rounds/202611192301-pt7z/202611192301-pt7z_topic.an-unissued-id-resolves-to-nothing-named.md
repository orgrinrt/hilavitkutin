# Topic: an id the arena did not issue resolves to nothing the contract names

**Date:** 2026-11-19
**Phase:** TOPIC
**Scope:** `hilavitkutin-str` (`ArenaInterner` contract, `StringInterner::resolve`), `hilavitkutin-providers` (`MemoryArena`, `InternerApi::resolve`, their tests), `hilavitkutin-persistence` (a test)
**Source topics:** the second pr-reviewer-senior pass over `work/hila-consumer-surface` at `3f54e21f`, blockers 1 to 4 and finding 5; round `202611192246-jute`, closed, whose wording this corrects

## What the record says

Rounds `202611192051-ers6` and `202611192246-jute` wrote into the `ArenaInterner` contract that resolving an id at or past the arena's live count returns the empty string, and the tests pin it: four of them assert `Maybe::Is("")` for the overflow handle or a handle past the count, and the ignored red asks the overflow handle to resolve to its own string. The persistence design says a handle the interner cannot resolve evicts to `PersistenceError::Missing` (`mock/crates/hilavitkutin-persistence/DESIGN.md.tmpl`), on `tenet::an_interned_string_handle_is_session_specific_so_it_is_stored_on_disk_as_its_content_hash`.

## Where the record is wrong

The empty string is a string, so a contract naming it says the overflow handle holds `""`, and `evict_str` of that handle stores the hash of `""` as though that were the string interned. The persistence design asks for `Missing`, which the contract as written forbids. The ignored red asks a four-byte arena holding `"abcd"` to resolve a handle to `"efgh"`, an outcome no implementation reaches, so it can never go green. `StringInterner::resolve` still says an arena hands out only ids it can resolve, which the overflow id contradicts, and `InternerApi::resolve` promises `Isnt` for an unreachable source, which no runtime handle gets.

## Decision for this round

Derived, not asked. The contract keeps what holds: resolving an id at or past the live count reads nothing outside the arena's storage, and the result is no string the arena holds. What it resolves to is left out of the contract, since saying "nothing" needs `arena_resolve` to return something other than `&str`, which is the signature change already put to op and the visible refusal loru asked for. The expressible red replaces the unreachable one: the overflow handle resolves to `Maybe::Isnt`, and `evict_str` of it returns `Missing`. The green tests keep their real properties (earlier handles hold, a repeat gets its id, an unissued id aliases no held string) and lose the empty-string assertion. The test asserting a carried handle aliases another arena's string is deleted, since it protects the defect and the past-count test already covers the safety property.

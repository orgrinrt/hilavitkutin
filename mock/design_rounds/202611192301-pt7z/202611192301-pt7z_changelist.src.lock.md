# src changelist

Round topic `202611192301-pt7z_topic.an-unissued-id-resolves-to-nothing-named.md`, against the locked doc changelist of this round.

## Changes proposed

### 1. Rustdoc says what the designs now say

`mock/crates/hilavitkutin-str/src/interner.rs`: the `ArenaInterner` doc and `arena_resolve` doc name no string for an id at or past the live count. `StringInterner::resolve` drops the claim that an arena hands out only ids it can resolve; the runtime branch carries `FIXME(evict_str_turns_an_unresolvable_runtime_str_into_the_hash_of)`, since it answers `Maybe::Is` for an id the arena did not issue. `mock/crates/hilavitkutin-providers/src/interner.rs`: the `MemoryArena` doc says the same, and `InternerApi::resolve` says `Maybe::Isnt` comes back for a const handle with no string behind it and not yet for an unissued runtime id.

### 2. The tests ask what the contract holds

`mock/crates/hilavitkutin-providers/tests/interner_law.rs`: the four tests that asserted `Maybe::Is("")` for an overflow or past-count handle assert instead that it resolves to none of the strings held, beside what they already asked. `an_overflow_handle_resolves_to_its_string` is replaced by `an_overflow_handle_resolves_to_nothing`, asserting `Maybe::Isnt`, ignored under the catalogue row. `a_handle_carried_to_another_arena_resolves_to_what_that_arena_holds` is deleted. `mock/crates/hilavitkutin-persistence/tests/archive_str.rs` gains `evicting_an_overflow_handle_is_missing`, asserting `Err(PersistenceError::Missing)`, ignored under a new catalogue row `evict_str_turns_an_unresolvable_runtime_str_into_the_hash_of`. The row `an_overflowing_runtime_intern_breaks_the_interning_law_in_me` in `mock/catalogue.md` is reworded: the overflow handle resolves as a held string rather than to nothing.

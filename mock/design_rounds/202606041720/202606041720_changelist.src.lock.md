# Src changelist: morsel-relative iteration indices

**Date:** 2026-06-04
**Phase:** SRC
**Round:** 202606041720 (morsel-relative-iteration, branch `feat/hilavitkutin-column-data-plane`)

Makes the per-WorkUnit Context iteration accessors yield morsel-relative
record indices `[0, morsel.len)`, matching the relative `i` that
`read(i)` / `write(i)` already expect (they add `morsel.start` to recover
the absolute column index). Before this fix the iteration accessors
yielded absolute indices `[morsel.start, morsel.end())`, so the canonical
`ctx.each().run(|i| ctx.writer().write(i, v))` body double-added
`morsel.start`. Correct only at `morsel.start = 0`; broken once the
morsel-loop split (#343) sets `start > 0`.

## CHANGE: `EachApi::run` for `EngineCtx` FROM iterating `[morsel.start, morsel.end())` TO iterating `[USize::ZERO, morsel.len)`
File: `mock/crates/hilavitkutin/src/dispatch/engine_ctx.rs`
Yields a morsel-relative index. `read` / `write` add `morsel.start`.
Verification: `cargo test --manifest-path mock/Cargo.toml -p hilavitkutin --test column_dispatch` stays green (runs at `start = 0`, where relative equals absolute).

## CHANGE: `ReduceApi::run` for `EngineCtx` FROM folding over `[morsel.start, morsel.end())` TO folding over `[USize::ZERO, morsel.len)`
File: `mock/crates/hilavitkutin/src/dispatch/engine_ctx.rs`
Yields a morsel-relative index to the fold closure, matching `EachApi`.

## CHANGE: `BatchApi::run` for `EngineCtx` FROM handing `(morsel.start, morsel.end())` TO handing `(USize::ZERO, morsel.len)`
File: `mock/crates/hilavitkutin/src/dispatch/engine_ctx.rs`
Hands the morsel-relative half-open range; a body looping that range and
calling `write(i)` lands at `morsel.start + i`.

## Tests

- `tests/engine_ctx.rs`: `context_each_covers_morsel` and
  `context_batch_full_range` build a morsel at `start = 5, len = 3` and
  previously asserted the absolute range (`[5, 6, 7]` and `(5, 8)`), pinning
  the old inconsistent contract. Updated to assert the relative range
  (`[0, 1, 2]` and `(0, 3)`). At `start = 5` relative differs from absolute,
  so the assertions now discriminate relative semantics.
- `tests/column_dispatch.rs` (from the column-data-plane round) stays green at
  `start = 0`, now exercising the relative-indexing contract.

## Out of scope

- The morsel-loop split that sets `start > 0` and a `start > 0` regression
  test (the C5 round, #343). This round fixes only the index contract.

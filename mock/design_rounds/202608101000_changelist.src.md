# Src changelist: an origin is an index, and the run is derived

**Date:** 2026-08-10
**Phase:** IMPL
**Doc CL:** `202608101000_changelist.doc.lock.md`

## CHANGE: `SymShape` declares `origin_index`; base and ceiling are provided

File: `mock/crates/hilavitkutin-sym/src/shape.rs`

`origin_base` and `origin_ceiling` leave the trait's required set. A shape
declares `origin_index`, and the run it owns is derived by provided methods:

```
base    = index << COUNTER_BITS
ceiling = base + (1 << COUNTER_BITS) - 1
```

**Disjointness stops being a law and becomes arithmetic.** Distinct indices own
`[i << C, ((i+1) << C) - 1]`, which cannot overlap, so the shape that defeated
round nine cannot be written at all.

Evidence, and this is why the round exists. Round nine's two laws reject origins
placed **past** the id field and say nothing about origins placed **inside** it
that overlap. Four origin bits, a twenty-four bit counter, bases spaced by 2^20:
every base and ceiling is inside the field, every span is exactly
`2^COUNTER_BITS - 1`, both laws pass, and **origin zero's 1048576th mint is
origin one's first**. Computed before the change and pinned as a test after it.

Both laws had been written to reject the construction that had just been found.
Each did, and neither described the property.

## CHANGE: three things that dissolve rather than being fixed

Same file.

- The literal shift in `SixteenMinters::origin_base` restated `COUNTER_BITS`
  with nothing tying them. There is no `origin_base` to write it in.
- The `Uint<28, Hot>` in the trait was `Standard`'s id width sitting where a
  shape could not override it. No signature carries it now.
- `every_shipped_shape_fits_its_id_field` becomes a consequence of the sum law
  once an index is bounded by `ORIGIN_BITS`, so the law it replaces is the
  smaller one below.

## CHANGE: what remains testable about origins

Files: `mock/crates/hilavitkutin-sym/src/shape.rs`, `tests/origins.rs`

**Distinct origins map to distinct indices, and an index fits `ORIGIN_BITS`.**
A shape can still map two origins onto one index, which is an error in its own
mapping rather than in the layout.

`OriginsPastTheIdField`, round eleven's committed liar, is replaced by
`TwoOriginsOneIndex`, which is the defect that survives the new mechanism. The
previous liar is not merely deleted: **it can no longer be expressed**, and that
is the result, recorded here because a deleted test otherwise reads as coverage
lost.

## Verification

The overlapping construction is unwritable: attempting it is a compile error,
pinned as a `compile_fail` doctest with a positive twin. `SixteenMinters` keeps
its shipped numbers exactly, checked against the raw values in
`hilavitkutin-str/tests/handle.rs`, so `Standard` byte compatibility is
unaffected. Counts measured after the autofix rather than predicted here.

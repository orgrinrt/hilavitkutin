# Src changelist: column data plane (input columns through dispatch)

**Date:** 2026-06-04
**Phase:** SRC
**Round:** 202606041631 (column-data-plane, branch `feat/hilavitkutin-column-data-plane`)

Wires input columns through dispatch. The per-WU column Context
(`EngineCtx::project` / `ColProject` / `read` / `write`) is already built;
this round reserves real column buffers, makes the scheduler bindings the
column source (Shape A, de-risked by the round sketch), lifts the
resource-only dispatch bound, and threads the build-time record count.
TDD red-first: a producer WorkUnit writes a `Column<T>` over `[0, N)`, a
consumer WorkUnit (ordered after it by the plan's RAW edge) reads it back,
and the round-trip is asserted through `run()`.

The dual `Selector` + `ColSelector` co-implementation over the interleaved
bindings cons-list is de-risked by
`mock/research/sketches/202606041631_column-source-dual-selector/`
(verdict WORKS). The two gotchas it found (projection must be
fully-qualified; the pointer wrappers impl `Copy` unconditionally) are
already satisfied by the real `EngineCtx::project` and `ColumnPtr`.

## CHANGE: `ColumnBinding` fields FROM `_ptr` / `_count` (placeholder) TO `ptr` / `count` (real) plus `__ptr` / `__count` / `__tail` accessors
File: `mock/crates/hilavitkutin/src/resource/bindings.rs`
The `Column<T>` binding stops being a dangling placeholder: it holds the
real reserved `ColumnPtr<T>` and the record count, read through hidden
accessors mirroring `ResourceBinding::__ptr` / `__tail`. The
`#[allow(dead_code)]` on the tail link is dropped (the pass-through
selectors read it).
Verification: `grep "pub(crate) ptr: ColumnPtr<T>" mock/crates/hilavitkutin/src/resource/bindings.rs` returns one match; `! grep "_ptr: ColumnPtr" mock/crates/hilavitkutin/src/resource/bindings.rs`.

## CHANGE: `DrainStores::drain` FROM `drain(self, cs, next_id)` TO `drain(self, cs, next_id, record_count: USize)`
File: `mock/crates/hilavitkutin/src/resource/bindings.rs`
All four impls (`SvEmpty`, `Sv<StagedResource<T>>`, `Sv<Column<T>>`,
`Sv<Virtual<T>>`) gain the `record_count` parameter. Resource and virtual
arms ignore it; the column arm reserves a buffer sized by it.
Verification: `grep "record_count: USize" mock/crates/hilavitkutin/src/resource/bindings.rs` returns matches in the trait method and the four impls.

## CHANGE: `DrainStores for Sv<Column<T>, L>` bound FROM `T: 'static` TO `T: ColumnValue`, body FROM dangling placeholder TO real reservation
File: `mock/crates/hilavitkutin/src/resource/bindings.rs`
The column arm reserves `cs.reserve::<T>(StoreId(next_id), record_count)`
at a `StoreId` continued from the resource drain (advancing `next_id`),
records the real `column_ptr_mut::<T>` and the count in the
`ColumnBinding`. A zero-record (or zero-sized) column reserves no bytes and
records a dangling well-aligned pointer (never dereferenced, the morsel is
empty). A reservation failure returns `BuildError::AllocationFailed`.
Verification: `grep "impl<T: ColumnValue, L> DrainStores for Sv<Column<T>, L>" mock/crates/hilavitkutin/src/resource/bindings.rs` returns one match.

## CHANGE: add `ColSelector` impls on bindings nodes and `Selector` / `ColSelector` `There` pass-through (Shape A)
File: `mock/crates/hilavitkutin/src/dispatch/engine_ctx.rs`
New `ColSelector<T, Here>` on `ColumnBinding<T, Tail>`; `ColSelector<T,
There<I>>` pass-through on `ColumnBinding<U, _>`, `ResourceBinding<U, _>`,
`VirtualBinding<U, _>`; `Selector<T, There<I>>` pass-through on
`ColumnBinding<U, _>` and `VirtualBinding<U, _>` (closing the pre-existing
resource-after-column traversal gap). With these, the bindings cons-list
resolves both `Project` (resources) and `ColProject` (columns) over the
interleaved list.
Verification: `grep "impl<T, Tail> ColSelector<T, Here> for ColumnBinding<T, Tail>" mock/crates/hilavitkutin/src/dispatch/engine_ctx.rs` returns one match.

## CHANGE: `CollectFiber` / `fiber_shim` bound FROM resource-only (`ColPtrNil: ColProject<..., Empty>`) TO `A: ColProject<Read, RCIdx> + ColProject<Write, WCIdx>`
File: `mock/crates/hilavitkutin/src/dispatch/fiber_codegen.rs`
`fiber_shim` gains `RCIdx` / `WCIdx` type params and projects columns from
the bindings via fully-qualified `EngineCtx::project::<A, A, RIdx, RCIdx,
WCIdx>(bindings, bindings, morsel)`. The `CollectFiber` witness element
becomes the per-unit triple `(RIdx, RCIdx, WCIdx)`; the column-free case
infers all three to the empty/`ColPtrNil` shape, so resource-only units
dispatch unchanged.
Verification: `grep "A: ColProject<<W as WorkUnit>::Read, RCIdx>" mock/crates/hilavitkutin/src/dispatch/fiber_codegen.rs` returns matches in `fiber_shim` and `CollectFiber`.

## CHANGE: `Scheduler` gains a `record_count: USize` field; `build` / `build_with` gain a `record_count: USize` parameter
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs`
`build` / `build_with` take the record count, feed it to `compute_plan`
(replacing `USize::ZERO`) and to the bindings drain, and store it on the
scheduler. `run` builds the morsel as `MorselRange::new(USize::ZERO,
self.record_count)` so the column accessors iterate the records. The
`Default` and bare-`builder` paths set the field to `USize::ZERO`.
Verification: `grep "record_count: USize" mock/crates/hilavitkutin/src/scheduler/mod.rs` returns matches in the struct field, `build`, and `build_with`.

## Tests

- New `tests/column_dispatch.rs`: producer writes `Column<Cv>` over
  `[0, N)`, consumer (registered first, so the prepend puts it ahead;
  the plan's RAW edge reorders the writer ahead) reads back into a
  thread-local recorder, asserts the round-trip and the recorded order.
  Also asserts the `ColumnBinding` recorded the reserved record count via
  `__bindings().__count()`.
- All resource-only `.build(store(...))` call sites across the test suite
  gain the `USize::ZERO` record-count argument (no records). `FileInfo` in
  `scheduler_builder.rs` gains `#[derive(Copy, Clone)]` so it satisfies the
  tightened `ColumnValue` drain bound.

## Summary

Three new `steps` functions plus a runner rewire populate `Trunk.components` with per-block fibers. Fibers form within each block (trunk) so they nest correctly. The spectral former + width-gate + the arvo bump are deferred to C1d-3b.

## CHANGE: new `steps::group_fibers_in_block`
File: `mock/crates/hilavitkutin/src/plan/steps.rs`
Verification: `grep -n "fn group_fibers_in_block" steps.rs` returns one match. Takes the graph, a block's units as a topo-ordered `&[UnitId]` slice, and emits a `FiberGrouping` with block-local FiberIds via the same out-degree roll-over the global `group_fibers` uses, restricted to the slice.

## CHANGE: new `steps::project_fiber_components`
File: `mock/crates/hilavitkutin/src/plan/steps.rs`
Verification: `grep -n "fn project_fiber_components" steps.rs` returns one match. Signature carries the eight plan dims (`MAX_UNITS, MAX_EDGES, MAX_FIBERS, MAX_PHASES, MAX_TRUNKS_PER_PHASE, MAX_COMPONENTS_PER_TRUNK, MAX_UNITS_PER_FIBER, MAX_COLUMNS_PER_FIBER`); returns `[[Trunk<...>; cap_size(MAX_TRUNKS_PER_PHASE)]; cap_size(MAX_PHASES)]`. Per phase: builds the block-id->trunk-index map (the same dedup `phase_trunk_counts` does), assigns each trunk a plan-wide running `TrunkId`, runs the per-block greedy former on the block's topo-ordered units, and emits each block-local fiber as a `TrunkComponent::Fiber(Fiber { id, units, unit_count })` with a plan-wide running `FiberId`. `columns`/`head_tail`/`dispatch_approach` stay at `Fiber::new()` defaults. The former-selection point carries a comment marking where the C1d-3b width-gate spectral branch lands.

## CHANGE: new `steps::fiber_grouping_from_trunks`

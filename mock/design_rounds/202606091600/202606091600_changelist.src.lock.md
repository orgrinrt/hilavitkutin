# Src changelist: spec-free ColumnValue, drop full `specialization`

**Round:** 202606091600
**Phase:** IMPL (src)
**Scope:** `hilavitkutin-api/src/column_value.rs`, `hilavitkutin-api/src/lib.rs`.

Makes `ColumnValue` spec-free and removes the `#![feature(specialization)]` gate from the crate root. `BIT_WIDTH` is dormant (no functional consumer; `engine_ctx.rs` sizes columns by `size_of`), so collapsing the `default const` blanket to a trait-body default plus an empty blanket impl, and deleting the three sub-byte overrides, is zero-regression: every `Copy + 'static` type still satisfies `ColumnValue` through the blanket.

## CHANGE: trait `ColumnValue::BIT_WIDTH` FROM blanket `default const` (full `specialization`) TO trait-body default const + empty blanket impl
File: `mock/crates/hilavitkutin-api/src/column_value.rs`
Verification: `! grep -n "default const" mock/crates/hilavitkutin-api/src/column_value.rs` (no `default const` remains) and `grep -n "const BIT_WIDTH: USize = USize(core::mem::size_of" mock/crates/hilavitkutin-api/src/column_value.rs` returns the trait-body default, and `grep -n "impl<T: Copy + 'static> ColumnValue for T {}" mock/crates/hilavitkutin-api/src/column_value.rs` returns the empty blanket.

## CHANGE: test `tests/column_value.rs` sub-byte assertions FROM logical-width (`BIT_WIDTH == 1/2/4`) TO container-width (`BIT_WIDTH == size_of * 8`)
File: `mock/crates/hilavitkutin-api/tests/column_value.rs`
Verification: `cargo test -p hilavitkutin-api --test column_value` passes 7/7. The three `specialised_*` tests are replaced by `sub_byte_*_reports_container_width`, asserting the blanket applies with no per-type override (the assertion fails if a width override is re-introduced).

## Notes

- `BIT_WIDTH` has no RUNTIME consumer (column reservation in `engine_ctx.rs` sizes by `size_of`), but the integration test `tests/column_value.rs` asserted the sub-byte logical widths, so it is the contract enforcer. Those three assertions are rewritten to the spec-free contract: sub-byte arvo types now report their container width through the blanket, and the logical sub-byte width becomes a future bitpacking-layer concern sourced from arvo's const-generic width. The decision to relocate the width source (rather than preserve per-type overrides via explicit per-type `impl ColumnValue` blocks, the other spec-free shape) keeps the zero-friction blanket and loses no recoverable information; recorded for op review.
- The `arvo::ufixed::UFixed`, `arvo::{fbits, ibits}`, and `arvo::strategy::Hot` imports in `column_value.rs` become unused once the sub-byte impls go; they are removed in the same edit to keep the crate warning-clean.
- `#![allow(incomplete_features)]` stays: the remaining allowed gates (`adt_const_params`, etc.) still emit incomplete-feature warnings.

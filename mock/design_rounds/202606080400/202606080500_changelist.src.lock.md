# Src changelist: GATE-2 G-e const-gated per-trunk dispatch + Scheduler::run re-point

**Date:** 2026-06-08
**Round:** GATE-2 G-e (doc CL `202606080400` locked)
**Phase:** SRC
**Scope:** `hilavitkutin` dispatch + scheduler. Single-core, output-equivalent.
**Proven shapes:** sketches `mock/research/sketches/202606080130_gate2-ge-const-range-dispatcher` and `202606080200_gate2-ge-outer-drives-rungatedtrunk` (the corrected, decisive proof: trunk-only keying + const-POS outer walk, zero GCE const-args).

## Summary

Make the shipped per-trunk walk `RunGatedTrunk` (round 2a) trunk-only keyed (a trunk lies wholly within one phase, so its `const PHASE` is redundant for membership), add the outer all-trunks dispatcher that drives one per-trunk mono per trunk-root in phase order, and re-point single-core `Scheduler::run` to it. The parallel `run_parallel` path is untouched (G2-N re-points it later). Phase order is the dispatcher's runtime phase loop; the per-trunk monos DCE to member-only programs.

## CHANGE: trait `RunGatedTrunk` FROM PHASE+TRUNK keyed TO TRUNK-only keyed
File: `mock/crates/hilavitkutin/src/dispatch/trunk_gate.rs`
Drop the `const PHASE: usize` parameter from the trait and both impls; the gate becomes trunk-only. Pre-1.0 churn: delete the PHASE-keyed form, no alias.
Verification: `! grep "const PHASE" mock/crates/hilavitkutin/src/dispatch/trunk_gate.rs` returns nothing.

## CHANGE: new module `dispatch::trunk_dispatch` with trait `RunTrunkDispatch` + `dispatch_trunks` entry
File: `mock/crates/hilavitkutin/src/dispatch/trunk_dispatch.rs` (new), `mock/crates/hilavitkutin/src/dispatch/mod.rs` (mod + re-export)
`RunTrunkDispatch<Full, A, Witnesses, GW, Stores, CU, CS, Adj, const POS>` over `WuCons` / `WuNil`: recursion threads `{POS+1}`, base on `WuNil`; per cell const-gate `const { trunk_of(POS) == POS }` (is trunk-root) and runtime `phase_of(POS) == p` (this phase's pass), dispatching `RunGatedTrunk::<.., TRUNK = POS, Here>::run_trunk` on the FULL carrier; always recurse the tail. The phase loop (runtime `0..phase_count`) drives `run` once per phase. `POS` reaches `TRUNK` by identity, no GCE const-arg.
Verification: `grep "pub trait RunTrunkDispatch" mock/crates/hilavitkutin/src/dispatch/trunk_dispatch.rs` returns one match.

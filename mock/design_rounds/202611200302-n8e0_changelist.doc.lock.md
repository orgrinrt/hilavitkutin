# doc changelist

Round topic `202611200302-n8e0_topic.what-the-review-of-the-freeing-round-found.md`.

## Changes proposed

### 1. What a refused re-reserve leaves

`mock/crates/hilavitkutin-api/DESIGN.md.tmpl`, the `ColumnStorage` listing: a reserve the store refuses for its arguments (an id past the cap, a byte length past `usize`) changes nothing, so a live column stays live; a reserve whose block the provider refuses leaves the id unreserved, count zero, since a re-reserve gives the old block back before it takes the new one.

`mock/crates/hilavitkutin-providers/DESIGN.md.tmpl`, `ArenaColumnStorage`: the same, said of `IdOutOfRange`, `LengthOverflow` and `Exhausted`.

### 2. `MemoryArena` takes up to 2^28 entries

`mock/crates/hilavitkutin-providers/DESIGN.md.tmpl`, the `MemoryArena` capacity paragraph: an arena of `ENTRIES` entries issues ids below `ENTRIES`, its refusal is `u32::MAX`, so an `ENTRIES` of up to 2^28 keeps every issued id inside the 28-bit field and below the refusal; one past 2^28 fails the build at `MemoryArena::new`.

### 3. The free-list provider's orderings

`mock/crates/hilavitkutin-providers/DESIGN.md.tmpl`, `StaticFreeListMemory`: the lock flag is taken by an acquire compare-exchange and given back by a release store, so every list write under one holder happens before the next holder's reads; `used` is relaxed and read as a count only, never to order a block's bytes.

### 4. Layout

`mock/crates/hilavitkutin-api/DESIGN.md.tmpl` and `mock/crates/hilavitkutin/DESIGN.md.tmpl`, the platform sections reflowed by yszg: lines brought back to the wrap width, no change of meaning.

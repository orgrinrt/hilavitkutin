# src changelist

Round topic `202611192343-hx2c_topic.a-host-imports-and-dumps-column-records.md`, against the locked doc changelist `202611192343-hx2c_changelist.doc.lock.md` and the section `### Host import and dump` of `mock/crates/hilavitkutin/DESIGN.md.tmpl`.

## Changes proposed

### 1. The host path on the scheduler

`mock/crates/hilavitkutin/src/scheduler/host.rs`, new, with `mod host;` and `pub use host::HostRefused;` in `scheduler/mod.rs`:

- `HostRefused::PastCount { count }`, the one refusal.
- `Scheduler::import::<C, I, J>(at, records)`: resolves the store's `ColRef` through `ColSelector<C::T, I, C::K>` on the bindings, refuses a range past its count with `PastCount` before any record moves (an `at + len` that overflows is past the count too), returns `Ok` and marks nothing for an empty slice, copies the records onto the read base and, where the write base is another reservation, onto that too, then calls `mark_dirty::<C, J>()`. A `FIXME(a_host_import_marks_its_whole_store_changed)` stands at the mark.
- `Scheduler::dump::<C, I, P>(at, len, sink)`: the same range check, then one `push_bulk` of a slice over the read base, which lives only for the call.

### 2. The count of a resolved column

`mock/crates/hilavitkutin/src/dispatch/engine_ctx/lists.rs`: `ColRef::count`, a crate-visible const accessor for the record count the host path checks a range against.

### 3. Tests

`mock/crates/hilavitkutin/tests/host_import.rs`, new:

- an import into `Column<A>`, a unit writing `B = 2A`, and a dump of `Column<B>` give the doubled records;
- the round trip over `Column`, `Buffered<_, Snapshot>` and `Buffered<_, Exchange>`, at an even and an odd frame;
- an import makes the units reading the store run in the next frame while an unrelated unit stays rested, and a twin that writes the records without the mark does not;
- a range past the count is refused, in both calls, and a canary record past the count is left as it was;
- an empty import marks nothing, so the next frame rests every unit;
- the import and dump history gives the same records under `run`, `run_fused` and `run_parallel`;
- the red `an_import_of_one_record_reruns_only_the_morsel_that_covers_it`, ignored under the catalogue row and ticket `a_host_import_marks_its_whole_store_changed`.

`mock/crates/hilavitkutin/tests/ui/`: compile-fail cases for `import` of an `Accum`, of a `Virtual` and of an unregistered column, and `dump` of a `Virtual`, run by `tests/ui.rs`.

## Not changed

`mark_dirty`, `replace_value` and `replace_resource` stay as they are. No range mark is added.

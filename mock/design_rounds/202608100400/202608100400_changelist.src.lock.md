# Src changelist: the refusals, and the liar that stays

**Date:** 2026-08-10
**Phase:** IMPL
**Doc CL:** `202608100400_changelist.doc.lock.md`

## CHANGE: a `refusals` module pinning what the design says is unrepresentable

File: `mock/crates/hilavitkutin-sym/src/lib.rs`

Two refusals the design claims in prose and nothing guarded:

- **Two shapes' handles do not compare**, `compile_fail,E0308`.
- **The literal tag constructor exists on `Standard` alone**,
  `compile_fail,E0599`.

**Each is paired with the nearest thing that must still compile.** A
`compile_fail` block passes when its contents fail for any reason at all, a typo
included, so the error code is pinned and a positive twin shows the surrounding
construction is sound. Without the twin the test asserts only that something went
wrong.

`trybuild` was tried first and does not run in this workspace: it rebuilds the
dependency graph in its own target directory and `tree-sitter`'s build script
output is absent there, which is the same failure `hilavitkutin-api`'s existing
trybuild suite hits. Recorded as an upstream defect rather than worked around.
`compile_fail` doctests with pinned error codes carry the same guarantee here and
run in the normal test flow.

## CHANGE: the existing generator doctest fails for one reason instead of two

File: `mock/crates/hilavitkutin-sym/src/generator.rs`

Its `Domain` impl omitted `type Shape`, so it emitted `E0046` beside the intended
`E0277` and shipped an uncompilable `Domain` example on a public rustdoc page.
The impl is completed, the code is pinned to `E0277`, and a positive twin shows
the impl compiles on its own, so the refusal is about the missing
`GenerativeDomain` and nothing else.

## CHANGE: the collision construction becomes a permanent negative test

File: `mock/crates/hilavitkutin-sym/src/shape.rs`

**This is the change the round exists for.** The fit law is expressed as
`origins_fit_the_id_field`, returning a verdict rather than asserting, so the
same law serves the shipped shapes and a shape built to break it. A law that can
only assert cannot be pointed at a liar, which is why every prior demonstration
of this defect was a hand edit that got reverted.

`OriginsPastTheIdField` is that liar, declared in the test module: four origin
bits over a twenty-six bit id, origins shifted as though the id were
twenty-eight wide. `the_fit_law_rejects_origins_past_the_id_field` asserts the
law rejects it, and `the_broken_shape_still_satisfies_every_width_law` asserts it
passes every width law, so a future law claiming to cover this case has to
disagree with a test rather than with a comment.

Nine rounds demonstrated this class by editing source and reverting. It is now
committed and cannot come back silently.

## CHANGE: round ten's allow that did not stick

File: `mock/crates/hilavitkutin-sym/src/shape.rs`

`#[rustfmt::skip]` did not hold across the autofix for the span statement: the
formatter split the `if` expression across lines and left the comment where the
lint does not read it. The expression is now a single shift the formatter will
not break, and the verdict function's `bool` return carries its own allow.

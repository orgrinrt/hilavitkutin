## CHANGE: the coverage section names the refusals

File: `mock/crates/hilavitkutin-sym/DESIGN.md.tmpl`

The section says every documented effect, boundary and edge case carries a test.
It does not say that a documented **refusal** does, and this crate's argument
rests more on what it refuses than on what it computes.

Added: every refusal the document claims is a compile-fail test, because a
refusal nothing guards can be removed by loosening a bound while every remaining
test still passes. And a construction that compiles but is wrong is a negative
test, declared inside the test module rather than left uncommitted, since the
alternative has been to verify it by hand and throw it away.

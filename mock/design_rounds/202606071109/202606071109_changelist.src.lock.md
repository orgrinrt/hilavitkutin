The per-(core, phase) unit-mask foundation for the N-core runtime-mask dispatch.
Pure functions, no threading (that is R4b). Reuses the R2 const grouping
(`phase_of` / `trunk_of`) as the per-unit (phase, trunk) source.

## CHANGE: module `dispatch::core_mask` ADDED with `grouping_arrays` + `core_phase_mask`
File: `mock/crates/hilavitkutin/src/dispatch/core_mask.rs`
Verification: `grep "pub fn grouping_arrays" mock/crates/hilavitkutin/src/dispatch/core_mask.rs` and `grep "pub fn core_phase_mask" mock/crates/hilavitkutin/src/dispatch/core_mask.rs` each return one match.
`grouping_arrays<Wus, Stores, Witnesses, CU: Capacity + [const] ConstCapacity, CS: Capacity, Adj>(phase_out: &mut [USize], trunk_out: &mut [USize]) -> USize` loops the shipped `phase_of` / `trunk_of` over carrier positions filling per-unit phase/trunk, returning the unit count (`Adj` is the grouping row word, threaded to `phase_of`/`trunk_of`). `core_phase_mask<Adj: BitAccess + Identity>(phase: &[USize], trunk: &[USize], n: USize, core: USize, target_phase: USize, ncores: USize) -> Adj` returns the AdjRow with bit `u` set iff `phase[u] == target_phase` and the within-phase rank of `trunk[u]` modulo `ncores` equals `core` (rank = count of distinct phase-`target_phase` trunks with id < `trunk[u]`).

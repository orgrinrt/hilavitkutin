# Source changelist: widths that constrain

**Phase:** IMPL
**Doc changelist:** `202608090500_changelist.doc.lock.md`
**Scope:** `mock/crates/hilavitkutin-sym/src/**`, `tests/**`,
`mock/crates/hilavitkutin-str/src/**`.

Every verification below is run **after** the commit hook's autofix, against
`git show HEAD`. The previous round wrote that discipline into its own header and
then shipped a verification false against HEAD, so this one records the command
and its output rather than asserting it was done.

## CHANGE: `SymLayoutOps` reports its carrier's actual widths

File: `src/shape.rs`, `src/handle.rs`

Gains `const KIND_WIDTH` and `const ID_WIDTH`, set by each layout to what its
bitfield actually declares. A layout is the only thing that knows, so it is the
only thing that should say.

Verification: `git show HEAD:...handle.rs | grep -c 'KIND_WIDTH'` is 2, one per
layout.

## CHANGE: a law ties each shape's declaration to its layout

File: `src/shape.rs`

`every_shape_declares_the_widths_its_layout_actually_has` asserts
`S::KIND_BITS == <S::Layout>::KIND_WIDTH` and the same for the id, over every
shipped shape. This is what turns the declarations from description into
constraint: a shape that lies now fails its own law.

Verification, by construction: write a shape declaring `KIND_BITS = 9` over the
three-bit layout, observe the law fail, then delete it. The reviewer's
counter-example must stop compiling clean.

## CHANGE: delete the two restatements

Files: `src/shape.rs`, `tests/origins.rs`

`assert_eq!(Standard::KIND_BITS.0, 3)` restates the literal declared in the same
file. `assert!(0b10000 > 0b111)` compares two literals. Both are structurally
incapable of failing and are deleted rather than repaired.

The wide-tag test keeps the half that constrains: that the minted tag round-trips
through a five-bit field, which fails if the layout is wrong.

Verification: `git show HEAD` greps clean for a constant compared to the literal
its own definition sets.

## CHANGE: `lint:allow` comments return to their item lines

Files: `src/shape.rs`, `hilavitkutin-str/src/interner.rs`

rustfmt moved seven of them into bodies, where they suppress nothing. Restored
same-line, which is what the rule requires.

Verification: every `lint:allow` in the touched files shares a line with the item
it covers.

## CHANGE: banned vocabulary out of prose this branch wrote

Files: `src/shape.rs`, `src/generator.rs`

`partition` is a banned term and appears four times in newly written prose.

Verification: `git show HEAD` greps zero for it in these files.

## Lock criteria

- The counter-example shape fails a law, observed before deletion.
- Zero restatement assertions, verified by grep against `git show HEAD`.
- `cargo build` warning-free from this crate; `cargo test` green workspace-wide.
- Scoped commit gate clean on every crate this round touches.

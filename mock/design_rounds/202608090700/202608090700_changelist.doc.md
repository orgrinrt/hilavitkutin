## CHANGE: the `SymShape` section

The document says a width the trait declares is one something constrains. Round
four made that half-true by tying a shape's declaration to a number the layout
also wrote by hand, which is the same statement twice rather than a constraint.

State the mechanism that closes it: a layout carries its own generated mask, and
the width is counted from that mask by a function no implementation can override.
Nobody writes the number, so nobody can write it wrong.

## CHANGE: the `Interner` section

Its methods take and return a bare handle in source, so a domain on any shape but
the default cannot have an interner. The design already said otherwise. Correct
the source rather than the document, and say here that both producers carry the
domain's shape.

## CHANGE: `README.md`

Still documents `build.rs` integration. This branch removed the last build
dependency and no build script remains in the workspace, so the section describes
a model the repo has left.

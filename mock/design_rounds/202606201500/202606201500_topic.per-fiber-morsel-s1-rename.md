# Topic: per-fiber morsel slice 1 (rename + corrected framing)

**Date:** 2026-06-19
**Phase:** TOPIC
**Scope:** `hilavitkutin` plan (`ExecutionPlan` field + the morsel step) + the scheduler store-back
**Source topics:** the per-fiber morsel blueprint (`mock/research/202606201400_per-fiber-morsel-blueprint.md`), slice 1

## Current state

The blueprint established that per-fiber morsel WINDOW sizing is canonical (spec
domain 12), and that the shipped `ExecutionPlan::morsel_sizes` is intermediate-
round drift: `size_morsels` (`plan/steps.rs:948`) computes a record-count
PARTITION (`Σ morsel_sizes[f] == record_count`), not a window chunk size. The
dispatch still windows uniformly by the const `Cfg::MORSEL_SIZE`, so the field is
computed-but-unconsumed.

## Changes proposed (slice 1, mechanical)

Establish the corrected framing without changing dispatch behaviour:

1. Rename `ExecutionPlan::morsel_sizes` -> `morsel_windows` (`plan/mod.rs:89`,
   init at `:127`), and its store-id accessor `morsel_sizes_id` ->
   `morsel_windows_id` (`scheduler/mod.rs:298`) plus the two store-back call
   sites (`:568`, `:2582`) and the single reader (`plan/core_program.rs:72`,
   rename only).
2. Rename `size_morsels` -> `compute_fiber_morsel_windows` (`plan/steps.rs:948`,
   call site `plan/mod.rs:391`). KEEP the current `(record_count, fiber_count)`
   signature and the partition body for now, marked as a PLACEHOLDER: the per-
   fiber L1 window formula (`(L1_usable / Σ write_bytes).clamp(MIN,MAX) & !3`)
   needs the per-fiber write-byte inputs that slice 4 introduces, so the
   signature change and the real body land in slice 4. The numeric output is
   unchanged, so all existing tests pass.
3. Correct the field + function docs to describe the canonical window semantics
   and explicitly flag the current value as the placeholder partition pending
   slice 4 (so the name does not silently mislead).
4. Catalogue-red test (`tests/r6_morsel_window_formula.rs`, `#[ignore =
   "catalogue: per-fiber L1 morsel-window formula; tracked #341"]`) asserting
   `morsel_windows[f]` matches the spec formula for a known fiber. Red until
   slice 4 lands the formula.

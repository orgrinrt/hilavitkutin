Round topic `202611132057_topic.review-fixes-second-pass.md`, doc changelist `202611132059_changelist.doc.lock.md`. The two other flat topics, `202607200100_topic.b1-cap-lifting-completion.md` and `202607281547_topic.adopt-the-shared-hlist.md`, name `hilavitkutin` and `hilavitkutin-api` only, which this round does not touch, so they need nothing from it.

## mock/crates/hilavitkutin-str/src/entry.rs

- `StaticStrEntry::new` is `#[doc(hidden)]` and its doc says it is public only for the macro and not for callers, as the design now says of it and of `Str::__make`. The struct doc names the section `hilavitkutin_strings` without the leading dot.

## mock/crates/hilavitkutin-str/tests/str_const.rs

- A test that the handle `str_const!("foobar")` returns is the entry's own `hash` and that its id is 0x073967e8, the low 28 bits of the published FNV-1a reference value for that string, so the formula is pinned against a value not computed by the code under test.

## mock/crates/hilavitkutin-sym/src/generator.rs

- Two doctests on `Generator::single`: a one-origin shape that reports index 1 against zero reserved bits fails to build in a constant with `E0080`, and the same shape reporting index 0 builds, so the failure is the range check's alone. They pin the build error the design claims.

## mock/crates/hilavitkutin-persistence/tests/archive_str.rs

- A catalogue test, ignored with the reason format the `catalogue-ignore` lint reads and tracked by the ticket slug `str_const_two_strings_sharing_28_hash_bits_get_one_const_han` (id `462b061b94ed`), that two `str_const!` strings sharing their low 28 bits ("const-7378" and "const-121144") each evict to their own key. It fails where it runs, since the two take one const handle.

## mock/catalogue.md

- A row for that ticket, which the ignore reason resolves against. The row for trampoline survival under fat LTO is removed: it said the check was missing off unix and needed a symbol reader, and the earlier round of this branch built both, so no ignored test names it any more.

## mock/crates/hilavitkutin-extensions-macros/tests/lto_smoke.rs

- The two `cargo` invocations use `env!("CARGO")`, the cargo that runs the tests, in place of the first `cargo` on the path.

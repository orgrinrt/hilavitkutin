# Two public types that exist only to carry doctests

**Date:** 2026-08-10
**Phase:** TOPIC
**Scope:** `hilavitkutin-sym`

Round eleven added `TwoShapesDoNotCompare` and `ALiteralTagIsStandardOnly`,
public structs whose only content is the rustdoc holding a compile-fail example.
The build gate refuses them, correctly: a public type not named in any design
document is either missing from the design or should not be public.

Here it is the second. Neither is a design surface. They were reached for because
a doctest needs an item to hang from, and a struct was the first item to hand.

The module they sit in is an item too, and it is the honest one: the refusals are
a property of the crate rather than of two empty types. Both blocks move onto
`pub mod refusals` and the structs go.

The gate found this immediately, which is worth recording. Round eleven's own
verification measured lint findings and test results and did not think to ask
whether it had added public surface. The gate asked.

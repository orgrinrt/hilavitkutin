# Src changelist: the doctests move to the module

**Date:** 2026-08-10
**Phase:** IMPL
**Doc CL:** `202608100700_changelist.doc.lock.md`

## CHANGE: delete two doc-carrier structs, keep every doctest

File: `mock/crates/hilavitkutin-sym/src/lib.rs`

`TwoShapesDoNotCompare` and `ALiteralTagIsStandardOnly` had no members, no
behaviour and no place in the design. Both existed because a doctest needs an
item, and a struct was the first item to hand.

Both blocks move onto `pub mod refusals`, which is the item that honestly owns
them: what the crate refuses is a property of the crate.

Verification: `grep -c 'TwoShapesDoNotCompare\|ALiteralTagIsStandardOnly'`
returns 0 in source, the doctest count is unchanged, and `mock --lint-only
--strict` reports no `undocumented-type`, measured after the autofix.

# Topic: morsel-outer dispatch post-review fixes

**Date:** 2026-06-05
**Scope:** hilavitkutin engine (`mock/crates/hilavitkutin`), test + doc-comment only. Follow-on to round 202606050220 (morsel-outer dispatch), addressing the PR #127 reviewer findings before merge.

The neutral PR reviewer cleared the morsel-outer dispatch change for merge after two fixes. Both are addressed here, on the same feature branch, as a source-only round (no design-template changes).

The first finding is a test gap. Round 202606050220 added `tests/morsel_outer.rs`, which asserts the morsel-outer nesting for an accumulator-free pipeline (the `accum_free == true` branch). The complementary branch, unit-outer dispatch for an accumulator pipeline (`accum_free == false`), has no discriminating test: the existing accumulator tests use record counts below the morsel size, so the two nestings are observationally identical there. That branch is the guard's reason to exist (a wrong guard would dispatch an accumulator pipeline morsel-outer, interleaving per-morsel appends from distinct units and reordering the accumulator buffer), so it gets a test that fails if the guard ever routes an accumulator pipeline to morsel-outer.

The second finding is a documentation gap. The `accum_free` guard is sound only because the accumulator append path is currently the single Context surface whose effect crosses a morsel boundary (the per-record `read` / `write` accessors are morsel-relative, `each` / `reduce` / `batch` are morsel-confined, and `fire` is a no-op at this stage). The `run` doc comment names `read` / `write` / append as the surface; it should state the assumption explicitly so that widening `fire` to real cross-record edge semantics revisits the guard.

## Changes proposed

A new test in `tests/morsel_outer.rs` covering the unit-outer-for-accumulator branch at a record count spanning multiple morsels, and a clarifying sentence in the `Scheduler::run` doc comment naming the single-cross-morsel-surface assumption. No source behaviour changes, no design-template changes.

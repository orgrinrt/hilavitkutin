## CHANGE: plan-band gates FROM first-frame-only TO first-frame OR plan-dirty

File: `mock/crates/hilavitkutin/src/scheduler/mod.rs` (the
`let plan_dirty = Bool(self.first_frame...)` frame-entry computation and
the worker-side band start `let mut p = if s.first_frame...`).
Frame entry computes `first_frame OR any plan_dirty bit`, clears the
bits it consumed, and publishes the band decision in a `plan_band:
AtomicBool` field the workers read where they previously read
`first_frame` (same between-frames write discipline, so the worker-side
happens-before argument is unchanged and all workers compute the same
start). The single-core paths consume the same computation directly.
Verification: `grep -c "plan_band" mock/crates/hilavitkutin/src/scheduler/mod.rs` returns at least 3.

## CHANGE: S6 test suite

File: `mock/crates/hilavitkutin/tests/replace_swap.rs` (new)

# src changelist

Round topic `202611132042_topic.review-fixes-leaf-crates.md`, doc changelist `202611132042_changelist.doc.lock.md`. The two other flat topics, `202607200100_topic.b1-cap-lifting-completion.md` and `202607281547_topic.adopt-the-shared-hlist.md`, name `hilavitkutin` and `hilavitkutin-api` only, which this round does not touch, so they need nothing from it.

## mock/crates/hilavitkutin-linking/src/backend/unix.rs

- `RTLD_NOW` and `RTLD_LOCAL` take their values from the `libc` crate for the target, in place of the hand-written constants. `RTLD_LOCAL` is 4 on Apple, 0 on Linux, 0x200 on NetBSD and QNX and 0x80000 on AIX; `RTLD_NOW` is 0 on 32-bit Android.

## mock/crates/hilavitkutin-linking/tests/not_yet_loaded.rs

- The candidate library is found by searching the common glibc directories (Debian multiarch, lib64, lib) for a small library that exists and is not mapped, in place of two fixed Debian paths. The control that `dlopen` with the value 4 returns null for it stays first.

## mock/crates/hilavitkutin-sym/tests/generator.rs

- A shape with one origin and an out-of-range origin index is offered to `Generator::single` and to `Generator::default`, and a `should_panic` test pins each panic, which is the failure path the assertion in `single` exists for and which no test reached.

## mock/crates/hilavitkutin-persistence/tests/archive_str.rs

- The ten-thousand-string test evicts the strings through `evict_str` on interned runtime handles and requires as many distinct keys, with the same keys counted at 16 bits as its control, in place of hashing the strings directly. A second test searches for two strings that share their low 28 bits and requires `evict_str` to key them apart and `inject_str` not to return the first string for the second key.

## mock/crates/hilavitkutin-persistence/src/string_table.rs

- The `lint:allow` on `StringTable::lookup` sits on the signature line again, held there by `#[rustfmt::skip]`, where the formatter had moved it into the body and left the signature unmarked.

## mock/crates/hilavitkutin-str/tests/section.rs

- The entry test asserts that an entry's hash equals the const handle built from `const_fnv1a` of its string, in place of comparing two calls of the constructor with each other.

## mock/crates/hilavitkutin-extensions-macros/tests/lto_smoke.rs

- The symbol table read from an ELF or Mach-O library counts defined symbols only, so an imported name is not taken for a trampoline that survived.

## mock/crates/hilavitkutin-extensions-macros/tests/lto_smoke_fixture/Cargo.toml

- The profile comment names the smoke test's symbol-table read in place of `nm`, which the test no longer runs.

## CHANGE: fold per-unit lifecycle rank into `BundleMasks::fill` + `UnitAccess::RANK`
File: `mock/crates/hilavitkutin/src/plan/grouping.rs`
Verification: `grep "const RANK: USize" mock/crates/hilavitkutin/src/plan/grouping.rs`; `grep "ranks: &mut \[USize\]" mock/crates/hilavitkutin/src/plan/grouping.rs`.

Implemented as a fold into the existing `BundleMasks::fill` (a `ranks: &mut
[USize]` param filled from `<Un as UnitAccess>::RANK`) rather than a separate
`BundleRanks` trait. `UnitAccess` gains a defaulted `const RANK = RANK_CONSUMER`

because `fill`'s only caller is `masks_of`, so no call-site bound ripples across
the ~10 dispatch sites that already bound `BundleMasks`.

## CHANGE: kernel sequences the meta lifecycle via band-ordered dispatch + plan-dirty skip
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs`, `mock/crates/hilavitkutin/src/dispatch/engine_ctx.rs`
Verification: new `tests/gate2_meta_pipeline.rs` green; engine suite green; `grep "for OnMeta" mock/crates/hilavitkutin/src/dispatch/engine_ctx.rs`; `grep "plan_phase_count" mock/crates/hilavitkutin/src/scheduler/mod.rs`.

The rank-outer renumber already sequences the meta WUs into lifecycle bands, so
the kernel does not fire per-virtual stamps in slice 2. `dispatch_trunks` gains a
`plan_dirty: Bool` and skips the leading plan band (`phases 0..plan_phase_count`)
on a clean frame; `run` passes `self.first_frame` as the plan-dirty signal (the
plan is computed once; the `replace_resource`-driven re-dirty is domain-22,
slice 3). `GateWith for OnMeta<V>` is const-open (GI = `Here`, like `Always`), so
an OnMeta unit runs whenever its band dispatches. For a carrier with no
plan-stage meta unit, `plan_phase_count` is zero, so dispatch is byte-identical
to before. Real Virtual firing for consumer `On<meta::V>` hooks is slice 3 (the
band dispatch here stays). Known limitation: on the morsel path with a large
record count, the meta bands dispatch per morsel rather than once per frame; the
once-per-frame meta-band split is a follow-on. The slice-2 test uses the
unit-outer (accumulator) path, where dispatch is once per frame.

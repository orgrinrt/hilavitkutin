# Src changelist: erased-addressed blob + per-morsel resource snapshot

**Date:** 2026-07-16
**Phase:** IMPL (this changelist opens it)
**Round:** 202606210600 (resource storage model)
**Doc CL:** `202607161000_changelist.doc.lock.md`
**Scope:** implement the settled storage model in the engine crate, additive on the
shipped one-record blob: erased static-shape addressing at the binding (op's hybrid,
global-capable) and the by-value resource snapshot in the Context projection (the
domain-19 stack-local caching). The api crate is untouched; collections (`Seq`/`Map`
member wiring) and the mutable-resource write-back stay designed-but-unbuilt, stated
in the design doc and catalogued below.

## Current state

`ResourceBinding<T, Tail>` holds a monomorphised `ResourcePtr<T>`. The resource
projection (`Project` over the bindings) copies that pointer into a `PtrCons`
bundle; `ResolveResource` derefs it live on every `resource()` call, so a WU's
per-record loop reads canonical storage each iteration (the V0 reload shape the
bench measured). No shape descriptor exists; nothing erased crosses the binding.

## CHANGE: struct `ResourcePtr<T>` gains sibling `ErasedResourcePtr`
File: `mock/crates/hilavitkutin/src/resource/provenance.rs`
`ErasedResourcePtr` wraps `NonNull<u8>`: the erased resource-value base the binding
records. `Copy`, unconditionally `Send + Sync` (the auto-trait gating on the value
type lives at `ResourceBinding<T>` via its `PhantomData<T>`). Constructors:
`unsafe fn new_unchecked(*mut u8)`, `fn as_ptr(self) -> *mut u8`, and
`unsafe fn typed<T>(self) -> ResourcePtr<T>` (the backcast; caller proves the base
was recorded for a `T`). Module doc gains the noalias-invariant statement.
Verification: `grep "pub struct ErasedResourcePtr" mock/crates/hilavitkutin/src/resource/provenance.rs` returns one match.

## CHANGE: new module `resource::shape` with `ValueShape`
File: `mock/crates/hilavitkutin/src/resource/shape.rs` (new)
`ValueShape { size: USize, align: USize }`, `Copy + PartialEq`, with
`pub const fn of<T>() -> ValueShape`. The static shape descriptor recorded next to
the erased base; in-process it witnesses the backcast (debug assert), across a
future extension boundary it is the addressing contract.
Verification: `grep "pub const fn of" mock/crates/hilavitkutin/src/resource/shape.rs` returns one match.

## CHANGE: `ResourceBinding<T, Tail>` field `ptr: ResourcePtr<T>` TO erased base + shape
File: `mock/crates/hilavitkutin/src/resource/bindings.rs`
Fields become `erased: ErasedResourcePtr`, `shape: ValueShape`, `_ty: PhantomData<T>`,
`tail: Tail`. `__ptr()` backcasts (`debug_assert_eq!(self.shape, ValueShape::of::<T>())`
then `self.erased.typed::<T>()`); the drain arm for `Sv<StagedResource<T>, L>` writes
the staged value through the typed pointer as today, then records the erased base and
`ValueShape::of::<T>()`. The ZST dangling path is unchanged in behaviour.
Verification: `grep "erased: ErasedResourcePtr" mock/crates/hilavitkutin/src/resource/bindings.rs` returns one match and `grep "ptr: ResourcePtr<T>" mock/crates/hilavitkutin/src/resource/bindings.rs` returns none.

## CHANGE: resource bundle `PtrCons`/`PtrNil` TO value-carrying `SnapCons`/`SnapNil`
File: `mock/crates/hilavitkutin/src/dispatch/engine_ctx.rs`
The projected resource bundle carries the resource VALUES, not pointers:
`SnapCons<H, Tail> { head: H, tail: Tail }`, `SnapNil`. Since the `EngineCtx` lives
on the dispatch stack frame, the bundle IS the domain-19 stack-local snapshot. The
old `PtrCons`/`PtrNil` names are deleted (no aliases, pre-1.0). Every in-tree use
(src + tests, including the `CtxFor`/`ResourceBundleOf` fold and the empty-bundle
type annotations) is renamed mechanically.
Verification: `grep -rn "\bPtrCons\b\|\bPtrNil\b" mock/crates/hilavitkutin/src mock/crates/hilavitkutin/tests` returns no plain matches (Col/Acc/Virt-prefixed bundles are unchanged).

## CHANGE: `Project` resource arm copies the value; `ResolveResource` drops its unsafe deref
File: `mock/crates/hilavitkutin/src/dispatch/engine_ctx.rs`
The resource-head `Project` impl reads the value once through the binding's backcast
pointer (`unsafe { core::ptr::read(ptr.as_ptr()) }`, `T: ColumnValue` so the duplicate
is a `Copy`) into the `SnapCons` head: the snapshot happens at projection, once per
unit per morsel. Bundle-side lookup becomes `SnapSelector<T, I>::get(&self) -> &T`
(binding-side `Selector<T, I> -> ResourcePtr<T>` stays, it feeds the projection);
`ResolveResource` resolves through `SnapSelector` with a safe borrow of the snapshot,
retiring the unsafe arena deref.
Verification: `grep "trait SnapSelector" mock/crates/hilavitkutin/src/dispatch/engine_ctx.rs` returns one match, and the `ResolveResource` impl body contains no `unsafe` block.

## CHANGE: red-first snapshot-semantics test
File: `mock/crates/hilavitkutin/tests/resource_snapshot.rs` (new)
Pins the snapshot contract: project a Context over drained bindings, mutate the
canonical value through the binding's base pointer AFTER projection, assert
`ctx.resource()` still returns the projection-time value (fails against the live
pointer impl, passes with the snapshot). Plus an erased-backcast round-trip
(drain, backcast, read equals staged value; `ValueShape::of` matches) and a
catalogued ignored case for the `Seq`/`Map` live-stream contract
(`#[ignore = "catalogue: Seq/Map collection members not yet wired into resource values; live-stream asserts land with them; tracked #344"]`).
Verification: `cargo test --manifest-path mock/Cargo.toml -p hilavitkutin --test resource_snapshot` passes; the ignored case is discoverable via `-- --ignored`.

## Not in this changelist

The register-promotion codegen proof (zero resource memory ops in the hot loop) is
the asm-gate fixture the A2b roadmap step owes (`mock/benches` asm gate); the
semantic snapshot test above is this round's contract test. The mutable-resource
write-back has no surface to test against; the design doc states it as the
activation condition. `Seq`/`Map` member wiring rides the collection-column round
(the catalogued ignored test marks it).

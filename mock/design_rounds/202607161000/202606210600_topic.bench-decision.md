## The decision run-1 + the five experts converge on

The earlier addendum (`202606210600_resource-storage-model-canonical-addendum.md`) asserted
**decompose-to-shape-bound-columns**. The bench + experts **reverse** that. The winner is:

**A one-record blob per resource (the handle points to a contiguous value), with a
stack-local snapshot of the scalar `Field` members before the morsel loop, and large
`Seq`/`Map` collection members streamed live (NOT snapshot-copied).**

Why (run-1 + the five deliverables):
- **Noalias mechanism confirmed in codegen** (objdump): V0 reloads blob members every
  iteration; V1-V5 hoist them to registers. The win is **provenance-separation + stack
  snapshot**, separable from decomposition; the snapshot is currently UNIMPLEMENTED in
  shipped code. Wall-clock parity for few-small scalars on M1 (reload is L1-hot); the
  snapshot is free insurance, decisive where the reload is not L1-cheap.
- **Decomposition (V2 type-unique columns, V5 runtime table) loses:** column count grows ~M,
  crossing the `Dim<256>` store cap on realistic resource sets; V2 also scatters (1.54x at
  M=64 intra-resource read).
- **Shape-bound shared columns (V3) loses:** 1.14x cross-core false-sharing + a
  resize-invalidates-all-sharers hazard. Its only benefit (column-count suppression) is moot
  for few resources.
- **loimu type-erasure (V4) matches the blob** on locality/column-count but adds backcast
  machinery + type-erasure soundness burden for no measured gain in the singleton regime.
- **Axis D (large collection):** live-stream beats snapshot-copy by up to 27% at 16 MiB. A
  `Seq`/`Map` member must stream live (or the snapshot holds only ptr+len), never copy elements.

## What stays locked regardless (not bench-gated)

- Resource is a **handle**, not an inline-value blob in the context struct (R5:1689). The
  shipped `DrainStores` one-record-opaque-blob is drift only in that it lacks the snapshot.
- The noalias guarantee is an **architectural invariant** (handle store never aliases value
  columns; snapshot scalar resource members before the morsel loop), not a measured outcome.

# Doc changelist: scheduler build/arena prose

One documentation surface changes this round: the engine `DESIGN.md.tmpl`
section that describes how `build` allocates the resource arena. The
prose currently describes the bespoke `MemoryProvider` path and the
`M: MemoryProviderApi` scheduler parameter. After the source migration
the scheduler is generic over `CS: ColumnStorage` and the arena reserves
its resource memory through that store. The prose must match.

## File: `mock/crates/hilavitkutin/DESIGN.md.tmpl`

Rewrite the `build`/arena paragraph (the one beginning
`` `build(memory_provider)` walks `Stores` and `StoreValues`... ``) to
describe the `ColumnStorage` mechanism:

- `build` takes a `CS: ColumnStorage` (the store the consumer wires),
  reserves a one-record column per registered `Resource<T>` through the
  store, writes the moved-in value, and records a `ResourcePtr<T>`.
  Returns an `Outcome` because reservation can fail.
- `Scheduler` gains a `CS: ColumnStorage` parameter (in place of the
  former `M: MemoryProviderApi`), owns the store, and the store frees
  every resource block on its own `Drop`. The scheduler no longer needs
  its own `Drop` for resource memory.
- Resource values are `ColumnValue` (`Copy + 'static`). Zero-sized
  resources record a dangling pointer and reserve no column.
- The engine ships `NullColumnStorage` as the default `CS` for the bare
  `Scheduler` type, so a no-store scheduler needs no concrete store.

All backticked type names introduced by the rewrite (`ColumnStorage`,
`NullColumnStorage`, `ColumnValue`, `ResourcePtr`) exist in source after
the src changelist lands, so the `design-doc-source-mismatch` lint is
satisfied. `MemoryProvider` / `MemoryProviderApi` remain real types (the
store is still backed by a provider); only the scheduler's direct
dependence on them is removed.

## Out of scope for the doc

`BACKLOG.md.tmpl` and `README.md.tmpl` need no change: the arena and
build mechanism is not described there. The api-crate `DESIGN.md.tmpl`
already documents `ColumnStorage` (it landed with the contract); this
round adds no api-crate surface.

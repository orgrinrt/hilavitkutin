# Topic: remove the stale mockspace build-dep claim

**Date:** 2026-09-19
**Phase:** TOPIC
**Scope:** `hilavitkutin-linking`, `hilavitkutin-extensions`, `hilavitkutin-extensions-macros`
DESIGN.md.tmpl sources and their generated `docs/*.md` counterparts.
**Grounded on:** PR #8's own diff against `dev` (dropping the bare `mockspace`
workspace dependency), and the `202607311110_topic.launcher-migration.md`
topic already open in this round, which tore down the `build.rs` bootstrap and
said explicitly that the teardown touched "none... crate source or design
docs".

## What is wrong

Three crates' `DESIGN.md.tmpl` sources, and the `docs/*.md` files generated
from them, carry a stale claim:

- `mock/crates/hilavitkutin-linking/DESIGN.md.tmpl:75`: "mockspace (workspace
  convention) bootstraps the mock workflow via build.rs."
- `mock/crates/hilavitkutin-extensions/DESIGN.md.tmpl:143`: "Build-time:
  mockspace (workspace convention)."
- `mock/crates/hilavitkutin-extensions-macros/DESIGN.md.tmpl:45`: "Build-time:
  mockspace (workspace convention)."

None of this is true after PR #8. No crate in this workspace carries a
`build.rs` calling into mockspace, no crate declares a
`[build-dependencies]` entry on it, and the workspace `mockspace` dependency
itself is gone from `mock/Cargo.toml`. The claim was already false before PR
#8, going back to `202607311110_topic.launcher-migration.md`, which tore down
every crate's bootstrap `build.rs` and the matching `[build-dependencies]`
entries but explicitly scoped itself away from crate source and design docs.
PR #8 removing the last trace of the dependency from `mock/Cargo.toml` is
what surfaces the gap now, in review.

No other crate's `DESIGN.md.tmpl` makes this claim (`hilavitkutin`,
`hilavitkutin-build`, and `hilavitkutin-persistence` each state their
dependencies without mentioning mockspace at all), so the fix is a deletion,
matching the sibling crates' existing shape, not a rewrite to some other
claim.

## What changes

Delete the false "Build-time" claim from each of the three `DESIGN.md.tmpl`
sources:

- `hilavitkutin-linking`: remove the "Build-time dependency:" subsection (the
  header and its one bullet) from the Dependencies section, leaving Workspace
  dependencies and Platform dependencies to flow directly into the
  "No dependency on..." sentence that already follows.
- `hilavitkutin-extensions`: remove the standalone "Build-time: mockspace
  (workspace convention)." line from the Dependencies section.
- `hilavitkutin-extensions-macros`: remove the same standalone line from its
  Dependencies section.

Regenerate `docs/LINKING.md`, `docs/EXTENSIONS.md`,
`docs/EXTENSIONS_MACROS.md` via `cargo mock` so the rendered documents match.

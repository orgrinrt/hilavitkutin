## Changes proposed

### 1. The sealers are `pub` in their private modules

`hilavitkutin-api/src/lib.rs:19` and `hilavitkutin-conformance/src/oracle/mod.rs:27` declare the sealing supertrait `pub` inside a module no path outside the crate names, so it is as sealed as before and a public trait may bound on it. The `private_bounds` attributes go from `hilavitkutin-api/src/store.rs:229` (`BufferMode`) and `:339` (`Starts`), `hilavitkutin-conformance/src/oracle/keeping.rs:15` (`Keeping`) and `visiting.rs:13` (`Visiting`). `hilavitkutin-api/src/access.rs:84` (`HoldsAll`, on `seal::Walk`) and `hilavitkutin/src/resource/bindings/column.rs:143` (`ColKind`) bounded on a `pub` trait in a private module already, so their attributes go with no other change.

`single-source` compares a `pub` item in a private module as public, so three crates each sealing with a `pub trait Sealed {}` read as one concept defined three times. The api keeps `Sealed`, which its design names (`hilavitkutin-api/DESIGN.md.tmpl:158`, `:185`, `:1622`). The sealers no design names are named for what they close: the engine's `KindSealed` (`bindings/column.rs:22`) and `BindingsSealed` (`bindings/mod.rs:62`), the conformance crate's `OracleSealed` (`oracle/mod.rs:28`). The lint's reading is the ticket `single_source_compares_a_pub_item_in_a_private_module_as_pub`.

### 2. `record::words` takes a `record::State`

`hilavitkutin-frozen-authors/src/record.rs:22` declares `State`, the stores as slices and the flag, and `words` takes it and the sink, as the locked design says. The harness builds it in `tests/common/lend.rs` (`kept!`) and `tests/common/mod.rs` (`words_of`, `model_frames`, `Stores::words`). `LEDGER.toml` carries the file's new hash; the trunk has no ledger yet, so no break is owed.

### 3. The shared test modules hold only what each binary uses

The inner `#![allow(dead_code)]` goes from `hilavitkutin-conformance/tests/common/mod.rs` and `hilavitkutin-frozen-authors/tests/common/mod.rs`; every item in both is used by every binary that includes them.

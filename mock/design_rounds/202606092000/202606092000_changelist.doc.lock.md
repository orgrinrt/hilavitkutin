Adds a short subsection after the ColumnValue section describing the opt-in per-record transform contract: a work unit that is a pure per-record map (read one column, write one column, value-to-value) may additionally declare that map so the engine can fuse a linear chain of such units into one register-passing loop body. The contract is opt-in (a simple work unit never implements it) and orthogonal to the `WorkUnit` execute contract (no change to execute). ## hilavitkutin/DESIGN.md.tmpl

Extends the dispatch description with the within-fiber fusion mechanism (the canonical spec's deep-single-fiber rust-pipe): a linear RAW chain of opt-in per-record maps folds at the type level into a single fused work unit whose body keeps the intermediate columns register-resident (DSE eliminates the memory traffic), and a fused dispatch entry on the scheduler folds the registered carrier and walks the fused unit. Records the scope boundary from the spec (multi-fiber diamonds reach parity through per-fiber dispatch, not linear fusion) and the explicit-entry dispatch shape (transparent auto-detection is not expressible on the toolchain; sketch 202606091800).

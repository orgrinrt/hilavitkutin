## Notes

- `RecordOp::In` / `::Out` are bounded `ColumnValue` (so they flow into `ChainWu`'s `Column<T>` read/write sets); `ColumnValue` is `Copy + 'static`, satisfied by the bench's value newtypes.
- The fused `ChainWu` reads only the chain input column and writes only the chain output column; internal columns stay registered (the bench reserves them) but are never touched at runtime, so they remain register-resident in the fused body. Eliding their reservation (C7) is a follow-up.
- No core `WorkUnit::execute` contract change. `RecordOp` is a separate opt-in trait; `ChainWu` is a normal `WorkUnit`.

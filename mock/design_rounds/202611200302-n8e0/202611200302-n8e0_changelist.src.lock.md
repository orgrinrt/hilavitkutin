# src changelist

Round topic `202611200302-n8e0_topic.what-the-review-of-the-freeing-round-found.md`, doc changelist `202611200302-n8e0_changelist.doc.lock.md`.

## Changes proposed

### 1. A refused re-reserve

`crates/hilavitkutin-providers/src/storage.rs`: `ArenaColumnStorage::reserve` computes the byte length, and answers `LengthOverflow`, before it gives a live id's block back, so a refused argument leaves the column as it was. The give-back stays ahead of the allocation.

Tests, `crates/hilavitkutin-providers/tests/column_storage.rs`: a re-reserve of a live id with a length past `usize` answers `LengthOverflow`, frees nothing and keeps the count; a re-reserve the provider refuses answers `Exhausted`, frees the old block once and leaves the id with a count of zero; a re-reserve over a buffer that holds one column and its alignment slack succeeds every cycle, so the old block goes back before the new one is taken.

### 2. The arena bound

`crates/hilavitkutin-providers/src/interner.rs`: `MemoryArena`'s build check reads `ENTRIES <= 1 << 28`, with its message and the docs on `new` and the type saying so; the ticket marker goes. `crates/hilavitkutin-providers/tests/ui/memory_arena_entries_past_the_id_width_fail.rs` takes an arena of 2^28 + 1 entries, and its `.stderr` is regenerated. Ticket `the_memory_arena_s_entry_bound_is_one_short_of_the_28_bit_id_field` is closed.

### 3. The free-list provider's tests

`crates/hilavitkutin-providers/tests/static_free_list_memory.rs`: a block aligned above the grain after a small one leaves the space in front of it on the list, so a small block lands in that gap and everything given back makes the whole span one block again; the list is laid over buffers that start 1 to `GRAIN - 1` bytes past a grain boundary with lengths that are not a multiple of the grain, every block lies inside the buffer and the grain-aligned interior is handed out whole, and a buffer shorter than its offset to the grain hands out nothing.

### 4. The str refusal boundary

`crates/hilavitkutin-str/tests/interner.rs`: an arena that answers `2^28 - 1` gives `Maybe::Is` with that id, beside the existing test that `2^28` is refused.

### 5. The allow's place

`crates/hilavitkutin-api/src/platform.rs`: the provided `allocate_zeroed` keeps its `lint:allow` on its signature under `#[rustfmt::skip]`, as its siblings do, and the trait doc's long line is rewrapped.

### 6. The asm gate report

`benches/asm_gate_fixtures/asm_gate_report.x86_64.md` is regenerated: the fixtures link `hilavitkutin-providers`, and `give_back` moves their stack-relative access counts.

## Not changed

`StaticFreeListMemory`'s source, which the review found correct; the orderings it names are the ones it already uses.

# Source changelist: gate2 worker-side waist barrier

**Round:** 202606071805 (gate2-worker-side-waist-barrier)
**Phase:** SRC

Replace the main-orchestrated per-phase park/wake in `run_parallel` with a
worker-side sense-reversing waist barrier: one publish/await round-trip per
frame, workers run all phases hot, syncing at each interior waist. The
sense-reversing flip is the deferred-E3 reset-race fix. Bench-justified:
`wide_parallel` parallel is 2.45x at N=4096 purely from the per-phase
round-trips (finding committed `ac1b305`).

## CHANGE: struct `PoolFrame` ADD field `barrier_sense: AtomicU32`
File: `mock/crates/hilavitkutin-api/src/platform.rs`
Verification: `grep "pub barrier_sense: AtomicU32" mock/crates/hilavitkutin-api/src/platform.rs` returns one match. The sense/generation word a reversing barrier flips each episode; `phase_arrived` (the count) is unchanged.

## CHANGE: fn `waist_barrier` ADD
File: `mock/crates/hilavitkutin/src/thread/barrier.rs`
Verification: `grep "pub fn waist_barrier" mock/crates/hilavitkutin/src/thread/barrier.rs` returns one match. Sense-reversing: snapshot `barrier_sense`, `fetch_add` `phase_arrived`; last arriver (`prior+1==expected`) resets `phase_arrived` to 0, bumps `barrier_sense` (Release), `atomic_wake_all(&barrier_sense)`; followers `atomic_wait(&barrier_sense, sense)` until it changes. Reusable per frame with no reset race.

## CHANGE: add `context_multi_column_distinct_read_write` integration test
File: `mock/crates/hilavitkutin/tests/engine_ctx.rs`
Adds two access-set aliases (`ReadU8U16 = {Column<u8>, Column<u16>}`, `WriteU16U32 =
{Column<u16>, Column<u32>}`) and a test that projects an `EngineCtx` over a three-column
source (`u8`, `u16`, `u32`), writes `u16` and `u32` through the write bundle and reads `u8`
and `u16` through the read bundle, asserting each resolves to its own buffer at the morsel
offset. `u16` is read-and-written (one buffer, resolved in both `RCols` and `WCols`). This
exercises `ColSelector` index resolution to both `Here` and `There<Here>` on each side of the
split, the deeper path the single-element `context_column_read_after_write` test did not
cover.
Verification: `cargo +nightly-2026-05-28 test -p hilavitkutin --test engine_ctx context_multi_column_distinct_read_write` passes.

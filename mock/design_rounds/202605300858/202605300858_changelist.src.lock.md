## CHANGE: NEW trait `RunFiber` ADD
File: `mock/crates/hilavitkutin/src/dispatch/fiber_walk.rs`
`pub trait RunFiber<A, Witnesses> { fn run(&self, arena: &A, morsel: MorselRange); }`. Base impl `RunFiber<A, Empty> for WuNil` is a no-op. Recursive impl `RunFiber<A, Cons<RIdx, WTail>> for WuCons<W, Tail>` projects `W`'s `EngineCtx` from the arena through `EngineCtx::project`, runs `execute` via `invoke_wu_in_fiber`, and recurses on the tail. The load-bearing bound is the HRTB GAT equality `for<'f> W: WorkUnit<Ctx<'f> = EngineCtx<'f, W::Read, W::Write, <A as Project<W::Read, RIdx>>::Out, ColPtrNil, ColPtrNil>>`; `Witnesses` carries each per-unit resource projection index (mirrors `plan::project::BundleProject`). The `ColPtrNil` column projections in the bound enforce the resource-only boundary at the type level.
Verification: `grep "trait RunFiber" mock/crates/hilavitkutin/src/dispatch/fiber_walk.rs`.

## CHANGE: NEW fn `run_fiber_walk` ADD
File: `mock/crates/hilavitkutin/src/dispatch/fiber_walk.rs`
`pub fn run_fiber_walk<F, A, Witnesses>(fiber: &F, arena: &A, morsel: MorselRange) where F: RunFiber<A, Witnesses>`. Drives the walk; the nested witness list infers at the call site, no caller turbofish. Carries a `compile_fail` doctest proving the resource-only boundary: a column-writing unit's `Ctx` has `ColPtrCons` write columns, so the walk's `ColPtrNil` bound is unsatisfied and the unit cannot enter the sequence.
Verification: `grep "fn run_fiber_walk" mock/crates/hilavitkutin/src/dispatch/fiber_walk.rs`; `grep "compile_fail" mock/crates/hilavitkutin/src/dispatch/fiber_walk.rs`.

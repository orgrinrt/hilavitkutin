# Topic: hilavitkutin-api unused feature gate removal

**Date:** 2026-06-19
**Crate:** hilavitkutin-api
**Tracked:** #686 (api feature-gate + warning drift cleanup), partial

## Problem

`hilavitkutin-api/src/lib.rs:16` declares `#![feature(impl_trait_in_assoc_type)]`,
which rustc reports as "declared but not used". Per the unstable-features rule a
declared-but-unused gate is drift: it misrepresents what the crate depends on.

## Change

Remove the unused gate line. The compiler confirms it is unused; removal clears
the warning and the build stays green. The second api warning (`sealed::Sealed`
more private than `Executor`, a sealed-trait private_bounds lint) needs a
visibility/allow judgment and is left to a follow-up slice of #686.

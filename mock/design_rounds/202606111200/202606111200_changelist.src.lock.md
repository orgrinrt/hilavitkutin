# Src changelist: E7 incremental-skip (GATE-1)

**Round:** 202606111200 (E7 dirty-skip incremental)
**Phase:** IMPL

Implements the canonical Step 9 dirty-propagation incremental skip for one core. Two parts, each fail-first tested. Part A is plan-time (per-unit predecessor masks); Part B is runtime (seed, propagate, gate). The propagate pass is proved by sketch `202606062600_e7_dirty_skip`; gating the real `RunFiber` walk while preserving devirtualisation is proved by sketch `202606111000_e1-e7-dirty-gated-walk`. The store-index resolution reuses the shipped `Locate` / `WitnessIndex` witness (`plan/project.rs`), the same Stores-list-position space `PlanInputs` masks index.

## Part A: per-unit predecessor masks (plan-time)

## CHANGE: add `compute_predecessor_masks` FROM `absent` TO `pub fn` over the dependency graph

## CHANGE: add `mark_dirty` and wire `replace_resource` / `replace_value` FROM `stub` TO setting the store-dirty seed
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs`
`pub fn mark_dirty<T, Index>(&mut self)` where `Stores: Locate<T, Index>, Index: WitnessIndex` sets `store_dirty = store_dirty.set(Index::INDEX)`. `replace_resource::<T: PlanAffecting>` and `replace_value::<T: Replaceable>` resolve T's store position the same way and set the seed bit (replace_resource additionally sets `plan_dirty`, whose recompute consumption is sequenced later; this round only sets the bit). The `let _ = &self.plan_dirty;` placeholders are replaced by real seed-setting.
Verification: `grep "fn mark_dirty" mock/crates/hilavitkutin/src/scheduler/mod.rs` returns one match; the resource-seeded skip test passes.

## CHANGE: `Scheduler::run` and `run_fused` FROM `unconditional walk` TO `seed-propagate-gate`
File: `mock/crates/hilavitkutin/src/scheduler/mod.rs`
At entry both compute `seed_units` (a `D::AdjRow`): if `first_frame`, all live carrier positions set; else for each unit `p`, set bit `p` iff `read_masks[p].overlaps(&store_dirty)`. Propagate forward in carrier order over `predecessor_masks` (`dirty[p] |= 1<<p` when `predecessor_masks[p]` intersects the running dirty). Both passes bound their loop to the live unit count (`topo_count`), not the full unit-capacity array length: positions past the live count carry empty masks and stay clean, so iterating them is pure per-frame overhead on the hot path. Walk the carrier via the dirty-gated `RunFiber` path threading the dirty mask and carrier position. After the frame, clear `store_dirty` to empty and set `first_frame` false. Stale doc comment on `record_count` (the field claiming single-morsel dispatch and citing the morsel-loop split as future #343) is corrected; `plan_dirty` / `plan_cache` are read by the seed/cold-frame logic rather than discarded.
Verification: the incremental-skip integration test passes (cold frame runs all, clean frame runs none, one-root-changed frame runs only the cone); `cargo test` for the engine green.

## CHANGE: add dirty-gated walk to `RunFiber` FROM `unconditional run` TO position-gated
File: `mock/crates/hilavitkutin/src/dispatch/fiber_run.rs`
The per-unit `RunFiber` step gains a dirty-mask + carrier-position parameter (a `run_gated` method or a dirty arg on the walk); each step projects and invokes its unit only when the dirty bit at its position is set, then recurses with `pos + 1`. The bound block is unchanged from `run`; only the body gains the `if dirty & (1<<pos) != 0` guard around project+invoke, matching sketch `202606111000`. The plain `run` stays for callers that always run every unit.
Verification: `grep "run_gated\|dirty" mock/crates/hilavitkutin/src/dispatch/fiber_run.rs` returns the gated path; objdump of a release dispatch mono shows the gate as a predicated branch with no new indirect call (zero added `blr`).

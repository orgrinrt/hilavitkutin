The step is about one property of the engine's suite: a test that cannot fail certifies nothing. The faults in scope are the ways this suite cannot fail today. The negative case of the builder is checked by hand and the comment says so (`tests/scheduler_builder.rs:10-16`). Twelve builder tests end on `.ok();`, so they pass whatever `build` returned. The incremental skip is tested by counting how many units ran and never by comparing what the stores hold against a run that skips nothing. Two replacement methods discard their argument. Several stubs sit behind a property marker, so a bound that names the property is satisfied by a body that does nothing.

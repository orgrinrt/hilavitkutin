# src changelist

Round topic `202611200033-ut6z_topic.review-fixes-to-the-host-path.md`, doc changelist `202611200033-ut6z_changelist.doc.lock.md`. Source changes are to tests only.

## Changes proposed

### 1. The compile-fail cases, one refusal each

`mock/crates/hilavitkutin/tests/ui/`: the pass fixture and the refusals share one body, `host_import_body.in`, brought in with `include!`. The body registers an `Accum`, a `Virtual` and a `Resource` of their own value types beside the two columns, so each fixture's refusal is the kind bound alone and not a registration failure as well. A macro in the body writes `main` from the store types of the import and the dump, and each fixture is that one call.

The fixtures:

- `host_import_pass.rs`: `Column<A>` in, `Column<B>` out;
- `host_import_accum_fail.rs` and `host_import_accum_dump_fail.rs`: a registered `Accum` in each position;
- `host_import_virtual_fail.rs` and `host_import_virtual_dump_fail.rs`: a registered `Virtual` in each position;
- `host_import_resource_fail.rs` and `host_import_resource_dump_fail.rs`: a registered `Resource` in each position;
- `host_import_unregistered_fail.rs` and `host_import_unregistered_dump_fail.rs`: a `Column` the builder never registered, in each position;
- `host_import_written_fail.rs`: `Written<Column<A>>`, which carries `ColMember` and is refused by `Kept` alone.

`tests/ui.rs` lists all of them.

### 2. The buffered test's comment

`mock/crates/hilavitkutin/tests/host_import.rs`: the comment over the buffered cases says what they catch, an import that missed the frozen side, and that the live-side copy has no reader a test can reach today, per the design.

## Not changed

`src/`: the code of `import` and `dump`.

# src changelist

Round topic `202611151003_topic.clippy-driver-wrapper-warning.md`; the doc changelist is `202611151003_changelist.doc.lock.md`.

## Current state

`configure_with` warns whenever the workspace wrapper cargo names does not end with `hilavitkutin-rustc-wrapper`, `clippy-driver` included. `a_missing_wrapper_is_warned_of_when_there_are_flags` asserts the warning for `clippy-driver`.

## Changes proposed

### 1. A wrapper ending with `clippy-driver` counts as wrapped

`configure_with` takes a wrapper path ending with `clippy-driver` as it takes `hilavitkutin-rustc-wrapper`, and writes no warning for it. Its rustdoc says a check loses nothing without the flags, which only steer code generation.

### 2. Tests

`a_missing_wrapper_is_warned_of_when_there_are_flags` takes a wrapper of another name (`rustc-wrapper`) where it took `clippy-driver`, so it still shows that an unknown wrapper is warned of. `clippy_driver_as_the_wrapper_is_not_warned_of` asserts no warning for a full `clippy-driver` path and a warning for `/usr/bin/sccache`; it fails without change 1.

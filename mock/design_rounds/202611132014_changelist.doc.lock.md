# doc changelist

Round topic `202611132013_topic.review-one-findings.md`. The other flat topic, `202607200100_topic.b1-cap-lifting-completion.md`, is about lifting the scheduler's scratch arrays onto the plan's capacities. Nothing here touches those arrays, and it stays flat for the round that does.

## Current state

The engine's design says a read-after-write edge into a read with a reach is a phase boundary, with the writer's whole range landed on every core before the reader's phase starts. It says so once, in general, and does not say how the unit-outer path of `run_parallel` keeps it. That path runs no phase loop, and the source keeps no boundary there: each core walks the whole carrier over its slice of the records, so a reach reader on one core reads across the slice edge while the writer on the next core is still writing. The first review reproduced it.

The design says a const assertion at `build` refuses a unit that writes a plain column it reads with a reach. It does not say at which dimensions the assertion folds the masks. The source names the default dimensions in the assertion and again in `build`.

The design says a buffered write lands on the live side whether the value differs from the frozen one or not. The source does that and no test would notice if it stopped.

## Changes proposed

1. `mock/crates/hilavitkutin/DESIGN.md.tmpl`, under "The value function and the close": one paragraph saying the boundary holds on every path that hands the record range to more than one core, and how the unit-outer path keeps it. The walk is cut ahead of each consumer unit that reads with a reach behind a writer, and the cores cross the barrier the phases use before any of them starts the reader. The cut positions fold at compile time, and a carrier with no such reader crosses no barrier. This is the second of the two repairs the review named. The first, refusing a plain-column reach in a carrier with an accumulator, would narrow what may be registered below what the design already grants.

2. The same section: one sentence saying the assertion folds the masks at the dimensions `build` computes the plan at, handed to it.

3. No design text for the buffered write. The sentence is already there. The source changelist adds the test that holds it.

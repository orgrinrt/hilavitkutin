# Src changelist: the overflow choice is the consumer's

**Date:** 2026-11-13

The source follows the locked doc changelist (`202611130554_changelist.doc.lock.md`). The choice is settled in the types: an associated type on `RunCfg`, a marker parameter on `DefaultRunCfg`, no cargo feature and no runtime branch on a value known at the call site.

## CHANGE: `AccumOverflow`, `Refuse` and `Assert`
Files: `mock/crates/hilavitkutin-api/src/accum_overflow.rs` (new), `mock/crates/hilavitkutin-api/src/lib.rs`.
A sealed trait with `type Out` and `fn conclude(verdict: Outcome<(), AccumRefused>) -> Self::Out`, and its two inhabitants, the engine's own fixed vocabulary. `Refuse` returns the verdict as it is. `Assert` has `Out = ()` and panics on an `Err`, naming the refusal. The api root exports all three.

## CHANGE: `RunCfg::Overflow` fixes `RunCfg::Out`
Files: `mock/crates/hilavitkutin-api/src/run_cfg.rs`.
`RunCfg` declares `type Out;` and `type Overflow: AccumOverflow<Out = Self::Out>;` in place of the `From<Outcome<(), AccumRefused>>` bound, so `Out` differs by the choice and by nothing else. `DefaultRunCfg<O: AccumOverflow = Refuse>` carries the choice as a marker parameter (`PhantomData<O>`) and a `const fn new`; every impl is generic over `O`. `DefaultRunCfg` written bare is the refusal as a value, as before.

## CHANGE: the frame's verdict is concluded by the choice
Files: `mock/crates/hilavitkutin/src/scheduler/verdict.rs`, `mock/crates/hilavitkutin/src/scheduler/builder.rs`.
`frame_verdict` builds the `Outcome` from the first refusal and returns `<Cfg::Overflow as AccumOverflow>::conclude(verdict)`. `build` names its budget consts as `<DefaultRunCfg as RunCfg>::...`, since a bare `DefaultRunCfg::CONST` path does not take the default parameter.

Where the assert fires is a vehicle choice and is kept as the design states it: at the close, in `frame_verdict`, on the thread that called the run, after every worker has re-parked. `dev`'s assert fired inside the append, on a worker, and under `run_parallel` that left the join waiting on a core that had unwound (fault H2 of the first review). The append path is the same under both choices; the panic is the assert inhabitant's conclusion of the same verdict.

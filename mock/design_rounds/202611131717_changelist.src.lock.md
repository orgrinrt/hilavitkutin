# src changelist: a pragma reaches rustc through the crate's own build script

**Date:** 2026-11-13
**Phase:** SRC
**Topic:** `202611131717_topic.every-crate-builds-through-hilavitkutin-build.md`
**Doc changelist:** `202611131717_changelist.doc.lock.md`

`hilavitkutin-build` gains `configure`, `configure_with`, `write_rustflags` and `write_wrapper`, and its
directives now carry the crate's rustc flags. Every other crate of the workspace builds through it,
the workspace commits the wrapper, and the release profile carries ExpandedLto's two keys.

## CHANGE: `mock/crates/hilavitkutin-build/src/flags.rs`, new

`write_rustflags` writes the flags of a `PragmaSet`, space-separated, in bit order. LoopOptimization
writes its five built-in `-Cllvm-args` options, `ParallelCodegen(n)` writes `-Zthreads=n`,
SharedGenerics writes `-Zshare-generics=y`; every other pragma writes nothing. The plugin flag is a
`FIXME(hilavitkutin_build_build_scripts_find_the_plugins_and_profil)` at its site.

## CHANGE: `mock/crates/hilavitkutin-build/src/bootstrap.rs`

`write_directives` writes `cargo::rerun-if-changed=build.rs`, the `rustc-check-cfg` declaration of
`arvo_fast_math`, the cfg when FastMath is active, and
`cargo::rustc-env=HILAVITKUTIN_BUILD_RUSTFLAGS=<flags>`. `write_wrapper` writes the wrapper's three
lines. The variable's name is one `macro_rules!` spliced into both by `concat!`, since the
`no-bare-static-str` lint refuses a `const &str` and the crate takes no `hilavitkutin-str`. `Env` is a
trait alias over the closure a build script passes; `configure` and `configure_with` read `PROFILE` and
`CARGO_CFG_TARGET_FEATURE` through it, apply the tuning, and write the directives. The module example
is the three-line build script.

## CHANGE: `mock/crates/hilavitkutin-build/src/profile.rs`

`from_cargo_profile` matches `release` and falls back to `Dev` for everything else, `debug` included.

## CHANGE: `mock/crates/hilavitkutin-build/src/lib.rs`, `Cargo.toml`

The new module and items are exported and the docs say what a build script does. The unused `arvo`
dependency is removed.

## CHANGE: every other crate's `build.rs` and `Cargo.toml`

The twelve crates other than `hilavitkutin-build` get a `build.rs` calling `configure` and
`hilavitkutin-build` under `[build-dependencies]`. `hilavitkutin-build` cannot take itself as a build
dependency.

## CHANGE: `mock/.cargo/config.toml`, `mock/.cargo/hilavitkutin-rustc-wrapper`, `mock/Cargo.toml`

The wrapper and the config naming it are committed; the wrapper is executable. `[profile.release]`
sets `opt-level = 3`, `lto = "fat"` and `codegen-units = 1`.

## CHANGE: tests

`tests/bootstrap.rs` pins the release and dev directives exactly, the empty flag list, that no flag is
one the pinned toolchain refuses, that `configure` reads the two variables through the closure, that
`configure_with` drops the cfg and keeps the loop flags, and that the committed wrapper is the written
one. `tests/profile.rs` pins the two names cargo passes and the fallback for the rest.

Shown failing first: with a line appended to `.cargo/hilavitkutin-rustc-wrapper`,
`the_committed_wrapper_is_the_written_one` fails on its `assert_eq`; the copy was put back.

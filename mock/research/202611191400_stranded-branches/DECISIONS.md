# The stranded hilavitkutin branches of last week, decided

On 19 November the workspace note `.shared/research/202611191130_stack-unmerged-branches/README.md` classed every unmerged remote branch of hilavitkutin. This note takes each SOURCE and MIXED branch it names, except the two of the build-pragmas job (`work/hilavitkutin-build-sets-a-consumer-up-by-itself-and-an`, `work/hilavitkutin-and-kaski-take-hilavitkutin-build-with-a-first`), and decides it: land, consolidate, or retire as superseded by `dev`. BENCH branches are left to the coordinator that sweeps them.

The classification counts a path as landed only where its blob on `dev` is identical, so a branch that landed by squash and was then moved past on `dev` reads as still differing. Every branch here was therefore measured three ways against `origin/dev` at `07a9e9a3`: whether a `dev` commit carries one of its subjects, and if so whether the branch tip differs from that commit on any path the branch changed; whether the branch is an ancestor of another branch that did land; and whether any file it adds under `mock/design_rounds`, `mock/research` or `mock/benches` has a blob found nowhere in `dev`'s tree or history. The scripts that did it are committed beside this note in `scripts/` (`landing.sh`, `ancestry.sh`, `record-blobs.sh`), each taking the clone's path and the branch names, and the method section below restates what they compute.

The outcome is that none of the seventeen lands its source. Thirteen retire, on `dev` already byte for byte at their landing. Three hold: their source is on `dev`, but each adds record files whose content is nowhere on `dev`, and the rule `the-record-lands-from-every-branch` lands a branch's record whole and has differing content at one path consolidated by hand, so the branch stays until its record lands. One waits on a mockspace change that has not landed. Retiring means the remote branch is deleted through `forge-route delete-branch`, which is the coordinator's step; this note only records the decision.

## Method

For each branch, with `base` its merge base against `origin/dev`: the `dev` commit whose subject equals one of the branch's own subjects in `base..origin/dev`, then `git diff --name-only <that commit> origin/<branch> -- <paths changed in base..branch>`, counted. Ancestry by `git merge-base --is-ancestor`. Record files by `git diff --name-only --diff-filter=A base origin/<branch> -- mock/design_rounds mock/research mock/benches`, each blob looked up in `git ls-tree -r origin/dev` and in `git log --raw origin/dev`.

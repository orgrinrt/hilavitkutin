## The nine findings

1. Staged side from the Bound. `Store::step(&mut self, Opening)` returns the committed view, `Read + Sync`, and the whole staged side, `Stage + Send`; only the checked table makes an `Opening`. `Bound::step` hands a `StepFn` the committed view and `Units`; `Units::next` hands each unit to a `StagedFn` as a `Staging` holding exactly its write columns (`Stage::take`), cut further by position with `split` (`Stage::split`). The swap commits only the columns taken. Proof that a threaded runner needs no author or implementor change: `hilavitkutin-reference/tests/threads.rs`, a `StepFn`/`StagedFn` that splits each part at its middle and runs both halves on `std::thread::scope`, over `Columns`, `Records` and the honest probe; its digests equal the reference's. No `unsafe` anywhere.
2. Branded Bound. `bind` takes `&mut S` and `Bound` holds it for its life. UI fixtures: `store_touched_while_bound` (E0499), `view_past_step` through the bound (E0502), `bound_literal` (E0451), `col_literal` and `col_mint` (private fields, E0624).
3. One role per column. `ValueKernel::Roles: Roles<D>`, each column once; every `Own`/`Near` member finds its place with notko-hlist `PlaceOf<M, P>`, the places tuple `P` inferred at `bind`. No specialization. A column named twice fails as E0283 (ambiguous place), a member whose column is not in `Roles` as E0277 ("has no place for"); UI fixtures `role_named_twice`, `member_outside_roles`. Fall-back, stated in the design and not built: one role per member with a bind-time check that members of one column name one stored column. Bind tests: `Pair` writing one column twice is refused, `Split`'s two written roles on one stored column are refused, `Carry` reading and writing one stored column binds.
4. Law matrix on three stored columns: `Diffuse` (column 1) and the test kernel `Mirror` (reads 1, writes 2), column 0 written by neither. B1 over the three stores, `Forward` and two `Permuted` seeds, morsels 1, 7 and 20, inputs Scramble, Zero and Edges. New mutants: `IgnoresColumn` (fails B1 at `first_of(HEAT)`) and `SwapDropsUnwritten` (fails B1 at `first_of(STILL)` and B3 at stream 2).
5. `Witness::TooFew { given, needs }`: `morsel_split_and_order` and `frame_isolation` check the count first; tests for 0 and 1 streams and 0 and 1 poisoned runs, including a case that would otherwise differ.
6. The assertion that cannot fail is gone with the `before` checks in `tests/bind.rs`: the store is lent `&mut` to `bind`, so nothing else can touch it.
7. The `lint:allow` escape is removed from `mock/lints/frozen/scan.rs`; each frozen lint's tests assert an escaped line is still reported.

## Departures, each a departure from the plan or from pass one's design

1. `Records` stages column-major (committed stays record-major, last key first); the swap copies written columns into the records.
2. `Value` is sealed with `Int` its one impl; a consumer's own value type waits on a `FormatId` uniqueness rule. The plan left `Value` open.
3. A morsel size of zero is not the whole: `Morsel` is never zero.
4. `Ordinal` and `ColumnNo` are new beside `Index` and `Count`.
5. `notko`/`notko-hlist` locked at `8a74dbcd` (the line carrying `PlaceOf`, after `ae194643`).
6. Only the frozen crates are `publish = false`; laws and reference stay publishable as the oracle a third party is held to.
7. `Refusal::Outside { frame, outside }`: a write a visiting order hands outside the store is refused as a value.
8. `Mirror` is a test kernel in the reference's tests, not a frozen author.
9. The ledger lint refuses dev and build dependencies too; the plan named normal dependencies.
10. The places tuple `P` is a type parameter of `bind`, `Bound` and the runner functions; callers write `_`.

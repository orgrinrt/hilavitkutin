# Parked work

A patch here is a slice somebody stopped mid-flight, on purpose, with a reason.
It sat in a git stash, which is the one place work can be lost without anybody
noticing: a stash is local to one clone, invisible to `git status`, and gone
with the clone.

The file names the round it belongs to and the reason it stopped. It is a
record, not a thing to apply: the trunk has moved since, and the mechanism has
usually been rebuilt differently. Read it for what was attempted and why it
stopped, then write the current version.
